# Ralph Progress Log
Started: Sun Mar  8 20:49:26 CST 2026

## Codebase Patterns
- GitHub adapter: for route-based directories where all files are named `index.mdx`/`index.md`, the adapter now derives slugs from the parent directory path instead of the filename. No special config needed — it auto-detects `index` filenames.
- Adding a new llms-full library: add entry to `packages/scraper/sources.json` with id, name, description, version, adapter, url fields; then `pnpm build && node dist/index.js --library <id>` from packages/scraper
- Adding a new llms-txt library: same pattern as llms-full but with `adapter: "llms-txt"` and url pointing to llms.txt; the adapter fetches the index, follows linked pages, and processes each individually
- If llms.txt links to .txt files (not .md), use `llms-index` adapter with `servicePattern` regex and `contentType: "llms-full"`
- The llms-txt adapter now supports HTML pages: if no .md/.docs links found, it falls back to all links; HTML responses are auto-detected and extracted via cheerio/turndown
- For HTML pages via llms-txt, optionally add `crawl.contentSelector` and `crawl.removeSelectors` to configure extraction
- Link fallback uses ratio: if .md/docs filtered links are <20% of total AND total ≥5, all links are used (prevents single outlier .md links from suppressing HTML doc links)
- Scraper auto-updates `registry/manifest.json` and writes docs to `registry/docs/<id>/`
- Commit should include sources.json, registry/docs/<id>/, and registry/manifest.json
- GitHub adapter: if tree fetch returns 404, try the other default branch (`main` vs `master`) — repos vary
- `slugify()` in `packages/scraper/src/utils.ts` truncates slugs to 200 chars max to avoid ENAMETOOLONG errors on macOS (255-byte filename limit)
- GitHub adapter: when repo has multilingual docs in subdirectories (e.g., `zh/`, `ja/`), use `exclude: ["zh/"]` to keep English-only content — otherwise translated files overwrite English ones for duplicate slugs
