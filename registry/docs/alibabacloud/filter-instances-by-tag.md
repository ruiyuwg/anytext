After you attach tags to MongoDB instances, you can filter the instances by tag. This helps you quickly find and manage instances in a specific category.

## Prerequisites

Log on to the MongoDB console using an Alibaba Cloud account. Resource Access Management (RAM) users do not have the permission to manage or use tags.

## Procedure

1.  Log on to the [MongoDB console](https://mongodb.console.alibabacloud.com/).
    
2.  In the navigation pane on the left, click **Replica Set Instances** or **Sharded Cluster Instances** based on the instance type.
    
3.  In the upper-left corner of the page, select the resource group and region where the instance is located.
    
4.  At the top of the page, click **Filter by Tag**. Select a **tag key** and a **tag value**.
    
    **Note**
    
    -   After you create a new tag or update an existing one, refresh the page to view the updated tag in the tag list.
        
    -   To clear the filter criteria, click the ![关闭](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4169027661/p67173.png) icon next to the selected tag.
        
    -   To filter by multiple tags, repeat Step 5.
        
    
5.  Click **Search**.
