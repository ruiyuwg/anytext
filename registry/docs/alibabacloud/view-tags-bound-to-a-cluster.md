This topic describes how to view the tags that are bound to a PolarDB cluster. You can view the tags on the Clusters page of the console.

## Procedure

1.  Log on to the [PolarDB console](https://polardb.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, click **Clusters**.
    
3.  In the top navigation bar, select the region in which the cluster that you want to manage is deployed.
    
4.  On the **Clusters** page, move the pointer over the ![More](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4803222061/p74099.png) icon in the **Tag** column of the target cluster.
    
5.  View the tags that are bound to the target cluster.
    
    ![View bound tags](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3432729951/p74150.png)
