This topic provides answers to some frequently asked questions about the billing for the monitoring and alerting of Simple Log Service.

## **How am I billed for the monitoring and alerting of Simple Log Service?**

You are charged for alert notifications only if the notifications are sent by text message or voice call. You are not charged for storage or active shards. For more information, see [Billing method](/help/en/sls/user-guide/the-alerting-feature-of-log-service#section-cpi-e6c-afo).

## **Am I charged if a voice call is not answered and I receive a text message?**

You are charged only once for a voice call regardless of whether the call is answered. You are not charged for the text message.

## **Am I charged only once if I receive an alert notification that is sent to me in two text messages?**

Yes, you are charged only once in this scenario. If a text message exceeds 70 characters in length, the text message is split into two messages when the message is sent. In this case, you are charged for only one text message.
