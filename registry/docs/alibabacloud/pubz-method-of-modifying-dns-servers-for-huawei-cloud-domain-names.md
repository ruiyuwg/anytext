This topic describes how to configure the DNS servers for domain names registered with Huawei Cloud to use Alibaba Cloud DNS.

## **Configuration Method**

1.  Log on to the [Huawei Cloud Domain Name Registration console](https://console.huaweicloud.com/domain/?#/domain/list).
    
2.  On the **Domain Names List** tab, click the **More** button next to the target domain name, then select **Manage**.
    
3.  On the **Domain Name Information** tab, in the **Basic Information** section, click the **Modify** button next to **DNS Servers**.
    
4.  In the **Modify DNS Servers** dialog box, replace the existing DNS server names with the DNS server names allocated by Alibaba Cloud DNS. Click **OK** to save the settings.
    
    **Note**
    
    If you do not know the DNS server names allocated by Alibaba Cloud DNS, for more information, see [View DNS Server Addresses for Domain Names](/help/en/dns/pubz-view-dns-server-status-and-exception-handling#2977dbc544lrs).
    
5.  After you complete the configuration, wait for the DNS server changes to take effect. Global propagation typically takes up to 48 hours.
