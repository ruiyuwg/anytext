## Request parameters

**Parameter**

**Type**

**Required**

**Description**

**Example**

AppType

string

No

The type of the application. Valid values:

-   WebApp
    
-   NativeApp
    
-   ServerApp
    

If this parameter is empty, the permissions on all types of applications are queried.

WebApp
