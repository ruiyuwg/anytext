The OSS Node.js SDK supports several methods to download files. Choose a download method based on your scenario:

-   To download a file to a local file or to local memory, see [Download to a local file (Node.js SDK)](/help/en/oss/developer-reference/download-objects-as-files-7) and [Download to local memory (Node.js SDK)](/help/en/oss/developer-reference/download-objects-to-the-local-memory-1).
    
-   To process data incrementally as a file downloads, use a streaming download. For more information, see [Streaming download (Node.js SDK)](/help/en/oss/developer-reference/streaming-download-2).
    
-   To download only part of a file, use a range download. For more information, see [Range download (Browser.js SDK)](/help/en/oss/developer-reference/range-download-3#concept-2166799).
    
-   To restrict a download based on specific conditions, use a conditional download. For example, you can download only files modified before a specific time or files that match a specific ETag. For more information, see [Conditional download (Browser.js SDK)](/help/en/oss/developer-reference/conditional-download-3#concept-2166878).
