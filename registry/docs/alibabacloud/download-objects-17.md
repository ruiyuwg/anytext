The OSS C SDK supports the following download methods:

-   [Download to a local file (C SDK)](/help/en/oss/developer-reference/download-objects-as-files-5#concept-90267-zh)
    
-   [Download to memory (C SDK)](/help/en/oss/developer-reference/download-objects-to-the-local-memory#concept-90280-zh)
    
-   [Range download](/help/en/oss/developer-reference/perform-range-download#concept-90282-zh)
    
-   [Resumable download (C SDK)](/help/en/oss/developer-reference/perform-resumable-download#concept-90283-zh)
    

You can also view the download progress using the [progress bar chart](/help/en/oss/developer-reference/progress-bars-2#concept-90284-zh) feature. For the complete sample code, see [GitHub](https://github.com/aliyun/aliyun-oss-c-sdk/blob/master/oss_c_sdk_sample/oss_progress_sample.c).
