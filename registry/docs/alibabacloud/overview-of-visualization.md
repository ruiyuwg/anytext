Simple Log Service provides the visualization feature that converts raw log data generated by systems, applications, or services into charts. You can define different types of charts based on your business requirements and save the charts to dashboards. In addition, you can connect Simple Log Service to external visualization tools.

## Visualization methods

The following table describes the visualization methods that are supported.

**Visualization method**

**Description**

Dashboard

A dashboard is a data visualization tool provided by Simple Log Service. It typically includes multiple statistical charts that summarize and present key performance indicators, important data, and analysis results. When you open or refresh a dashboard, the query statement for each chart on the dashboard is automatically executed.

Chart

A chart displays the rendered result of data that is returned by query statements. Simple Log Service provides multiple types of charts, including tables, line charts, and column charts. Simple Log Service provides two versions of charts: Pro and standard.

-   Pro: This version can display the results of multiple query statements and allows you to configure personalized display settings for the results of each query statement. For more information, see [Overview of charts (Pro)](/help/en/sls/user-guide/overview-of-charts#concept-2142173).
    
-   Standard: You can upgrade this version to the Pro version with a few clicks. For more information, see [Chart overview](/help/en/sls/chart-overview#concept-q3w-zmq-zdb).
    

**Important** Before you can obtain a chart based on log data and add the chart to a dashboard, you must store the data in a Standard Logstore. For more information, see [Manage a Logstore](/help/en/sls/manage-a-logstore#concept-xkb-zh5-vdb).

External visualization tool

You can connect Simple Log Service to external visualization tools, such as DataV, Grafana, and Tableau, to display data on dashboards.

## Limits

The following table describes the limits of the visualization feature.

**Visualization method**

**Description**

Dashboard

You can create up to 100 dashboards for a project.

Chart

You can add up to 200 charts to a dashboard.
