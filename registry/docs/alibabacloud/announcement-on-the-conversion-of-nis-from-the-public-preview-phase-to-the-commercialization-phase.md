Dear Alibaba Cloud customers:

Since the release of Network Intelligence Service (NIS)(public preview) in 2022, NIS has served as a centralized self-service platform for cloud network O&M to help you use and maintain cloud networks more simply and efficiently. Based on O&M solutions of Alibaba Cloud experts for cloud networks in multiple scenarios such as network diagnosis, network monitoring, and network insights, NIS has gradually released features including instance diagnosis, reachability analyzer, network topology, traffic analysis, event center, and network inspection, which served numerous cloud customers. After continuous refinement, NIS plans to end its public preview phase and officially release its commercial version on April 1, 2025.

## **Commercialization date**

April 1, 2025 (UTC+8)

## **Commercial features**

After NIS is commercially released, [traffic analysis (public review)](/help/en/nis/user-guide/flow-analysis-overview/) will be upgraded to [traffic analyzer (commercial version)](/help/en/nis/user-guide/traffic-analyzer/), which will be billed. For more information, see [Billing rules](/help/en/nis/product-overview/billing-method-new-version). Traffic analysis (public preview) will be gradually retired. Other NIS features will continue to be provided free of charge.

## **Retirement of traffic analysis (public preview)**

As an upgraded version of the traffic analysis feature, traffic analyzer supports analyzing virtual private cloud (VPC) traffic and Internet traffic, and will gradually replace all features of traffic analysis (public preview). Traffic analysis (public preview) will no longer be evolved. If you want to activate VPC and Internet traffic analysis services, we recommend that you use traffic analyzer. If you have activated Internet traffic analysis (public preview), we recommend that you migrate the public preview version to the commercial version. For more information, see [Migrate traffic analysis from the public preview version to the commercial version](/help/en/nis/user-guide/traffic-analysis-migration-from-the-public-preview-edition-to-the-commercial-edition/).

-   From April 16, 2025 00:00:00 (UTC+8), traffic analysis (public preview) will no longer be activated in all regions for all Alibaba Cloud accounts.
    
-   From June 30, 2025 00:00:00 (UTC+8), traffic analysis (public preview) is stopped. All existing traffic analysis (public preview) services in all regions will be terminated, all traffic analysis data will be deleted, and the business of traffic analysis (public preview) in the NIS console and OpenAPI will be completely retired.
