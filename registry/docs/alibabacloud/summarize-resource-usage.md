Alibaba Cloud CDN allows you to summarize resource usage data of all your accelerated domain names by day or by month. Usage data is categorized based on billable items and exported to a PDF file.

## Summarize usage data by day or by month

**Note** You can query usage data up to the last 12 months.

-   Summarize usage data by day: You can query usage data of the current day or a day within the last 355 days.
-   Summarize usage data by month: You can query usage data of the current month or a month within the last 11 months.

1.  Log on to the [Alibaba Cloud CDN](https://cdn.console.alibabacloud.com) console.
    
2.  In the left-side navigation pane, click **Usage**.
    
3.  On the **Billable Items** tab, select **Select Date** or **Select Month**, select a date or a month, and then click **Search**.
    
    ![Query usage data](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/6919786761/p365732.png)
