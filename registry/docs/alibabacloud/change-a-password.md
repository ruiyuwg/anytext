If you are a CloudSSO user, you can change your password in the CloudSSO user portal. A password is valid for 90 days. To ensure data security, we recommend that you regularly change your password.

## Methods to change a password

To change the password of a CloudSSO user, use the following methods provided by CloudSSO:

-   If you are a CloudSSO administrator, you can change the password of a CloudSSO user in the CloudSSO console.
    
    A CloudSSO administrator can reset the password of a CloudSSO user in the CloudSSO console. This is suitable for scenarios in which a user forgot the password, the password is expired, or the password may pose security risks. For more information, see [Reset the password of a user](/help/en/cloudsso/user-guide/perform-basic-operations#section-7w1-rpd-24k).
    
-   If you are a CloudSSO user, you can change your password in the CloudSSO user portal.
    
    In the following scenarios, you can change your password in the CloudSSO user portal:
    
    -   Your password is about to expire within 20 days. Each time you log on to the CloudSSO user portal, the system prompts you to change the password. You can ignore the prompt. However, we recommend that you change the password at the earliest opportunity. When you change the password, you need only to enter the new password.
        
    -   The first time you log on to the CloudSSO user portal, you must change your password. A CloudSSO administrator can configure system settings to require password changing the first time a user logs on.
        
    -   To ensure data security, we recommend that you regularly change your password. In this scenario, you must enter both the previous and new passwords. This topic describes how to change the password the first time you log on to the CloudSSO user portal.
        
    

## Procedure

1.  Log on to the CloudSSO user portal by using the username-password logon method.
    
    For more information, see [Log on to the CloudSSO user portal and access Alibaba Cloud resources](/help/en/cloudsso/user-guide/log-on-to-the-cloudsso-user-portal-and-access-alibaba-cloud-resources#task-2090790).
    
2.  Move the pointer over your profile picture in the upper-right corner of the page and click **Change Password**.
    
3.  On the **Change Password** page, enter the old password and a new password, and click **Confirm**.
    
    The new password must comply with the password policy that is configured by the CloudSSO administrator. For more information, see [Configure a password policy](/help/en/cloudsso/user-guide/set-password-policy).
