Alibaba Cloud updates and releases public image versions on a regular basis. The versions may include the latest operating system features, performance optimizations, updates to basic software packages, and security patches. This topic describes the available versions of Edge Node Service (ENS) public images.

## **Public images**

**Note**

-   Public images are available only for x86-based computing instance families.
    
-   Alibaba Cloud may no longer provide technical support for specific services for a variety of reasons, such as end of lifecycle (EOL) of services, end of third-party support, or open source projects. You need to take note of the lifecycle plans of the operating systems contained in images that you use to create ENS instances. You can visit the official websites of the operating systems to obtain their lifecycle plans. This helps you update your instances to stable operating system versions at the earliest opportunity.
