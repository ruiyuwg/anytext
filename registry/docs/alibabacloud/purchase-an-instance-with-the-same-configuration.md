You can use the **Buy Same Specifications** feature in the Elastic Compute Service (ECS) console to go to the instance buy page and quickly create ECS instances that have the same configurations as an existing ECS instance, including the instance type, disk settings, image, and bandwidth settings and excluding the environment settings and data. Alternatively, you can modify instance parameters on the instance buy page to create ECS instances.

## Prerequisites

(Optional) If you want to purchase an ECS instance within the Chinese mainland, you must complete **account verification**. For more information, see [When is identity verification required?](/help/en/account/support/which-users-are-required-to-undergo-account-authentication#h2--3)

## Procedure

1.  Go to [ECS console - Instances](https://ecs.console.alibabacloud.com/server/region).
    
2.  In the top navigation bar, select the region and resource group of the resource that you want to manage. ![地域](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8343404471/p680076.png) 
    
3.  Click the ID of the target instance to go to the instance details page, click **All Actions** in the upper-right corner to expand the **All Actions** pane, and then find and click **Buy Same Specifications**.
    
4.  Confirm whether to modify the configurations.
    
    -   If you do not want to modify the configurations, read and select **ECS Terms of Service | Product Terms of Service** and click **Buy Now**.
        
    -   If you want to modify the configurations, click **Modify Configurations on Buy Page** and then modify the configurations on the [Custom Launch tab of the instance buy page](/help/en/ecs/user-guide/create-an-instance-by-using-the-wizard).
        
        In the right-side pane, confirm the configurations, specify parameters such as the duration, and then click **Create Order**.
        

## Reference

You can use a launch template to create ECS instances that have the same configurations. For more information, see [Create an instance by using a launch template](/help/en/ecs/user-guide/create-an-instance-by-using-a-launch-template).
