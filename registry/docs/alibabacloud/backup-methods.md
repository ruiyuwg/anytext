PolarDB provides backup solutions. You can modify the backup policy of your cluster based on your business requirements while ensuring data reliability.

## **View backups**

1.  Log on to the [**PolarDB console**](https://polardb.console.alibabacloud.com/). In the left-side navigation pane, click **Clusters**. In the upper-left corner of the page, select the region in which the cluster resides and find the cluster in the list.
    
2.  In the left-side navigation pane, select **Settings and Management** > **Backup and Restoration** to view backups.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/7857949471/p964884.png)
    

## Modify the automatic backup policy

1.  Log on to the [**PolarDB console**](https://polardb.console.alibabacloud.com/). In the left-side navigation pane, click **Clusters**. In the upper-left corner of the page, select the region in which the cluster resides and find the cluster in the list.
    
2.  In the left-side navigation pane, select **Settings and Management** > **Backup and Restoration**.
    
3.  On the **Backup Policy Settings** tab, click **Modify**.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/7857949471/p964916.png)
    
4.  In the **Backup Policy Settings** dialog box, configure the parameters in the **Data Backup**, **Log Backup**, and **General** sections. For more information, see [Configure backup policy settings](/help/en/polardb/polardb-for-mysql/user-guide/configure-backup-settings#task-2122812).
    
5.  After you complete the backup settings, click **OK**.
    

## **Manually create backups**

1.  Log on to the [**PolarDB console**](https://polardb.console.alibabacloud.com/). In the left-side navigation pane, click **Clusters**. In the upper-left corner of the page, select the region in which the cluster resides and find the cluster in the list.
    
2.  In the left-side navigation pane, select **Settings and Management** > **Backup and Restoration**.
    
3.  On the **Data Backups** tab, click **Create Backup**.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/7857949471/p964912.png)
    
4.  In the dialog box that appears, click **OK**.
    

## **Delete backups**

-   You can delete only manual backup sets.
    
-   Automatic backup sets cannot be manually deleted. You can modify the retention period of automatic backup sets. For more information, see [Configure backup policy settings](/help/en/polardb/polardb-for-mysql/user-guide/configure-backup-settings#46fff911d6c2d).
