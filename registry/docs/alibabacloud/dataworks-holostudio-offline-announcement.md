Dear DataWorks users:

To provide better development experience, Alibaba Cloud plans to integrate **HoloStudio** into **DataStudio**. From **February 29, 2024**, HoloStudio will stop providing services, and you can use DataStudio to perform Hologres-related development operations. DataStudio allows you to migrate existing files in HoloStudio to DataStudio. For more information, see [Migrate files from HoloStudio to DataStudio](/help/en/dataworks/user-guide/migrate-holostudio-tasks-to-datastudio).

### Precautions

-   Before **February 29, 2024**, you can still create and update files in HoloStudio. You can also manually migrate existing files in HoloStudio to DataStudio with a few clicks.
    
-   From **March 26, 2024**, HoloStudio will no longer provide services. If you do not manually migrate files in HoloStudio to DataStudio before this day, the development results in HoloStudio will be automatically migrated to DataStudio based on the [default migration logic](/help/en/dataworks/user-guide/migrate-holostudio-tasks-to-datastudio#43f5886142qg6).
