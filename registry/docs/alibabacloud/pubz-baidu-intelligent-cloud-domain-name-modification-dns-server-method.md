This topic describes how to configure the DNS server of a domain name registered with Baidu Intelligent Cloud to Alibaba Cloud DNS.

## **Configuration method**

1.  Log on to the [Baidu Intelligent Cloud Domain Name Service Console](https://console.bce.baidu.com/bcd/?#/bcd/manage/list).
    
2.  On the **Domain Management** page, click the **More Operations** button next to the target domain name, and then select **Domain Information**.
    
3.  In the **Basic Information** section, click the **DNS Server** **Modify DNS** button.
    
4.  On the DNS server modification page, select **Use Custom DNS Server**, enter the DNS server names allocated by Alibaba Cloud DNS, and then click **OK**.
    
    **Note**
    
    If you do not know the DNS server names allocated by the Alibaba Cloud DNS system, you can refer to [View DNS server status](/help/en/dns/pubz-view-dns-server-status-and-exception-handling#2977dbc544lrs).
    
5.  After the configuration is complete, please wait patiently for the DNS server configuration to take effect. The global propagation typically requires 48 hours.
