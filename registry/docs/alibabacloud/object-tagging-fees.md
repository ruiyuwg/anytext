Object Storage Service (OSS) charges fees for each tag added to objects in your bucket.

**Note**

This topic describes the billable items and billing methods for object tagging. For pricing details, see the [OSS pricing](https://www.alibabacloud.com/product/oss/pricing) page.

**Billing rule**

**Billing cycle**

**Billing method**

Object tagging

Charged based on the total number of tags on objects in your bucket.

Hourly. Bills are generated after each billing cycle ends. The exact generation time is determined by the system.

**Pay-as-you-go:** Tagging fees = Number of tags per hour × Unit price per month ÷ 30 (days) ÷ 24 (hours) ÷ 10,000

Resource plans are not supported for object tagging fees.
