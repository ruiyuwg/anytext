Elastic Desktop Service convenience accounts support organizations. You can add convenience accounts to organizations to manage personnel and permissions in a centralized manner. This topic describes how to create an organization.

## Procedure

1.  Log on to the [Elastic Desktop Service console](https://eds.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, choose **Users & Logons** > **Users & Organizations**.
    
3.  On the **Users & Organizations** page, click **Create Organization** on the **Organization** tab.
    
4.  In the **Create Organization** dialog box, enter an organization name, select the parent organization to which the organization belongs, and then click **Confirm**.
    
    **Note**
    
    The root organization is `Organization Structure`, which can be the parent organization if this is the first time you create an organization. When you create an organization for the first time, you can only use it as a parent organization.
    
    The organization that you have created is displayed in the left-side navigation tree on the **Organization** tab.
    

## **What to do next**

-   After you create the organization, you can add convenience users to the organization. For more information, see [Manage convenience users](/help/en/wuying-workspace/user-guide/manage-convenience-users-1).
    
-   If you want to change the name of the organization, click **Edit** in the **Actions** column and enter a new name.
    
-   If you want to adjust the organizational hierarchy, click **Move** in the **Actions** column to select a new parent organization.
    
-   If you want to delete the organization, make sure that no convenience users are in the organization and its child organizations. Then, click Delete in the **Actions** column. You can also select the Forcefully Delete Child Organization check box when you delete the organization.
