This product(`Sts/2015-04-01`) OpenAPI adopts RPC Signature style. See signature details in [Description of the signature mechanism](/help/en/sdk/product-overview/request-structure-and-signature/). We have packaged SDKs for common programming languages for developers. Developers can directly call the OpenAPI of this product by [downloading the SDK](https://api.alibabacloud.com/api-tools/sdk/Sts?version=2015-04-01) without paying attention to the technical details. If the existing SDK cannot meet the usage requirements, you can connect through the signature mechanism. It will take about 5 working days. Therefore, it is recommended to join our DingTalk service group (78410016550) and sign under the guidance of experts.

Before using the API, you need to prepare your identity account and access key (AccessKey) to effectively access the API through client tools (SDK, CLI, etc.). For details see [getAccessKey](/help/en/ram/user-guide/create-an-accesskey-pair).
