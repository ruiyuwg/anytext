Alibaba Cloud Linux 4 LTS 64-bit Deb Edition is the first long-term support (LTS) version in the Alibaba Cloud Linux series to be compatible with the Debian software ecosystem. It is compatible with Ubuntu 24.04 packages and toolchains and provides a consistent support lifecycle to ensure a stable and reliable technology evolution path.

## **Pre-configured software**

1.  Pre-installed `kmod-fuse`. This enhances support for fuse over io\_uring mode and large folio. It achieves one million input/output operations per second (IOPS) and 40 GB/s cache read/write bandwidth.
    
2.  Pre-installed `keentune`. This is a performance tuning product developed by Alibaba Cloud. It uses both expert knowledge and AI algorithms to provide performance tuning for AI scenarios.
    

## Benefits

1.  The user mode packages of Alibaba Cloud Linux 4 LTS 64-bit Deb Edition are compatible with Ubuntu 24.04. You can use packages from Ubuntu 24.04 on this operating system.
    
2.  Provides greater stability than community operating systems. The kernel includes essential hotpatching capabilities.
    
3.  AI-accelerated kernel. The kernel features optimized I/O scheduling and management for deep learning training and inference. It works with Alibaba Cloud AI container images to deliver end-to-end performance improvements.
    
4.  Intelligent tuning with keentune. This out-of-the-box tuning framework for AI scenarios uses automated policies for compatibility across multiple scenarios and simplified operation. It includes pre-configured tuning templates for common AI scenarios, such as deep learning training and real-time inference. You can trigger the tuning process with a single click to reduce complexity.
    

## Billing

Alibaba Cloud Linux 4 LTS 64-bit Deb Edition is a free image. When you use this image to create an Elastic Compute Service (ECS) instance, you are charged for other resources, such as vCPUs, memory, storage, public bandwidth, and snapshots. For more information, see [Billing overview](/help/en/ecs/billing-overview#concept-isb-scd-5db).

## **Scenarios**

This image is compatible with Ubuntu 24.04 and provides enhanced system stability, making it ideal for business scenarios that require high reliability. The image also provides significant performance improvements for workloads that are sensitive to memory allocation latency.

## Instructions

For the scenarios described above, you can select Alibaba Cloud Linux 4 LTS 64-bit Deb Edition as the OS image. For more information, see [Quickly purchase a subscription instance](/help/en/ecs/user-guide/create-a-subscription-instance-on-the-quick-launch-tab).
