This topic provides answers to some frequently asked questions about the use of the Secure Access Service Edge (SASE) client.

## How do I upload logs if an error occurs when I use the SASE desktop client?

If an error occurs before or after you log on to the SASE client, you can click **Feedback** to upload logs.

Before logon:

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/5105620371/p865633.png)

After logon:

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/5105620371/p865635.png)

You can view the error codes of the SASE client to identify possible causes and obtain solutions. For more information, see [Network diagnosis-related error codes of the SASE client](/help/en/sase/user-guide/error-codes-of-sase-client).
