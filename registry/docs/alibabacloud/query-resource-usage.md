Alibaba Cloud allows you to export the usage details of Simple Log Service resources. This topic describes how to query the usage details of Simple Log Service resources.

## Procedure

1.  Log on to the [Expenses and Costs console](https://usercenter2-intl.console.alibabacloud.com/billing/#/account/overview).
    
2.  In the left-side navigation pane, choose **Bills > Bill Details**.
    
3.  On the **Usage Records** page, set the parameters as listed in the following table.
    
    **Parameter**
    
    **Description**
    
    **Product**
    
    Select **sls**.
    
    **Billable Item**
    
    Select **Simple Simple Log Service (SLS)**.
    
    **Time Period**
    
    Select the time range for the query.
    
    You can query the resource usage of at most one calendar month at a time. For example, if you set the start time to 2022-02-01, the latest end time that you can specify for the time range is 2022-02-28. You cannot select 2022-03-01 as an end time.
    
    **Time Unit**
    
    Select **Hour**.
    
4.  Click **Export CSV**.
    
    After you export the CSV file, you can download the file to a local directory and view the usage details of Simple Log Service resources.
