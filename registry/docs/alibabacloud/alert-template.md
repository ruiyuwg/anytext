Simple Log Service sends alert notifications based on the content that is specified in alert templates.

-   [Create an alert template](/help/en/sls/create-an-alert-template): Outlines the steps to create an alert template.
    
-   [Default alert templates](/help/en/sls/default-alert-templates): If you do not configure the Content parameter for an alert template, Simple Log Service uses the content of the default alert template based on the notification method that you specify.
    
-   [Custom notification content](/help/en/sls/custom-notification-content): Simple Log Service allows you to customize notification content when you configure an alert template.
    
-   [Syntax for new alert templates](/help/en/sls/syntax-for-new-alert-templates): The syntax for the new alert templates is fully compatible and can be used with the syntax for the original alert templates. However, the syntax for the new alert templates uses different types, values, and styles for alert attributes than the syntax for the original alert templates. Therefore, we recommend that you do not simultaneously use the syntax for the new alert templates and the syntax for the original ones.
    
-   [Built-in functions in alert templates](/help/en/sls/built-in-functions-in-alert-templates): You can use the built-in functions of the new templates to configure the formats and styles of alert notifications.
    
-   [Variables in new alert templates](/help/en/sls/variables-in-new-alert-templates): Introduces the variables that are available for use in the new alert templates and the methods you can use to reference the variables.
    
-   [Variables in original alert templates](/help/en/sls/variables-in-original-alert-templates): Introduces the variables that are available for use in the original alert templates and the methods you can use to reference the variables.
