    -   [Backup features of an ApsaraDB RDS for PostgreSQL instance](/help/en/doc-detail/444451.html) and [Overview of data restoration methods](/help/en/doc-detail/444453.html)
        
    -   [Methods to back up an ApsaraDB RDS for MariaDB instance](/help/en/doc-detail/444456.html) and [Restore data](/help/en/rds/apsaradb-rds-for-mariadb/restore-the-data-of-an-apsaradb-rds-for-mariadb-instance)
