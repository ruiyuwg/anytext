Intelligent Media Management (IMM) can be used for document format conversion and preview, image content recognition, face detection, and quick response (QR) code detection.

## Prerequisites

An Alibaba Cloud account is created and has passed real-name verification. If you have not created an Alibaba Cloud account, create one as prompted when you activate IMM. For more information, see [Sign up to Alibaba Cloud](https://account.alibabacloud.com/register/intl_register.htm?spm=a2c44.29466963.0.0.e6935455HGOXYu).

## Procedure

1.  Go to the [IMM product page](https://www.alibabacloud.com/en/product/imm?_p_lc=1).
    
2.  Click **Activate Now**.
    
3.  On the **Intelligent Media Management** page, read and agree to **Intelligent Media Management Terms of Service**, and then click **Activate Now**.
    
    After you activate IMM, click the [Alibaba Cloud Management Console](https://imm.console.alibabacloud.com/) to go to the IMM console.
    
    You can also click **Console** in the upper-right corner of the home page of the Alibaba Cloud official website to go to the Alibaba Cloud Management Console, click the ![fig_tablestore_control_001](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0984692951/p96140.png) icon, and then choose **Products** > **Intelligent Media Management** in the navigation pane to go to the IMM console.
