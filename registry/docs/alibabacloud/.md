Reserves an IPv6 CIDR block.

## Operation description

# [](#)[](#)

The following section describes how to allocate an IPv6 CIDR block to a virtual private cloud (VPC):

1.  Call the AllocateVpcIpv6Cidr operation to reserve the IPv6 CIDR block.
2.  To allocate an IPv6 CIDR block to an existing VPC, call the [AssociateVpcCidrBlock](/help/en/vpc/api-associatevpccidrblock) operation. Set **RegionId**, **VpcId**, and **IPv6CidrBlock** to the IPv6 CIDR bock, and set **IpVersion** to **ipv6**. To allocate an IPv6 CIDR block when you create a VPC, call the [CreateVpc](/help/en/vpc/api-createvpc) operation. Set **RegionId** and **Ipv6CidrBlock** to the IPv6 CIDR block, and set **EnableIpv6** to **true**.
