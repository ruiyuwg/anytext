DataWorks Open API provides more than 100 APIs that enable you to perform batch operations and system integrations to boost data development efficiency. You can call these APIs to access various features and integrate your applications with the DataWorks service.

Through the Open Platform, you can monitor your API usage at a glance, including free quota consumption, call volumes, and call logs. For details, see [DataWorks Open API overview](/help/en/dataworks/developer-reference/use-dataworks-openapi).

## Edition requirements

To use a specific Open API, your DataWorks edition must support the corresponding feature module (e.g., Tenant, Metadata, Data Studio).

-   Each edition has specific daily call limits. For details, see [Use Open API](/help/en/dataworks/developer-reference/use-dataworks-openapi#section-noi-w5e-8xv).
    
-   Each edition includes a monthly free quota. Calls that exceed the free quota are billed on a pay-as-you-go basis. For details, see [Free quota and billing methods](/help/en/dataworks/developer-reference/use-dataworks-openapi#9043e6a325tiq).

## View Open API usage

To view your API usage statistics, follow these steps:

1.  Log on to the [DataWorks console](https://dataworks.console.aliyun.com/overview).
    
2.  In the top navigation bar, select the desired region.
    
3.  In the left-side navigation pane, choose **More** > **Open Platform**.
    
4.  On the page that appears, click **Go to Open Platform**. The **Developer Backend** tab appears.
    

This page displays your API usage statistics and best practices.

![OpenAPI](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2168841371/p521502.png)

### Usage metrics

The Open API page details your usage in the following sections:

**Metric**

**Description**

**Open API free quota**

Displays your free quota usage for the current calendar month. Once the free quota is exhausted, pay-as-you-go billing applies.

**Open API call count**

The total number of API calls made month-to-date. This counter resets on the first day of each month.

**Open API call details**

Detailed logs of your API calls, including date, API category, and daily/monthly totals. You can filter results by API type.
