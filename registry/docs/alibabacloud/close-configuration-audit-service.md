If you no longer need Cloud Config to evaluate resource compliance, you can deactivate Cloud Config.

**Important**

After you deactivate Cloud Config, the resource configurations, created rules, and compliance evaluation results that are stored in Cloud Config are automatically cleared and cannot be restored. Proceed with caution.

## **Prerequisites**

-   Make sure all account groups are deleted from your management account. For information about how to delete account groups, see [Delete an account group](/help/en/cloud-config/latest/delete-an-account-group#task-2068260).
    
-   Make sure that all members are removed from the account groups by using your management account. For information about how to remove member accounts from an account group, see [Modify an account group](/help/en/cloud-config/latest/modify-an-account-group#task-2068150).
    

## Procedure

1.  Log on to the [Cloud Config console](https://confignew.console.alibabacloud.com).
    
2.  Deactivate Cloud Config.
