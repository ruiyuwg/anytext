-   For more information about how to obtain an AccessKey pair, see [Create an AccessKey pair](/help/en/ram/user-guide/create-an-accesskey-pair#task-2245479).
    
-   For more information about Resource Directory API operations, see [List of operations by function](/help/en/resource-management/resource-directory/developer-reference/api-resourcedirectorymaster-2022-04-19-overview).
