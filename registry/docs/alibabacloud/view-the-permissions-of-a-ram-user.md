This topic describes how to view the permissions of a Resource Access Management (RAM) user, including policies attached directly to the user and policies inherited from user groups.

## View policies attached directly to a RAM user

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) with an Alibaba Cloud account.
    
2.  In the left-side navigation pane, choose **Identities** > **Users**.
    
3.  On the **Users** page, click the username of the target RAM user.
    
4.  Click the **Permissions** tab.
    
5.  On the **Individual** tab, view the list of policies attached directly to the user.
    

## View policies inherited from user groups

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) with an Alibaba Cloud account.
    
2.  In the left-side navigation pane, choose **Identities** > **Users**.
    
3.  On the **Users** page, click the username of the target RAM user.
    
4.  Click the **Permissions** tab.
    
5.  Click the **Group Permissions** tab to view the policies that the user inherits from the groups they belong to.
