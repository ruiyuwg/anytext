**CloudOps Orchestration Service (OOS)** is an automated O&M service provided by Alibaba Cloud to help you manage and execute O&M tasks in the cloud. You can create templates to define O&M tasks, the execution sequence of the tasks, input parameters, and output parameters, and use the templates to automatically execute the tasks. OOS can be used to manage diverse Alibaba Cloud services, such as Elastic Compute Service (ECS), ApsaraDB RDS, Server Load Balancer (SLB), and Virtual Private Cloud (VPC).

## Execution modes

OOS supports automated, semi-automated, and interactive execution modes to help you execute diverse O&M tasks.

## Scenarios

You can use OOS to manage repeated, event-driven, scheduled, and cross-region O&M tasks. It also allows you to easily handle multiple O&M tasks at a time and manage approval requests. OOS also serves as a standardization platform for O&M tasks and allows you to create templates from O&M manuals, operation manuals, and maintenance manuals based on best practices of operations as code.

## Billing

OOS is free of charge. However, if you use OOS to create a cloud service resource that needs to be paid, you are charged based on the billing rules of the cloud service. For more information, see the pricing of relevant cloud services.
