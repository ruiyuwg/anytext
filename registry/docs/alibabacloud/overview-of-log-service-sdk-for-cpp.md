Simple Log Service SDK for C++ allows you to call the API operations of Simple Log Service in C++ programs. This SDK applies only to Linux platforms.

## Release notes

For more information, see [Alibaba Cloud Simple Log Service SDK for C++ Releases](https://github.com/aliyun/aliyun-log-cpp-sdk/releases).
