CloudMonitor Basic adjusted the free quotas and billing methods from 10:00:00 (UTC+8) on September 26, 2024.

The following items show the changes:

-   Alert text messages and alert phone calls
    
    -   Only mobile phone numbers with country code 86 support alert text messages and alert phone calls. The free quota of alert text messages is 1,000 per month, and no free quota is available for alert phone calls.
        
    -   If the preceding free quota does not meet your requirements, you can activate CloudMonitor Basic (pay-as-you-go). For more information about the pay-as-you-go billing method, see [Pay-as-you-go](/help/en/cms/cloudmonitor-1-0/product-overview/pay-as-you-go-1).
        
    -   After you activate CloudMonitor Basic (pay-as-you-go), you can purchase resource plans. For more information about the resource plans of CloudMonitor Basic, see [Resource plans](/help/en/cms/cloudmonitor-1-0/product-overview/resource-plan-2).
        
    
    **Note**
    
    If you have been added to a whitelist for using alert text messages, the free quota of alert text messages is changed to 1,000 per month. If the free quota does not meet your requirements, you must activate CloudMonitor Basic (pay-as-you-go). Otherwise, alert text messages can no longer be used after the free quota is used up.
    
-   Dynamic threshold
    
    -   You are charged for using the dynamic threshold feature after the public preview ends. For more information about the billing of the dynamic threshold feature, see [Pay-as-you-go](/help/en/cms/cloudmonitor-1-0/product-overview/pay-as-you-go-1).
        
    -   The dynamic threshold-based alert rules created during public preview are automatically disabled. If you want to continue using the dynamic threshold feature, you must activate CloudMonitor Basic (pay-as-you-go) or enable Free Trial on Dynamic Threshold in Trial Center. For more information, see [Pay-as-you-go](/help/en/cms/cloudmonitor-1-0/product-overview/pay-as-you-go-1).
        
-   API calls for metric data query
    
    -   CloudMonitor Basic changed the free quota of API calls for metric data query from 10 million per month to 1 million per month from 00:00:00 (UTC+8) on October 1, 2024. If the free quota is used up, the data query APIs can no longer be called as expected.
        
        **Important**
        
        -   If the free quota of API calls for metric data query is used up, resolve the issue by referring to [How do I fix the issue that the quotas of CloudMonitor are insufficient?](/help/en/cms/cloudmonitor-1-0/support/fix-the-issue-of-insufficient-cloudmonitor-quota)
            
        -   If the free quota is used up, throttling is triggered. As a result, the monitoring data of the related cloud service cannot be displayed properly. For more information about how to resolve the issue that the free quota is used up or is about to be used up, see [How do I fix the issue that the API quota has been exhausted or is about to be exhausted?](/help/en/cms/cloudmonitor-1-0/support/fix-the-issue-that-the-api-quota-has-been-exhausted-or-is-about-to-be-exhausted)
            
        
    -   If the preceding free quota does not meet your requirements, you can activate CloudMonitor Basic (pay-as-you-go). For more information about the pay-as-you-go billing method for the API calls for metric data query, see [Pay-as-you-go](/help/en/cms/cloudmonitor-1-0/product-overview/pay-as-you-go-1).
