Get a Lindorm instance up and running by selecting configurations, creating the instance, configuring access control, and connecting to it.

## Select engines and configurations

Before you create a Lindorm instance, select the required configurations based on your business scenarios, access loads, access mode, and capacity. For more information, see [Select configurations for a Lindorm instance](/help/en/lindorm/product-overview/select-configurations-for-a-lindorm-instance#concept-2222545).
