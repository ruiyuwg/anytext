Before you use Cloud Config, you must activate Cloud Config. Then, you can obtain resources across regions and perform compliance auditing on the resources.

## Background information

After you activate Cloud Config, Cloud Config obtains only read-only permissions on the resource configurations of the current Alibaba Cloud account. This does not affect the operations of the related Alibaba Cloud services.

## **Procedure**

1.  Log on to the [Cloud Config console](https://confignew.console.alibabacloud.com).
    
2.  Click **Activate Now**.
    
    Alibaba Cloud automatically creates a service-linked role for Cloud Config. The service-linked role is used to obtain access permissions on other Alibaba Cloud services. For more information, see [Manage the service-linked role](/help/en/cloud-config/latest/manage-the-service-linked-role-for-cloud-config).
    
    **Note**
    
    Cloud Config requires 2 to 10 minutes to scan the resources of the current Alibaba Cloud account and generate a resource list.
