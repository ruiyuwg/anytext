ESA provides the following tools: **IP geolocation**, **Violation URL Query**, and **ActionTrail**. These features facilitate point of presence (POP) analysis, real-time content compliance check, and user behavior audit, thereby quickly identifying risks and precisely executing security policies.

## **Features overview**

-   **[IP geolocation](/help/en/edge-security-acceleration/esa/user-guide/ip-attribution-query)**:
    
    After you add a website to Edge Security Acceleration (ESA), you can use the IP geolocation feature to check whether the actual IP address that clients request to access belongs to an ESA point of presence (POP), therefore verifies whether acceleration takes effect.
    
-   **Violation URL Query**: Violation URL Query helps you query URLs of content suspected of violation.
    
-   **ActionTrail**: ActionTrail helps you monitor and record the activities of your Alibaba Cloud account, including access and usage on cloud products and services through the Alibaba Cloud consoles, OpenAPI, and Developer Tools. You can download or save these events to Simple Log Service or Object Storage Service (OSS), and then perform operations such as behavior analysis, security analysis, resource change tracking, and compliance auditing based on the events. For more information, see [What is ActionTrail](/help/en/actiontrail/product-overview/what-is-actiontrail#concept-28804-zh).
