You are charged for pay-as-you-go E-MapReduce (EMR) Serverless StarRocks instances only after you use the instances. Therefore, refunds are not supported for pay-as-you-go instances. Subscription instances are paid based on the subscription period when the instances are created. If you no longer require a subscription instance, you can apply for a refund. This topic describes the refunding rules and methods of subscription instances.

## Refunding rules

You can apply for a refund of a subscription instance. Before you unsubscribe from a subscription instance, make sure that you understand the unsubscription rules, precautions, and unsubscription cases. For more information, see [Rules for unsubscribing from resources](/help/en/user-center/refund-rules#main-2277885).

## Refunding methods

The following table describes the refunding method that corresponds to each billing method.

**Billing method**

**Refunding method**

Subscription

If you no longer require a subscription instance, you can apply for a refund. The system settles payments based on the specifications of the subscription instance that you purchase.

For more information, see [Methods for unsubscribing resources](/help/en/user-center/refund-methods#main-2277947).

Pay-as-you-go

Pay-as-you-go instances are billed only after they are used. Therefore, refunds are not involved. If you no longer require a pay-as-you-go instance, you can release the instance in the EMR console. After the instance is released, you are no longer charged for the instance.
