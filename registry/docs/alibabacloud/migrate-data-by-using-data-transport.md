Data Online Migration is a tunnel between different storage services of Alibaba Cloud. You can use Data Online Migration to migrate data between File Storage NAS (NAS) file systems with ease. This topic describes how to migrate data between NAS file systems by using Data Online Migration.

To migrate data by using Data Online Migration, you only need to log on to the console, specify the address information of the source and destination NAS file systems, and then create a migration job. After the migration job starts, you can manage the job in the console. For example, you can view the progress and traffic information of the job.

## **Procedure**

For information about how to migrate data between NAS file systems, see [Migrate data between local file systems](/help/en/data-online-migration/user-guide/migration-between-localfs-tutorial/).
