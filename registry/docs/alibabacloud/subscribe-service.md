Alibaba Cloud DNS PrivateZone is a shared service. Before you use the service, you must activate the service.

To activate Alibaba Cloud DNS PrivateZone, perform the following steps:

1.  Log on to the [Alibaba Cloud DNS console](https://dc.console.alibabacloud.com/dns/).
    
2.  Go to the **PriviteZone** and click **Activate Now**.
    
3.  View the billing information, read and accept the **Terms of Service**, and click **Activate Now**.
    
4.  After the service is activated, go to the Alibaba Cloud DNS PrivateZone console to use the service.
