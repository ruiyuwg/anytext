This topic describes the simple mode of the Data Management (DMS) console.

## Prerequisites

[DMS](https://dms.aliyun.com/) is activated.

## Benefits

-   The interface is simple, spacious, and easy to navigate.
    
-   You can search for database instances without switching to the console homepage.
    

## Usage notes

-   The DMS console is displayed in simple mode when users log on to it for the first time.
    
-   The DMS console is displayed in normal mode when existing users log on and can be switched to the simple mode.

## Enter the simple mode

1.  Log on to the [DMS console V5.0](https://dms.alibabacloud.com/new).
2.  In the top navigation bar of the homepage, click the ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3767336661/p507061.png) icon to enter the simple mode.
    

## Exit the simple mode

1.  Log on to the [DMS console V5.0](https://dms.alibabacloud.com/new).
2.  In the top navigation bar of the homepage, click the ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3767336661/p507060.png) icon to exit the simple mode.
