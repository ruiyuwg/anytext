This integration ensures the availability of resources, stability of business operations, and overall system health. You can use monitoring services to collect metric data. Alibaba Cloud provides various monitoring and log audit-related services, such as CloudMonitor and Cloud Config, to help you monitor the usage of cloud resources and business status in real time.

## **Monitor the health status of Alibaba Cloud services**

We recommend that you keep track of the health status of your Alibaba Cloud resources so that you can handle exceptions at the earliest opportunity. For more information, visit [Alibaba Cloud status](https://status.alibabacloud.com/#/?region=cn-beijing).

On the **Alibaba Cloud status** page, you can check the health status of cloud services in each region, and subscribe to Really Simple Syndication (RSS) feeds about service exceptions.

## CloudMonitor

Lindorm is integrated with CloudMonitor and you can use the service free of charge. CloudMonitor monitors various metrics for cloud resources and Internet applications in real time, such as the running status of cloud services, resource usage in Elastic Compute Service (ECS), website performance, and service failure.

### Configure **alert rules for metrics**

You can create custom monitoring dashboards to collect data of specific metrics. For more information, see [Manage the monitoring charts of a custom dashboard](/help/en/cms/cloudmonitor-1-0/user-guide/manage-the-monitoring-charts-of-a-custom-dashboard).

You can configure alert rules for metrics. Alerts can be sent by using phone calls, text messages, emails, DingTalk chatbots, and the Alibaba Cloud app.

You can create an alert blacklist to block alerts for a specific metric. For detailed instructions, see [Manage blacklist policies](/help/en/cms/cloudmonitor-1-0/user-guide/create-a-blacklist-policy).

## Simple Log Service

Lindorm is integrated with Simple Log Service (SLS). You can enable the audit log feature in the Lindorm console. SLS collects and processes log data such as the operation information, running status, and business updates of cloud services, and analyzes and delivers logs in real time for monitoring and auditing. For more information about how to enable SLS in Lindorm, see [Enable the audit log feature](/help/en/lindorm/user-guide/activate-audit-log). The logs can be retained for up to 180 days and you can change the retention period. For more information, see [Modify the configurations of a logstore](/help/en/sls/manage-a-logstore#section-evc-rjx-ndb).
