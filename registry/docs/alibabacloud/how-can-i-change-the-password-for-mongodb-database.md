## Overview

You can set the password of a database when you create an instance. If you did not set the password immediately when creating an instance, or if you wanted to change the password or forget the password, you can reset the password. This topic describes how to modify the logon password of a MongoDB database.

## Description

> Alibaba Cloud reminds you that:
> 
> -   Before you perform operations that may cause risks, such as modifying instance configurations or data, we recommend that you check the disaster recovery and fault tolerance capabilities of the instances to ensure data security.
> -   You can modify the configurations and data of instances including but not limited to Elastic Compute Service (ECS) and Relational Database Service (RDS) instances. Before the modification, we recommend that you create snapshots or enable RDS log backup.
> -   If you have authorized or submitted sensitive information such as the logon account and password in the Alibaba Cloud Management Console, we recommend that you modify such information in a timely manner.

Change the password for logging on to an apsaradb for MongoDB database. For more information, see [set password](/help/en/mongodb/reset-a-password-optional-3 "This topic describes how to set or reset a password for a sharded cluster instance.").

> **Instructions** we recommend that you do not log on to a database as the root user in a production environment. You can create other users and grant permissions to them. For more information, see [use DMS to manage MongoDB users](/help/en/mongodb/user-guide/manage-user-permissions-on-mongodb-databases).

## Application scope

-   ApsaraDB for MongoDB
