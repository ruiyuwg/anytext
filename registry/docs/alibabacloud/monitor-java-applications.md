Managed Service for OpenTelemetry helps you monitor your applications and gain insights into application topology, traces, abnormal or slow transactions, and SQL analysis data. You can use OpenTelemetry, SkyWalking, Jaeger, and Zipkin to instrument your applications and to report trace data to Managed Service for OpenTelemetry. The following topics are for your reference:

-   [Use OpenTelemetry to report the trace data of Java applications](/help/en/opentelemetry/user-guide/use-opentelemetry-to-submit-trace-data-of-java-applications)
    
-   [Use SkyWalking to report Java application data](/help/en/opentelemetry/user-guide/use-skywalking-to-report-java-application-data)
    
-   [Use Jaeger to report Java application data](/help/en/opentelemetry/user-guide/use-jaeger-to-report-java-application-data)
    
-   [Use Zipkin to report Java application data](/help/en/opentelemetry/user-guide/use-zipkin-to-report-java-application-data)
