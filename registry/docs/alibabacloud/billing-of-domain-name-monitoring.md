The public domain name monitoring feature helps you monitor the HTTPS service status of multiple public websites. You can detect SSL certificate-related risks on the websites at the earliest opportunity. This topic describes the billable items, expiration, and refund policies of the public domain name monitoring feature.

## **Billing method**

The domain name monitoring service is a subscription-based service.

## Billable items

You are charged based on the number of resource plans that you select. The unit price varies based on the specifications of the resource plan. For pricing details, see the [Public Domain Name Monitoring buy page](https://common-buy-intl.alibabacloud.com/?spm=5176.2020520163.0.0.ce3dhhXuhhXuUM&commodityCode=cas_ssl_public_intl&request=%7B%22product%22%3A%22cloud_product%22%7D).

## Expiration

After the public domain name monitoring feature expires, Alibaba Cloud no longer monitors the HTTPS service status of your domain name, and the value displayed in the Remainder of Monitoring Validity Period (Days) column for the domain name changes to 0.

If you want to continue using the feature, you must renew the feature within 30 calendar days before it expires.

You cannot renew the feature after it expires. If you want to continue using the feature after it expires, you must re-enable the feature for your domain name.

## Refund policies

If you do not enable the feature for domain names within 7 days after you purchase the feature, you can perform the following steps to request a full refund:

1.  Log in to the [Certificate Management Service console](https://yundunnext.console.alibabacloud.com/?p=cas).
    
2.  In the navigation pane on the left, choose **Comprehensive Management** > ****Refund Management****.
    
3.  From the Order Type drop-down list, select **Public Domain Name Monitoring**. Find the target order and click **Refund** in the **Actions** column.
    
4.  In the **Refund Application** panel, click **Refunded**.
    
    If the console displays the message "**The refund failed because the eligible refund period has expired or the instance has been enabled.**", the order is not eligible for a refund.
