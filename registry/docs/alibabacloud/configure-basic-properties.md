In the scheduling configuration dialog box, you can view the name, ID, and type of a scheduling node. You can also configure basic information, such as the owner, labels, and description. This topic describes the parameters for the basic properties of a scheduling node.

Go to the edit page of the node. In the right-side navigation bar, click **Properties**. In the **General** section, configure the basic information for the node.

**Parameter**

**Description**

**Name**

The name of the node that you enter when you create it. The name cannot be modified.

**Node ID**

A unique ID that is generated after the node is submitted. The ID cannot be modified.

**Node Type**

The type of node that you select when you create it. The type cannot be modified.

**Owner**

The owner of the node. By default, the owner is the user who is currently logged on. You can change the owner as needed.

**Note**

Only a workspace administrator can change the owner. The new owner must be a member of the current DataWorks workspace.

**Label**

Use labels to categorize and manage tasks. For more information, see [Label management](/help/en/dataworks/user-guide/label-management).

**Description**

A description of the scheduling node. Use this to describe the business purpose or usage of the node.
