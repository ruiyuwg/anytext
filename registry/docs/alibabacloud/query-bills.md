This topic describes how to query Simple Log Service bills.

## Procedure

1.  Log on to the [Expenses and Costs console](https://usercenter2-intl.console.alibabacloud.com/billing/#/account/overview).
    
2.  In the left-side navigation pane, choose **Bills** > **Bill Details**.
    
3.  On the **Billing Details** tab, configure the **Billing Cycle** parameter, and then select **Simple Log Service** from the **Product** drop-down list.
    
    -   If you set the **Product Details** parameter to **Simple Log Service (SLS)**, you can view the bills of the pay-by-feature billing mode.![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0329386961/p717942.png)
        
    -   If you set the **Product Details** parameter to **Log Service - Pay-by-ingested-data Billing Mode**, you can view the bills of the pay-by-ingested-data billing mode.![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/9791752271/p717940.png)
