This topic describes how to register and log on to an Alibaba Cloud account.

## Register an Alibaba Cloud account

You can register an Alibaba Cloud account by using one of the following methods:

-   On the [Alibaba Cloud International site](https://www.alibabacloud.com/), click **Free Trial** in the upper-right corner.
    
-   Directly go to the [Alibaba Cloud account registration page](https://account.alibabacloud.com/register/intl_register.htm).
    

## Log on to your Alibaba Cloud account

Your Alibaba Cloud account and Resource Access Management (RAM) user have different logon pages.

-   [Logon page](https://account.alibabacloud.com/login/login.htm) for an Alibaba Cloud account.
