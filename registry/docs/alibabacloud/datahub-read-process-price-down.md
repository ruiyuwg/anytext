**Dear Alibaba Cloud users,**

Since **March 31, 2025** (UTC+8), the unit price of **read traffic** of DataHub is reduced from **USD 0.024 per GB** to **USD 0.0024 per GB**, a 90% decrease. The price adjustment is to meet the increasing scale of streaming data that needs to be processed and minimize costs. The price adjustment is applicable to all regions where DataHub is activated.

DataHub provides the [data synchronization feature](/help/en/datahub/user-guide/overview#h2-datahub-1) free of charge for batch analysis of streaming data. It allows you to synchronize data from a DataHub **topic** to a **table** by using **Zero-ETL**, write streaming data into data lakes and data warehouses. Data can be synchronized from DataHub to Alibaba Cloud services such as **MaxCompute**, **Hologres**, **Elasticsearch**, and **Object Storage Service (OSS)**.

DataHub provides the following benefits: **free data writing**, **free synchronization**, and **low-cost data reading**. DataHub is also [compatible with the Kafka protocol](/help/en/datahub/developer-reference/compatibility-with-kafka/). This way, you can use messages in an easy-to-use and cost-effective manner.
