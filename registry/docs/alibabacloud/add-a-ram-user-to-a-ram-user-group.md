After you add a Resource Access Management (RAM) user to a RAM user group, the RAM user inherits all permissions of the group. You can add a RAM user to a group from either the Users page or the Groups page.

## Method 1: From the Users page

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) as a RAM administrator.
    
2.  In the left-side navigation pane, choose **Identities** > **Users**.
    
3.  On the **Users** page, find the target RAM user and click **Add to Group** in the **Actions** column.![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4653064371/p889423.png)
    
4.  In the **Add User to Group** panel, select the RAM user group to which you want to add the RAM user. The information about the RAM user is automatically filled in.
    
5.  Click ****Add User to Group****.
    
6.  On the page that appears, click **Close.**
    

## Method 2: From the Groups page

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) as a RAM administrator.
    
2.  In the left-side navigation pane, choose **Identities** > **Groups**.
    
3.  On the **Groups** page, find the target RAM user group and click **Add User** in the **Actions** column. ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3163064371/p889427.png)
    
4.  In the **Add User to Group** panel, select the RAM user group to which you want to add the RAM user. The information about the RAM user is automatically filled in.
    
5.  Click ****Add User to Group****.
    
6.  On the page that appears, click **Close.**
