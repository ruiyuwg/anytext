Key Management Service (KMS) provides OpenAPI and KMS instance API. Choose the one best suited to your needs.

**Operation type**

**Description**

Management operations

Manage resources such as keys, secrets, tags, and aliases. Only OpenAPI supports management operations. For more information, see [API overview](/help/en/kms/key-management-service/developer-reference/api-overview-1).

Service-related operations

-   Cryptographic operations: Use either OpenAPI or KMS Instance API.
    
    -   OpenAPI: [Cryptographic operations](/help/en/kms/key-management-service/developer-reference/api-overview-1#27509fc001wvj).
        
    -   KMS Instance API: [Cryptographic operations](/help/en/kms/key-management-service/developer-reference/api-overview#section-llo-9kj-kbj).
        
-   Secret retrieval: Use OpenAPI ([GetSecretValue](/help/en/kms/key-management-service/developer-reference/api-getsecretvalue)) or KMS Instance API ([GetSecretValue](/help/en/kms/key-management-service/developer-reference/getsecretvalue-2)).
