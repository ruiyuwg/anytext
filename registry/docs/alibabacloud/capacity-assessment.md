Database Autonomy Service (DAS) provides the capacity assessment feature. You can use this feature to view suggestions on capacity optimization, performance capacity statistics, storage usage, and the number of remaining days for which the storage is available. This feature uses machine learning and capacity algorithms to predict future storage usage.

## Prerequisites

The following types of databases are supported:

-   ApsaraDB RDS for MySQL
    
-   PolarDB-X 2.0
    

## Procedure

1.  Log on to the [DAS console](https://hdm.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, click **Instance Monitoring**.
    
3.  On the page that appears, find the database instance that you want to manage and click the instance ID. The instance details page appears.
    
4.  In the left-side navigation pane, click **Capacity Assessment**.
    
5.  On the **Capacity Assessment** tab, perform the following operations:
    
    -   In the **Capacity Suggestion** section, view the instance storage status and related suggestions.
        
    -   In the **Capacity Assessment** section, view the storage performance and storage usage within a specific time range.
