Displays the current ossutil version number.

## Syntax

```
ossutil version [flags]
```

**Note**

For available flags, see [Command-line options](/help/en/oss/command-line-options).

## Example

Display the current ossutil version number:

```
ossutil version
```

If the command runs successfully, the current ossutil version number is displayed.
