Dear users,

Thank you for your support and trust in Alibaba Cloud Data Lake Formation (DLF). From February 15, 2023, Alibaba Cloud no longer updates the data ingestion feature provided by DLF. This aims to improve service quality and user experience. You can continue to use other features of DLF.

## **Detailed information**

-   **End-of-update time:** February 15, 2023
    
-   **Involved feature:** data ingestion feature of DLF
    
    **Important**
    
    You can continue to use other features of DLF.
    

## **Impact**

-   **New users or users who have not used the data ingestion feature:** The data ingestion feature cannot be accessed or used.
    
-   **Users who have used the data ingestion feature:** During the end-of-update period, Alibaba Cloud still provides O&M and after-sales support services for existing data ingestion tasks and jobs.
    

## **Recommended alternatives**

For real-time or offline data ingestion scenarios, we recommend that you use the following alternative services:

-   **Realtime Compute for Apache Flink:** It is suitable for efficient and low-latency data transmission from the source system to the destination data lake. For example, you can use components such as MySQL CDC DataStream Connector for the implementation. For more information, see [MySQL CDC DataStream Connector](/help/en/flink/realtime-flink/developer-reference/mysql-connector/).
    
-   **DataWorks Data Integration:** It provides powerful data integration capabilities that help you distribute data from different storage locations to a data lake. For more information, see [Overview of Data Integration](/help/en/dataworks/user-guide/overview-of-data-integration/).
    

Thank you for your understanding and support. If you have any questions, contact us.
