The following tables list API operations available for use in ActionTrail.

## Trail management

 

API operation

Description

[CreateTrail](/help/en/actiontrail/developer-reference/api-tracking-related-apis-createtrail#doc-api-Actiontrail-CreateTrail "Creates a trail.")

Creates a trail.

[DescribeTrails](/help/en/actiontrail/developer-reference/api-tracking-related-apis-describetrails#doc-api-Actiontrail-DescribeTrails "Queries detailed information about trails.")

Queries the detailed information about trails.

[GetTrailStatus](/help/en/actiontrail/developer-reference/api-tracking-related-apis-gettrailstatus#doc-api-Actiontrail-GetTrailStatus "Queries the status of a trail.")

Queries the status of a trail.

[StartLogging](/help/en/actiontrail/developer-reference/api-tracking-related-apis-startlogging#doc-api-Actiontrail-StartLogging "You can call this operation to enable logging for a trail.")

Enables logging for a trail.

[StopLogging](/help/en/actiontrail/developer-reference/api-tracking-related-apis-stoplogging#doc-api-Actiontrail-StopLogging "You can call this operation to disable logging for a trail.")

Disables logging for a trail.

[UpdateTrail](/help/en/actiontrail/developer-reference/api-tracking-related-apis-updatetrail#doc-api-Actiontrail-UpdateTrail "Updates the configuration of a trail.")

Updates the configuration of a trail.

[DeleteTrail](/help/en/actiontrail/developer-reference/api-tracking-related-apis-deletetrail#doc-api-Actiontrail-DeleteTrail "You can call this operation to delete a trail.")

Deletes a trail.
