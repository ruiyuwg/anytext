This topic explains the fields in the reports for **upgraded** bills, which are available through an invitational preview. The reports include **Billing Details**, **Split Bill Details**, and **Cost Details**.

## **Identification information (**LineItemDetails**)**

**Field name**

**Description**

Order ID (OrderId)

A unique number that Alibaba Cloud assigns to an order based on specific rules.

-   If the fee type is related to a subscription, such as subscription upfront fees, subscription pay-as-you-go fees, subscription refund fees, or subscription coverage fees, this is the ID of the order placed for the subscription, resource plan, or savings plan.
    
-   If the fee type is pay-as-you-go, rounding adjustment, commission, or another type of fee, the order ID is empty.
    

## **Identity information (**IdentityDetails**)**

**Field name**

**Description**

Resource purchase account ID (ResourcePurchaseAccountId)

The ID of the account that purchased the Alibaba Cloud resource instance.

Resource purchase account (ResourcePurchaseAccount)

The name of the account that purchased the Alibaba Cloud resource instance.

Resource owner account ID (ResourceOwnerAccountId)

The ID of the account that actually uses the resource instance. This may differ from the resource purchase account ID.

Resource owner account (ResourceOwnerAccount)

The name of the account that actually uses the resource instance. This may differ from the resource purchase account.

## **Billing information (**BillingDetails**)**

**Field name**

**Description**

Service entity (ServiceEntity)

The name of the company that provides the product or service. Alibaba Cloud sells many products, and different companies may be responsible for some of them.

Billing month (BillingMonth)

The billing period shown in the contract, which is the billing month.

Billing date (BillingDate)

The date when the cloud product was consumed.

Fee type (LineItemType)

The type of fee on the bill. It includes:

-   Subscription upfront fee: The amount paid when you place an order for a subscription, resource plan, or savings plan.
    
-   Subscription pay-as-you-go fee: For subscription orders (resource plans, savings plans) with zero or partial upfront payment, this is the pay-as-you-go portion of the bill.
    
-   Subscription refund fee: The refund amount for an unsubscribed subscription, resource plan, or savings plan order.
    
-   Subscription coverage fee: The daily amortized amount for a subscription order.
    
-   Subscription unused fee: For a subscription order, this is the one-time amortized amount for the original order after a refund occurs.
    
-   Subscription refund unused fee: For a subscription order, this is the one-time amortized amount for the refunded order after a refund occurs.
    
-   Pay-as-you-go cloud resource fee: The fee generated based on actual usage during the billing cycle for pay-as-you-go resources.
    
-   Adjustment fee: The fee generated from adjustments (increases or decreases) made to a bill because of errors in a previous billing cycle.
    
-   Rounding adjustment fee: The amount discarded when Alibaba Cloud rounds down the total cost, removing values from the third to the tenth decimal place.
    
-   Minimum and maximum spending fee: The fee generated by the minimum and maximum spending business after a contract is signed.
    
-   Commission fee: The commission fee that Alibaba Cloud, as a platform, collects from Independent Service Vendors (ISVs) on the Alibaba Cloud Marketplace.
    

Transaction type (ConsumeType)

The type of transaction corresponding to the bill. It includes the following types:

-   New purchase: A bill generated for a new subscription (subscription, resource plan, or savings plan) order.
    
-   Renewal: A bill generated for a subscription (subscription, resource plan, or savings plan) renewal.
    
-   Downgrade: A bill generated for a subscription (subscription, resource plan, or savings plan) downgrade.
    
-   Upgrade: A bill generated for a subscription (subscription, resource plan, or savings plan) upgrade.
    
-   Unsubscribe: A refund bill generated after a refund is issued for a paid order.
    
-   Trade-in: A bill generated for a trade-in.
    
-   Fixed fee installment: A bill generated for a fixed fee installment.
    
-   Pay-as-you-go: A bill generated for a pay-as-you-go cloud product.
    
-   Adjustment: A bill generated from adjustments (increases or decreases) made to a bill because of errors in a previous billing cycle.
    

Consumption time (ConsumedTime)

The payment time or the time when the fee was incurred for a consumption record:

-   For subscription products, this is the time when the order payment was completed.
    
-   For pay-as-you-go products, this is the start time of each pay-as-you-go billing cycle.
    

Service start time (ServiceStartTime)

The start time of the consumption.

-   For subscription products, this is the start time of the instance validity period.
    
-   For pay-as-you-go products, this is the start time of each pay-as-you-go billing cycle.
    

Service end time (ServiceEndTime)

The end time of the consumption.

-   For subscription products, this is the end time of the instance validity period.
    
-   For pay-as-you-go products, this is the end time of each pay-as-you-go billing cycle.
    

Amortization start time (ServiceStartTime)

The start time for cost amortization of the cloud product.

Amortization end time (EndTimeOfService)

The end time for cost amortization of the cloud product.

## **Resource information (**ResourceDetails**)**

**Field name**

**Description**

Resource ID (ResourceId)

The identifier that uniquely identifies a resource in an Alibaba Cloud product or service.

Instance ID (billing granularity) (InstanceId)

The dimension used for statistics and summarization when Alibaba Cloud products or services generate bills. Different cloud products and services may have different billing granularities. This affects the level of detail in the bill and how fees are calculated.

For cloud products where the billing granularity is not equal to the resource management granularity, additional splitting is required to meet internal management needs.

Resource name (ResourceName)

The custom name for a cloud resource on Alibaba Cloud.

Region code (RegionCode)

The logical region code where the cloud resource is located.

Region (Region)

Some Alibaba Cloud products are deployed in different regions. This indicates the region selected when the order was placed.

Zone (Zone)

The zone of the cloud resource.

Resource group (ResourceGroup)

The group where the cloud resource is located, as set in the Resource Management console.

Resource tag (ResourceTag)

The custom tag on an Alibaba Cloud resource.

Public IP address (PublicIpAddress)

The public IP address corresponding to the cloud resource.

Private IP address (PrivateIpAddress)

The private IP address corresponding to the cloud resource.

**Description**

Duration before deduction (ChargeDurationBeforeDeduction)

The duration deducted for a pay-as-you-go instance by a reserved instance or other means.

Deducted usage (DeductedUsage)

The usage amount deducted for a pay-as-you-go instance by a resource plan, free quota, or other means.

Usage (Usage)

The final billable usage of an Alibaba Cloud product or service.

Usage unit (UsageUnit)

Usage details (UsageConversionInformation)

## **Fee information (**FeeDetails**)**

**Field name**

**Description**

Gross amount (GrossAmount)

The total list price for the selected configuration of the Alibaba Cloud resource.

Billing formula (BillingFormula)

The billing formula used to calculate the gross amount.

Billing auxiliary information (BillingAuxiliaryInformation)

## **Subscription deduction information (**SubscriptionDetails**)**

**Field name**

**Description**

Subscription deduction gross amount (SubscriptionDeductGrossAmount)

The gross amount of pay-as-you-go cloud resources deducted by a subscription (savings plan).

Amount after subscription deduction (AmountAfterSubscriptionDeduction)

The amount after a subscription (savings plan) deduction is applied. **Amount after subscription deduction = Gross amount - Subscription deduction gross amount.**

Subscription deduction amount (SubscriptionDeductAmount)

The commitment amount consumed by the subscription (savings plan) itself when a deduction is applied.

Subscription deduction details (SubscriptionDeductDetails)

Details of the deduction made by a subscription (savings plan). It includes the savings plan discount, instance ID, type, and commitment amount.

Example: A savings plan has a commitment of 2 CNY/hour and can be applied to ecs.g6.xlarge instances. The regular pay-as-you-go price is 1 CNY/instance/hour. The savings plan discount for the ecs.g6 family in the China (Shanghai) region is 40%, so the discounted price is 1 × 0.4 = 0.4 CNY/instance/hour. This savings plan can cover up to 2 / 0.4 = 5 ecs.g6.xlarge instances per hour. If you run 5 instances for one hour:

\[Subscription deduction gross amount\] = 1 CNY/instance/hour × 5 instances × 1 hour = 5 CNY.

Because the savings plan is fully utilized, \[Amount after subscription deduction\] = 0 CNY.

\[Subscription deduction amount\] is the commitment amount consumed by the savings plan itself = 2 CNY.

## **Discount information (**DiscountDetails**)**

**Field name**

**Description**

Discount amount (DiscountAmount)

The total discount amount on the bill. This includes official website promotions, contract discounts, and other discounts.

Amount after discount (AmountAfterDiscount)

This is the amount on a bill after discounts, such as website promotions and contract discounts, are applied. This amount is the final payable amount and reflects deductions for coupons. **Discounted amount = Total list price - Subscription discount - Discount amount.**

Discount details (DiscountDetails)

Details of the official website promotions, contract discounts, and other deductions on the bill. This includes the discount name, coupon amount, discount type, and discount source.

## **Coupon deduction information (**CouponDeductionDetails**)**

**Field name**

**Description**

Coupon deduction amount (CouponDeductionAmount)

The amount deducted by a coupon. This amount cannot be used to issue an invoice.

Coupon deduction details (CouponDeductionDetails)

Detailed information about the coupon deduction on the bill. This includes the number, type, and deduction amount for each coupon used.

## **Payable information (**PayableDetails**)**

**Field name**

**Description**

Payable amount (tax inclusive) (TaxInclusivePayableAmount)

The actual amount you need to pay after all discounts, subscriptions (savings plans), and coupons are applied.

**Payable amount = Gross amount - Subscription deduction gross amount - Discount amount - Coupon deduction amount**.

## **Split bill information (**SplitLineItemDetails**)**

**Field name**

**Description**

Split item name (SplitItemName)

The name corresponding to the specific split granularity of the bill. For example, if an OSS bill is split by bucket, the split item name is the name of the bucket.

Split item ID (SplitItemId)

The ID corresponding to the specific split granularity of the bill. For example, if an OSS bill is split by bucket, the split item ID is the ID of the bucket.

The usage ratio corresponding to the specific split item of the bill.

**Field name**

**Description**

Pay-as-you-go gross amount (Gross Amount)

The gross amount for consumed pay-as-you-go cloud resources. This value is the same as the fee.

Pay-as-you-go discount amount (Discount Amount)

The discount amount for consumed pay-as-you-go cloud resources. This value is the same as the fee.

Pay-as-you-go coupon deduction amount (Coupon Deduction Amount)

The coupon deduction amount for consumed pay-as-you-go cloud resources. This value is the same as the fee.

Pay-as-you-go payable amount (tax inclusive) (Tax-inclusive Payable Amount)

The payable amount for consumed pay-as-you-go cloud resources. This value is the same as the fee.

## **Subscription deduction fee (**SubscriptionDetail**)**

This group of fields appears only on the [Cost Details](https://usercenter2-intl.console.alibabacloud.com/finance/cost-detail) page in the Expenses and Costs console. These fields have values when the fee type is **Subscription coverage fee** and the subscription type is **Savings plan**.

**Field name**

**Description**

Subscription deduct gross amount (Subscription Deduct Gross Amount)

The gross amount of a pay-as-you-go instance that is deducted by a subscription (savings plan).

Subscription deduction discount (Subscription Deduction Discount)

The discount for a pay-as-you-go instance covered by a subscription (savings plan). The deduction discount is calculated as follows: Deduction Amount / Gross Amount of the Deducted Portion.

Example: A savings plan has a commitment of 2 CNY/hour and can be applied to ecs.g6.xlarge instances. The regular pay-as-you-go price is 1 CNY/instance/hour. The savings plan discount for the ecs.g6 family in the China (Shanghai) region is 40%, so the discounted price is 1 × 0.4 = 0.4 CNY/instance/hour. This savings plan can cover up to 2 / 0.4 = 5 ecs.g6.xlarge instances per hour. If you run 5 instances for one hour:

\[Subscription deduct gross amount\] = 1 CNY/instance/hour × 5 instances × 1 hour = 5 CNY.

\[Subscription deduction discount\] = 0.4 (40% discount)

## **Subscription information (**Subscription**)**

This group of fields appears only on the [Cost Details](https://usercenter2-intl.console.alibabacloud.com/finance/cost-detail) page in the Expenses and Costs console. These fields have values when the fee type is **Subscription coverage fee**, **Subscription refund coverage fee**, or **Subscription unused fee**.

**Field name**

**Description**

Subscription type (Subscription Type)

The general category of the subscription. The main categories are:

-   Subscription
    
-   Resource plan
    
-   Savings plan
    

Subscription gross amount (Subscription Gross Amount)

-   If the subscription type is Subscription:
    
    -   If the fee type is Subscription coverage fee, this is the amortized gross amount. For example, with linear amortization, this value is the gross amount of the original bill divided by the number of service periods.
        
    -   If the fee type is Subscription refund coverage fee, this is the gross amount from the original refund bill.
        
    -   If the fee type is Subscription unused fee, this is the gross amount of the remaining value that is amortized at one time when the original purchased order is refunded.
        
-   If the subscription type is Resource plan, the subscription gross amount is not displayed.
    
-   Subscription Type: Savings Plan
    
    -   If the fee type is Subscription coverage fee, this is the gross amount of the savings plan that is consumed when it covers a pay-as-you-go instance.
        
    -   If the fee type is Subscription refund coverage fee, this is the gross amount of the savings plan refund bill.
        
    -   If the fee type is Subscription unused fee, this is the gross amount of the remaining value that is amortized at one time when the original savings plan order is refunded.
        

Subscription discount (Subscription Discount)

-   If the subscription type is Subscription:
    
    -   If the fee type is Subscription coverage fee, this is the amortized discount amount. For example, with linear amortization, this value is the discount amount of the original bill divided by the number of service periods.
        
    -   If the fee type is Subscription refund coverage fee, this is the discount amount of the subscription refund bill.
        
    -   If the fee type is Subscription unused fee, this is the discount amount of the remaining value that is amortized at one time when the original subscription order is refunded.
        
-   If the subscription type is Resource plan or Savings plan, the subscription discount amount is not displayed.
    

Subscription coupon deduction amount (Subscription Coupon Deduction Amount)

-   If the subscription type is Subscription:
    
    -   If the fee type is Subscription coverage fee, this is the amortized coupon deduction amount. For example, with linear amortization, this value is the coupon deduction amount of the original bill divided by the number of service periods.
        
    -   If the fee type is Subscription refund coverage fee, this is the coupon deduction amount of the subscription refund bill.
        
    -   If the fee type is Subscription unused fee, this is the coupon deduction amount of the remaining value that is amortized at one time when the original subscription order is refunded.
        
-   If the subscription type is Resource plan or Savings plan, the subscription coupon deduction amount is not displayed.
    

Subscription payable amount (Subscription Payable)

-   If the subscription type is Subscription:
    
    -   If the fee type is Subscription coverage fee, this is the amortized payable amount. For example, with linear amortization, this value is the payable amount of the original bill divided by the number of service periods.
        
    -   If the fee type is Subscription refund coverage fee, this is the payable amount of the subscription refund bill.
        
    -   If the fee type is Subscription unused fee, this is the payable amount of the remaining value that is amortized at one time when the original subscription order is refunded.
        
-   If the subscription type is Resource plan or Savings plan:
    
    -   If the fee type is Subscription coverage fee, this is the payable amount of the resource plan or savings plan that is consumed when it covers a pay-as-you-go instance.
        
    -   If the fee type is Subscription refund coverage fee, this is the payable amount of the resource plan or savings plan refund bill.
        
    -   If the fee type is Subscription unused fee, this is the payable amount of the remaining value that is amortized at one time when the original resource plan or savings plan order is refunded.
        

Subscription instance ID (Subscription Instance ID)

The instance ID of the subscription, resource plan, or savings plan that is used.

## **Cost information (**CostDetails**)**

This group of fields appears only on the [Cost Details](https://usercenter2-intl.console.alibabacloud.com/finance/cost-detail) page in the Expenses and Costs console.

**Field name**

**Description**

Cost amount (CostAmount)

-   If the fee type is a subscription-related fee, including **Subscription coverage fee**, **Subscription unused fee**, and **Subscription refund coverage fee**, the cost amount equals the **Subscription payable amount**.
    
-   For other fee types, the cost amount equals the pay-as-you-go **Payable amount (tax inclusive)**.
    

Cost amount (including coupons) (Cost Amount (Coupon Deduction Amount Included))

The cost amount including coupon deductions. **Cost amount (including coupons) = Cost amount + Subscription coupon deduction amount + Pay-as-you-go coupon deduction amount.**
