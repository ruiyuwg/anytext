Checks whether the auto-renewal feature is enabled for each subscription Server Load Balancer (SLB) instance. If so, the evaluation result is Compliant.

## Scenarios

This rule applies when you need to enable the auto-renewal feature for a subscription SLB instance. This prevents your business from being interrupted due to an expired instance.

## Risk level

Default risk level: high.

When you apply this rule, you can change the risk level based on your business requirements.

## Compliance evaluation logic

-   If the auto-renewal feature is enabled for each subscription SLB instance, the evaluation result is Compliant.
-   If the auto-renewal feature is disabled for a subscription SLB instance, the evaluation result is Incompliant.
