This topic describes how to change the Domain Name System (DNS) servers for a domain name registered with West.cn to Alibaba Cloud DNS.

## **Procedure**

1.  Log on to [West.cn](http://www.west263.com/). In the upper-right corner of the page, click **Management Center**.
    
2.  In the left navigation pane, click **Domain Management**. On the **Domain List** tab, click **Manage** next to the domain name that you want to manage.
    
3.  On the **Modify DNS** tab, select **Use Custom DNS**. Enter the Alibaba Cloud DNS server names in the text boxes and click **Submit**.
    
    **Note**
    
    If you do not know the DNS server names assigned in the Alibaba Cloud DNS system, refer to [View the DNS server addresses for a domain name](/help/en/dns/pubz-view-dns-server-status-and-exception-handling#2977dbc544lrs).
    
4.  Wait for the DNS server configuration to take effect. The changes can take up to 48 hours to propagate globally.
