## **Install instgo**

Instgo is a compilation tool for Go applications provided by Application Real-Time Monitoring Service (ARMS). After you compile your Go project with instgo, ARMS can monitor your Go application. For more information, see [Introduction to instgo](/help/en/arms/application-monitoring/developer-reference/instgo-tool-introduction).
