Deletion protection prevents clusters from being deleted by mistake. You can enable this feature in the ApsaraDB for HBase console.

1.  Log on to the [ApsaraDB for HBase](https://hbase.console.alibabacloud.com/) console.
    
2.  In the top navigation bar, select the region in which your cluster is deployed.
    
3.  On the Clusters page, find the cluster for which you want to enable deletion protection and click the cluster ID.
    
4.  In the left-side navigation pane, click **Basic Information**.
    
5.  Click **Enable** next to Delete Protection. ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3315622961/p707677.png)
    
6.  In the Enable Delete Protection dialog box, click **OK**. ![OK icon](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1238790361/p324105.png)
    
    **Note**
    
    After you enable deletion protection for a cluster, you cannot delete the cluster by performing operations in the console or making API calls in OpenAPI Explorer. Before you delete the cluster, disable deletion protection for the cluster.
