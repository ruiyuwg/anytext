This document is written based on Object Storage Service (OSS) SDK for iOS 2.10.20.

## Prerequisites

-   OSS is activated. For more information, see [Activate OSS](/help/en/oss/getting-started/activate-oss#task-njz-hf4-tdb).
    
-   An AccessKey ID and AccessKey secret are created. For more information, see [Create an AccessKey pair](/help/en/ram/user-guide/create-an-accesskey-pair#task-2245479).
    
-   iOS 8.0 or later is installed.
