Set up and use Coding Plan with Cline.

1.  In [VS Code](https://code.visualstudio.com/), open the Extensions Marketplace, search for **Cline**, and install it.
    
    ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3661724671/p947567.png)
    
2.  After installation, click the Cline icon in the left pane and then click **Bring my own API key**. In the pop-up window, set **OpenAI Compatible** as the API Provider and configure the following parameters.
    
    > If you have used Cline before, click the Settings button in the top-right corner to configure it.
    
    **Item**
    
    **Description**
    
    API Provider
    
    Set to **OpenAI Compatible**.
    
    Base URL
    
    Set to https://coding-intl.dashscope.aliyuncs.com/v1
    
    OpenAI Compatible API Key
    
    Enter your Coding Plan-specific [API key](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=globalset#/efm/coding_plan) (starts with `sk-sp-`).
    
    Model ID
    
    Enter a model ID from the [supported models](/help/en/model-studio/coding-plan-overview) list, such as `qwen3.5-plus`.
    
    After configuration, click **Done** in the top-right corner.
    
3.  To use Cline, click the gear icon in the top-right corner to open Settings. Change the Model ID to switch models.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2148019671/p1040271.png)
