Domain Names is a domain name management platform that integrates domain registration, monitoring, and protection. It works with Alibaba Cloud DNS to provide you with a full suite of domain name services.

## Domain name registration

If you want to use a domain name for your website, email, or other services, you can register one on the [Domain Name Registration](https://www.alibabacloud.com/zh/domain?spm=a3c0i.23458820.6791778070.138.4eb76e9bO2smAD) page. Before registering, you must first create a registrant profile and complete identity verification. After the domain name is successfully registered, you can configure its DNS records to make it accessible online.

1.  **Registration**:
    
    Alibaba Cloud offers a wide variety of domain extensions. You can choose your desired domain name on the [Domain Name Registration](https://www.alibabacloud.com/zh/domain?_p_lc=1) page. For more information, see [Register a domain name](/help/en/dws/user-guide/how-to-register-a-domain-name).
    
2.  **DNS**:
    
    After your domain name is registered, you must configure its DNS records to point it to your website or other services. [Alibaba Cloud DNS](https://www.alibabacloud.com/zh/product/dns?_p_lc=1) provides stable, secure, and fast resolution services.
    

## Domain name brokerage

If a domain name you want is already registered by someone else, you can use the domain name brokerage service to acquire it. This service provides brokerage assistance, including price inquiry, negotiation, analysis, acquisition, and secure transfer of domain names. For more information, see [Purchase a registered domain name](/help/en/dws/user-guide/purchase-of-a-registered-domain-name).

## Domain name management and security

After registering a domain name, you are responsible for its daily management and security to avoid service interruptions.

-   **Daily management**
    
    -   **Domain name renewal and redemption**:
        
        Keep track of your domain name's expiration date. Alibaba Cloud will send renewal reminders to your registered mobile number and email address. You should renew your domain name before it expires. For more information, see [Renew a domain name](/help/en/dws/user-guide/domain-name-renewal1#concept-k34-1xw-12b). If you fail to renew in time, the domain name enters a redemption period where it can be recovered at a higher cost. For more information, see [Redeem a domain name](/help/en/dws/user-guide/redeem-a-domain-name#concept-fkm-4zw-12b).
        
    -   **Domain name information maintenance**:
        
        Alibaba Cloud allows you to easily manage your domain name information. You can [create and maintain registrant profiles](/help/en/dws/user-guide/materials-required-for-real-name-verification) in the console and associate them with your domain names. You can also modify non-registrant information. To change the domain name registrant or other information, see [Update domain name information](/help/en/dws/user-guide/domain-information-modification/).
        
    -   **DNS record management**:
        
        You can manage your DNS records to point your domain name to a website or other services. For more information, see [Quick links](/help/en/dns/quick-links).
        
-   **Security management**
    
    -   To protect your domain name, consider enabling security features such as the [update lock](/help/en/dws/user-guide/enable-the-update-prohibition-lock#concept-dds-xy1-b2b) and [transfer lock](/help/en/dws/user-guide/enable-the-transfer-prohibition-lock#concept-ztt-zv1-b2b). It is also a good practice to regularly review your DNS logs. For more information, see [Best practices for domain name security](/help/en/dws/best-practices-for-domain-name-security#concept-mqd-bcb-b2b).
        
-   **Authorization management**
    
    -   To authorize other users to manage your domain name, attach the required policies to them in the [Resource Access Management (RAM) console](https://ram.console.alibabacloud.com/).
        
    -   **The domain name management portal is a legacy feature available only to certain HiChina agent accounts and is no longer offered.** All other accounts should use the [RAM console](https://ram.console.alibabacloud.com/) for authorization management.
        
    -   If your non-HiChina agent account previously enabled this portal, you may continue to use it. However, once disabled, it cannot be re-enabled.
