The proactive alerting feature allows you to enable the alert service of key metrics for a cloud service with a single click. This feature allows you to build an alert system for multiple metrics in cloud services. If an exception occurs, Cloud Monitor sends an alert notification. You can then handle the exception at the earliest opportunity.

## Background information

For more information about the cloud services that support the proactive alerting feature and the alert rules of the cloud services, see [Initiative Alert List](https://cloudmonitor.console.alibabacloud.com/?accounttraceid=e1dcf862da934eb3b627949c4fbe79b0zgnh&#/initiativeAlarm).

If you enable the proactive alerting feature for a cloud service, take note of the following information:

-   All the alert rules of the cloud service are enabled by default. Cloud Monitor automatically creates an alert system for the specified metrics.
    
-   The alert rules of the cloud service are applied to the instances that already exist and the instances that are created after the proactive alerting feature is enabled.
    
-   You can modify, delete, or disable the alert rules of the cloud service.
    

## Procedure

1.  Log on to the [Cloud Monitor console](https://cloudmonitor.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, choose **Alerts** > ****Proactive** Alerting**.
    
3.  Turn on **Proactive Alerting** for the cloud service.
    
    **Note**
    
    You can also enable or disable the proactive alerting feature for Elastic Compute Service (ECS) instances in the ECS console. For more information, see [Enable the initiative alert feature](/help/en/ecs/user-guide/configure-alerts-for-an-ecs-instance#section-u83-pol-cbv).
    
4.  Click the ![下拉按钮](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1587407061/p179583.png) icon next to the cloud service to view the alert rules provided by Cloud Monitor.
    

## What to do next

In the alert rule list of a cloud service, you can click **Disable**, **Modify**, or **Delete** in the **Actions** column to disable, modify, or delete an alert rule.
