This topic provides an example of how to use Terraform in Terraform Explorer to create a virtual private cloud (VPC).

Terraform Explorer is a tool provided by Alibaba Cloud to debug Terraform configuration files online based on open source Terraform. It is designed to help developers simplify the processes of writing Terraform configuration files and operating Terraform while lowering the barrier to entry. With Terraform Explorer, developers can write a form to automatically generate and convert Terraform configuration files, and use a simple button-based interface to run Terraform online. For more information about Terraform Explorer, see [Terraform Explorer introduction](/help/en/terraform/introduction-to-terraform-explorer).

Terraform Explorer lets you create resources by configuring custom parameters or using a sample template. You can use either method to create resources as needed.

## Create a resource by configuring custom parameters

You can create an Alibaba Cloud resource by configuring custom parameters as needed.

1.  On the [Terraform Explorer](https://api.aliyun.com/api-tools/terraform?spm=api-workbench.home.0.0.69bbe85cc1wFjp&provider=1.227.1&resource=alicloud_instance&product=ECS&example=) page, configure the **Products** and **Resource Type** parameters, configure the parameters in the **Documentation** section based on the instructions, and then click **Parameters**, click **Initiate Debugging**.
    
    For more information about the parameters for creating a VPC, see [alicloud\_vpc](https://registry.terraform.io/providers/aliyun/alicloud/latest/docs/resources/vpc).
    
    Parameter
    
    Description
    
    Example
    
    vpc\_name
    
    The name of the VPC.
    
    tf-test-vpc
    
    cidr\_block
    
    The private CIDR block of the VPC.
    
    192.168.0.0/16
    
    description
    
    The description of the VPC.
    
    The VPC was created using Terraform.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863324.png)
    
2.  On the **Debugging Code** tab, view the input parameters. After you confirm that the parameters are correct, click **Plan** to view the execution plan generated by Terraform.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863327.png)
    
3.  On the **Plan Details** tab, view the details of the resource that you want to create. After you confirm that the information is correct, click **Apply** to view the execution result of Terraform.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863329.png)
    
4.  On the **Apply Details** tab, view the execution result. If the execution is successful, the following message appears: "Apply complete! Resources: 1 added, 0 changed, 0 destroyed." If the execution fails, modify the parameters as prompted and click Save and Continue.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863430.png)
    
5.  On the **Resource Details** tab, view the information about the created resource.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863428.png)
    
6.  If you want to modify the information about the created resource, adjust the related parameters and click **Save And Continue**. Then, repeat Step 2, Step 3, and Step 4. After the execution is complete, you can view the execution result on the **Apply Details** tab. If the execution is successful, the following message appears: "Apply complete! Resources: 0 added, 1 changed, 0 destroyed." If the execution fails, adjust the parameters as prompted and click Save and Continue.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863437.png)
    
7.  If you want to release the created resource, click the **Apply Details** tab, click **Destroy Resources**, and then click the **Plan Details** tab, click **Apply** to release the resource.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863443.png)
    

## **Create a resource using a sample template**

Creating resources of specific cloud services involves configuring numerous parameters. If you are not familiar with parameter configurations or want to experience a quick resource creation process using Terraform, we recommend that you use a sample template to create a resource. Terraform Explorer provides sample templates for each resource type. You can select one of the sample templates to quickly complete debugging.

1.  On the [Terraform Explorer](https://api.aliyun.com/api-tools/terraform?spm=api-workbench.home.0.0.69bbe85cc1wFjp&provider=1.227.1&resource=alicloud_instance&product=ECS&example=) page, configure the **Products**, **Resource Type**, and **Sample** parameters, and click **Initiate Debugging**. You can view the details of the sample template on the **Sample** tab on the right.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863397.png)
    
2.  On the **Template Details** tab, click **Preview And Execute**.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863399.png)
    
3.  On the **Apply Details** tab, view the execution result.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863393.png)
    
4.  If you want to release the created resource, click the **Apply Details** tab, click **Destroy Resources**, and then click the **Plan Details** tab, click **Apply** to release the resource.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3710913371/p863395.png)
    

**Note**

You can also perform operations such as **Continue** debugging and **Destroy Resources** on the **Debugging History** tab.
