## **Benefits of the new EMR console**

### **Convenient O&M**

-   The architecture of the cluster management page is optimized. High-frequency operations are displayed in the Actions column and key cluster information is clearly displayed.
    
-   The **All Operations** button is provided. This button provides quick access to common O&M operations on clusters.
    
-   The intelligent refresh feature is added. Cluster status is updated in real time, and page switching is smoother.
    
-   The dark mode is added to decrease eye strain. To switch to the dark mode, click the ![Toggle button](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0422912761/p412246.png) icon in the upper-right corner of the new EMR console.
    

![image..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2088553071/p670513.png)

### **Simple operations**

-   A global search box is added on the **Overview** page. You can search for a cluster by cluster name or cluster ID and go to the cluster management page.
    
-   The Cluster Fees module is added to help you obtain the status of your orders.
    
-   You can view clusters by cluster status or cluster type in the cluster list.
    

![Overview page](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2664783861/p412258.png)

### **Efficient deployment**

-   When you create a cluster, you can select services in a flexible manner based on business scenarios. The DataLake, OLAP, DataServing, Dataflow, and custom cluster types are added. The speed at which an EMR cluster is created is increased by more than two times.
    
-   More on-screen instructions and configuration verification mechanisms are provided to reduce cluster creation failures caused by invalid configurations.
    
-   A configuration list that can be modified is added. This allows you to modify cluster configuration items in a flexible manner.
