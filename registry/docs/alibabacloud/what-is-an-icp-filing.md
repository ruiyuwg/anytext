An Internet content provider (ICP) filing ensures compliance with the regulations in **Measures for the Administration of Internet Information Services** and **Registration Administration Measures for Non-Commercial Internet Information Services**. The People's Republic of China mandates an ICP filing system for non-commercial Internet information services and an ICP licensing system for commercial Internet information services. You cannot provide Internet information services without an ICP filing or a commercial ICP license for your website or application. You can apply for an ICP filing, modify ICP filing information, cancel an ICP filing, and claim ICP filing information in the Alibaba Cloud ICP Filing system.

## What happens if you do not have an ICP filing?

As mentioned above, if you want to run a website or an application by using a domain name that is resolved to a server deployed in the Chinese mainland, you must obtain an ICP filing. Otherwise, you cannot use the website or application to provide services.

-   You must obtain an ICP filing before you resolve your domain name to an Alibaba Cloud instance that is deployed in the Chinese mainland. If you do not obtain an ICP filing, the Alibaba Cloud monitoring system suspends your website or application and asks you to obtain an ICP filing.
    
-   If you have obtained an ICP filing from another service provider and you want to resolve your domain name to an Alibaba Cloud instance that is deployed in the Chinese mainland, you must add your ICP filing information to the Alibaba Cloud ICP Filing system. If you do not perform this operation, the Alibaba Cloud monitoring system suspends your website or application and asks you to add your ICP filing information to the Alibaba Cloud ICP Filing system.

The Alibaba Cloud ICP Filing system allows you to apply for an ICP filing, modify ICP filing information, cancel an ICP filing, and claim ICP filing information.

-   Apply for an ICP filing
    
    If you need to apply for an ICP filing for a website, you can purchase an Alibaba Cloud instance that is deployed in the Chinese mainland and log on to the [Alibaba Cloud ICP Filing system](https://beian.aliyun.com/order/index.htm) on a PC or the Alibaba Cloud application. Then, you can apply for an ICP filing in the Alibaba Cloud ICP Filing system.
    
    For more information about the procedure and ICP filing types, see the ICP filing application overview topic in the ICP filing documentation on the Alibaba Cloud China site (aliyun.com). For more information about how to apply for an ICP filing on a PC, see the ICP Filing for the first time topic in the ICP filing documentation on the Alibaba Cloud China site (aliyun.com).
    
-   Modify ICP filing information and cancel an ICP filing
    
    -   Modify ICP filing information
        
        **Modify ICP filing information**: After you obtain an ICP filing, you can submit a request to modify ICP filing information in the Alibaba Cloud ICP Filing system on a PC or the Alibaba Cloud application. For example, you can submit a request to modify the information of the entity, website, or application, including the administrator and domain name of your website or application.
        
    -   Remove your ICP filing information from the Alibaba Cloud ICP Filing system or cancel an ICP filing
        
        After you obtain an ICP filing, you can log on to the [Alibaba Cloud ICP Filing system](https://beian.aliyun.com/order/index.htm) on a PC or the Alibaba Cloud application to remove your ICP filing information from the Alibaba Cloud ICP Filing system or cancel an ICP filing. The procedure on the Alibaba Cloud application is the same as that on the PC.
        
        -   **Remove your ICP filing information from the Alibaba Cloud ICP Filing system**: After you remove your ICP filing information from the Alibaba Cloud ICP Filing system, the ICP filing information is dissociated from Alibaba Cloud. We recommend that you set another service provider before you remove your ICP filing information.
            
            **Warning**
            
            If you remove your ICP information before you set another service provider, the ICP filing of your website or application may become invalid. Therefore, you must set another service provider at the earliest opportunity.
            
        -   **Cancel an ICP filing**: If you no longer need to use the website or application, you must delete the website information, application information, or entity information to cancel the ICP filing.
            
-   Other services
    
    **Note**
    
    You can import or claim ICP filing information only on a PC. These operations are not supported on the Alibaba Cloud application.
    
    Import or claim ICP filing information: You can determine whether to import or claim your ICP filing information to the Alibaba Cloud ICP Filing system. For more information, see the Determine whether to import or claim the ICP filing information section in the ICP filing documentation on the Alibaba Cloud China site (aliyun.com).
    

## Usage notes

When you apply for an ICP filing in the Alibaba Cloud ICP Filing system, take note of the following limits, requirements, and regulations:

-   Limits
    
    Pay attention to the limits when you apply for an ICP filing in the Alibaba Cloud ICP Filing system. For example, you can apply for an ICP filing only for a domain name, but not an IP address. For more information, see [Limits](/help/en/icp-filing/basic-icp-service/product-overview/limits#concept-fyq-1bp-r2b).
    
-   Requirements for domain names and instances
    
    Before you apply for an ICP filing, you must verify that your website domain name and the instance that hosts your website meet the ICP filing requirements. For more information about the requirements, see [Prepare and check a domain name](/help/en/icp-filing/basic-icp-service/user-guide/prepare-and-check-the-domain-name#task-1893876) and [Prepare and check the instance and access information](/help/en/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check#concept-m5j-vrl-zdb).
    
-   Regulations
    
    The MIIT has regulations on the content and format of ICP filing information, required materials, modifications of ICP filing information, and changes in the service provider. These regulations vary among provinces, autonomous regions, and municipalities. Before you apply for an ICP filing, we recommend that you read and understand the ICP filing regulations of the MIIT for your region, and prepare the ICP filing materials as required. For more information, see the [ICP filing regulations of the MIIT for different regions](/help/en/icp-filing/basic-icp-service/user-guide/icp-filing-regulations-of-the-miit-for-different-regions) topic in the ICP filing documentation on the Alibaba Cloud China site (aliyun.com).
