Alibaba Cloud Edge Security Acceleration (ESA) provides fine-grained control over rule configuration. Content optimization rules process only requests that match specified conditions. This lets you configure comprehensive optimization rules for the domain name of your ESA site, improving your website's performance and user experience.

## **Features**

**Note**

Content optimization rules process only requests that match the specified conditions.

**Configuration item**

**Description**

[File compression](/help/en/edge-security-acceleration/esa/user-guide/file-compression)

ESA compresses static resources to reduce data transfer sizes and improve page load speeds.

[Image optimization](/help/en/edge-security-acceleration/esa/user-guide/image-optimization)

Edge Security Acceleration (ESA) provides image transformation features. It transforms the format or quality of origin images, crops and scales them, and caches the results. This improves image delivery speed and reduces back-to-origin traffic.

[Video processing](/help/en/edge-security-acceleration/esa/video-processing)

In on-demand video/audio streaming scenarios, the video processing feature of ESA provides a seamless playback experience by identifying the nearest previous keyframe to the requested playback position and loading the corresponding video segment.
