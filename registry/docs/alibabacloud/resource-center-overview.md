Resource Center allows you to view resources across accounts, services, or regions. This helps you have a global view of resources within your Alibaba Cloud accounts. Resource Center also allows you to search for resources by region, service, resource type, resource ID, resource name, or tag. After you find the resource that you want to manage, you can go to the corresponding service console with one click and perform subsequent operations. Resource Center facilitates resource searches and management.

## Features

-   **Global resource view**
    
    You can view resources that belong to different services or reside in different regions. If you use a single Alibaba Cloud account, you can view all resources within the account. If you use a resource directory to manage multiple Alibaba Cloud accounts, you can use the management account of the resource directory to view all resources within the members in the resource directory.
    
-   **Resource search**
    
    You can search for resources by region, service, resource type, resource ID, resource name, or tag.
    
-   **Resource O&M and management**
    
    After you find the resource that you want to manage, you can go to the corresponding service console with one click and perform subsequent operations. The resource details page integrates common O&M tools. For example, you can view the operation records of a resource on the details page of the resource.
    

## Benefits

-   **Easy resource searches**
    
    You can search for resources by region, service, resource type, resource ID, resource name, or tag.
    
-   **Resource visualization**
    
    The information about resources that belong to different accounts and services and reside in different regions is displayed in one view.
    
-   **Improved resource O&M and management efficiency**
    
    You can search for resources without the need to configure a custom search architecture. After you find the resource that you want to manage, you can go to the corresponding service console with one click and perform subsequent operations. On the details page of a resource in Resource Center, you can view the configuration change history and operation records of the resource. Resource Center helps you search for resources in an efficient manner and troubleshoot issues at the earliest opportunity.
    

## Resource types supported by Resource Center

Not all Alibaba Cloud services and resources are supported by Resource Center. You can view and search for only the supported resources. For more information, see [Services that work with Resource Center](/help/en/resource-management/resource-center/product-overview/services-that-work-with-resource-center#concept-2134481).

## **Billing**

This service is free of charge. You can use it immediately after you activate it.

You only need to pay for the Alibaba Cloud services that you activate. When you use the resource delivery feature to deliver data to services such as Object Storage Service (OSS) and Simple Log Service, you are charged for the services based on their billing methods.

## Feedback

If issues occur when you use Resource Center or you want to submit feedback for service improvement, you can log on to the [Resource Management console](https://resourcemanager.console.alibabacloud.com/resource-center) and click **Submit Feedback** in the upper-right corner of a resource list.
