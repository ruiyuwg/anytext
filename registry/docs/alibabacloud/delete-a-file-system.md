If you no longer need a CPFS for Lingjun file system, delete it to avoid additional charges.

**Warning**

After a file system is deleted, the data stored in it is deleted and cannot be recovered. Before you delete the file system, confirm that you no longer need the data.

1.  Log on to the [NAS console](https://nas.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, choose **File System** **>** **File System List****.**
    
3.  In the top navigation bar, select a region.
    
4.  Find the target CPFS for Lingjun file system and click **![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4264443671/p1027163.png)** > **Delete** in the Actions column.
    
5.  In the **Delete File System** dialog box, confirm the name of the file system to be deleted and click **OK**.
    
    **Note**
    
    -   Deleting a CPFS for Lingjun file system automatically deletes its mount targets.
        
    -   After you delete a CPFS for Lingjun file system instance, you will not be charged for it in the next billing cycle.
