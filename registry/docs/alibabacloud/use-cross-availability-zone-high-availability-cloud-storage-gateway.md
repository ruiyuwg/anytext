A Cloud Storage Gateway is considered compliant if it is configured for multi-zone high availability.

## **Risk level**

Default risk level: High.

You can change the risk level as needed.

## **Detection logic**

-   A Cloud Storage Gateway is considered compliant if it is configured for multi-zone high availability.
