You can temporarily ignore the evaluation result generated by a specific rule for a resource. You can also specify a time period for ignoring the evaluation result. After the period ends, the evaluation result is automatically recovered. Then, the **Evaluation Result** column of the resource displays the evaluation result.

## Procedure

1.  Log on to the [Cloud Config console](https://confignew.console.alibabacloud.com).
    
2.  Optional. In the upper-left corner, select an account group.
    
    This operation is required only if you are using a management account of a resource directory. Otherwise, you do not need to perform the operation.
    
3.  In the left-side navigation pane, choose **Compliance & Audit** > **Rules**.
    
4.  On the **Rules** page, click the rule name or click **Detail** in the **Actions** column.
    
5.  In the **Compliance Result of Related Resources** section of the **Result** tab, find the resource and click Ignore Evaluation Result in the **Actions** column.
    
6.  In the **Ignore Evaluation Result** dialog box, set **Automatic Recovery Time** and **Ignore Reason** for the resource.
    
    If you do not set the **Automatic Recovery Time** parameter, the resource is not automatically recovered. You must manually recover the resource.
    
    **Note**
    
    If you ignore the evaluation result generated by a rule for a resource, the rule still evaluates the resource. However, the evaluation result of the resource is **Ignored**.
    
7.  Click **OK**.
    
    After you configure the preceding settings, the **Evaluation Result** of the resource is **Ignored**.
    
    **Note**
    
    To recover the evaluation result generated by a rule for a resource, find the resource and click **Revert Evaluation Result** in the **Actions** column.
