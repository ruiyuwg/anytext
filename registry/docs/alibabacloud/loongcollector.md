LoongCollector is a Kubernetes log collection agent provided by Simple Log Service. Building on the log collection and processing capabilities of the Logtail component, LoongCollector extends its functionality with enhanced features.

## **Overview**

**Note**

This component is in canary release.

LoongCollector retrieves cluster data directly through Kubernetes native APIs, providing a non-intrusive solution for cluster log collection. To implement cluster log collection with the LoongCollector component, see [LoongCollector collection](/help/en/sls/loongcollector-collection/).
