After you get started with DataWorks, you already have a basic command of some core features and the working procedure of DataWorks. This topic describes the usage of more DataWorks services and provides tutorials for different business scenarios.

## **Comprehensive example: User profile analysis**

This tutorial uses a case of website user profile analysis to describe an end-to-end procedure from data synchronization, data development (data warehouse building), to data governance. DataWorks is used to quickly synchronize the information and behavior log data of website users and perform fine-grained cleansing on the information and log data to build a comprehensive model for website user profiles.

-   Tutorial link: [Comprehensive case: Analysis of website user profiles](/help/en/dataworks/user-guide/simple-user-profile-analysis/)
    
-   Compute engine required by the tutorial: MaxCompute, StarRocks, or E-MapReduce (EMR)
    
-   DataWorks services involved in the tutorial: Data Integration, Data Studio, Operation Center, Data Quality, Data Map, DataService Studio, and DataAnalysis
