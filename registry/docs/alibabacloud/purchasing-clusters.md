This topic describes how to purchase a PolarDB cluster in the PolarDB console.

## **Purchase a cluster**

**Purchase method**

**Description**

[Quick purchase](/help/en/polardb/polardb-for-mysql/user-guide/quick-purchase)

You can create a PolarDB cluster with simple configurations within minutes. This method improves your purchase efficiency.

[Custom purchase](/help/en/polardb/polardb-for-mysql/user-guide/purchase-a-pay-as-you-go-cluster)

You can create a PolarDB cluster in the following ways:

-   Create Primary Cluster: creates a new PolarDB cluster.
    
-   [Create Secondary Cluster](/help/en/polardb/polardb-for-mysql/user-guide/manage-a-secondary-cluster#section-ks2-m4q-hja): creates a secondary cluster that is deployed in a global database network (GDN).
    
-   [Upgrade/Migrate from PolarDB](/help/en/polardb/polardb-for-mysql/user-guide/overview-3#main-2251079): creates a cluster by replicating data from the source PolarDB cluster and synchronizing incremental data.
    
-   [Migrate from RDS](/help/en/polardb/polardb-for-mysql/user-guide/overview-43#task-1580301): creates a cluster by cloning the data of an ApsaraDB RDS instance and synchronizing incremental data from the ApsaraDB RDS instance to the PolarDB cluster. In most cases, this method is used for data migration.
    
-   [Clone from RDS](/help/en/polardb/polardb-for-mysql/user-guide/create-a-polardb-for-mysql-cluster-by-cloning-an-apsaradb-rds-for-mysql-instance#task-1580301): creates a PolarDB cluster by cloning the data of the selected ApsaraDB RDS instance.
    
-   [Restore from Recycle](/help/en/polardb/polardb-for-mysql/user-guide/cluster-recycle-bin/): creates a cluster by restoring a backup file of a deleted cluster from the recycle bin.
