Data Transfer Plans are easy-to-use and cost-effective traffic packages that take effect immediately after purchase. It automatically offsets the traffic fees of multiple pay-by-traffic cloud products until the Data Transfer Plan is depleted or expires.

## **Supported products and traffic types**

**Product**

**Traffic type**

**Offset description**

ECS

IPv4

IPv4 traffic from static public IP addresses of Elastic Compute Service (ECS) instances that are billed by data transfer.

EIP

IPv4 traffic from EIPs that are billed by data transfer and bound to the following cloud resources (excluding EIPs of BGP Multi-ISP Pro):

-   ECS instances in a virtual private cloud (VPC)
    
-   Secondary elastic network interfaces (ENIs)
    
-   SLB instances, including the following:
    
    -   Private-facing Classic Load Balancer (CLB) instances in a VPC
        
    -   Application Load Balancer (ALB) instances
        
    -   Network Load Balancer (NLB) instances
        
-   NAT Gateway instances
    
-   High-availability virtual IP addresses (HaVips)
    

CLB

IPv4 traffic from public IP addresses of public-facing CLB instances that are billed by data transfer.

Internet Shared Bandwidth

IPv4 traffic from Internet Shared Bandwidth instances that are billed data transfer. This does not include Data Transfer over BGP Pro Lines.

IPv6 gateway

IPv6

Public IPv6 traffic from IPv6 Internet bandwidth that is billed by data transfer.

## Benefits

-   Cost-effective
    
    Data Transfer Plans offer affordable traffic rates.
    
-   Covers multiple cloud products
    
    A Data Transfer Plan can offset the traffic fees of products such as ECS, EIP, CLB, and Internet Shared Bandwidth that are billed by data transfer. For more information, see [Supported products and traffic types](#0bf6f99d98xuf).
    
-   Easy to use
    
    After you purchase a Data Transfer Plan, it is automatically applied to products in multiple regions to offset their traffic fees. No additional configuration is required. For more information, see [Purchase a Data Transfer Plan](/help/en/dtp/user-guide/purchase-a-data-transfer-plan#task-ys4-kzx-b2b).
    
-   Centralized management
    
    Monitor your total Internet traffic usage by tracking the consumption of your Data Transfer Plan.
