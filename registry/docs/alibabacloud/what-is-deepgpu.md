DeepGPU is a collection of tools provided by Alibaba Cloud to enhance GPU computing capabilities of Elastic GPU Service. DeepGPU helps you build enterprise-level services based on Elastic GPU Service in an efficient manner. You can use Elastic GPU Service together with DeepGPU components to utilize GPU resources in Alibaba Cloud in a convenient manner. This way, you can efficiently run tasks, such as deep learning, machine learning, and big data analysis tasks.

## **Overview**

DeepGPU is a collection of free tools that provide enhanced GPU computing capabilities. You can use the tools to facilitate deployment, split GPU resources, optimize AI training and inference, and accelerate popular AI models. You can use all DeepGPU components together with Elastic GPU Service and Container Service for Kubernetes (ACK) for free. This helps you use GPU resources in Alibaba Cloud in a convenient and efficient manner.

DeepGPU includes the following components:

-   [FastGPU](/help/en/egs/what-is-fastgpu#concept-2040143)
    
-   [cGPU](/help/en/egs/what-is-cgpu#concept-2041879)
    

## **Benefits**

DeepGPU provides significant performance benefits in training and inference scenarios. You can use DeepGPU to improve computing efficiency and reduce costs. DeepGPU can help you save time and economic costs, allocate resources in a flexible manner, and implement isolation to ensure business security. For more information, see [DeepGPU](/help/en/egs/benefits-1#bceb2f10574he).

## **Billing**

DeepGPU is provided free of charge. You need to pay only for the Alibaba Cloud resources that you use to run computing tasks. In most cases, Alibaba Cloud resources that are used together with DeepGPU include Elastic Computing Service (ECS), Object Storage Service (OSS), and File Storage NAS (NAS). For more information, see [Billing for DeepGPU](/help/en/egs/shenxing-toolkit-billing).
