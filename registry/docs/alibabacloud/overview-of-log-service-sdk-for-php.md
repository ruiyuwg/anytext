The Simple Log Service PHP SDK offers comprehensive encapsulation of all API interfaces, enabling convenient access to these interfaces using PHP.

## Releases

See [aliyun-log-php-sdk releases](https://github.com/aliyun/aliyun-log-php-sdk/releases).

## Sample code

**Description**

[sample.php](https://github.com/aliyun/aliyun-log-php-sdk/blob/master/sample/sample.php)

Examples related to writing logs, querying logs, querying log distribution, shard management, and batch querying logs.

[loggerSample.php](https://github.com/aliyun/aliyun-log-php-sdk/blob/master/sample/loggerSample.php)

Examples related to creating, updating, deleting, and querying log dump tasks (called Shipper) in different formats (CSV, JSON, Parquet).

[credentialsProviderSample.php](https://github.com/aliyun/aliyun-log-php-sdk/blob/master/sample/credentialsProviderSample.php)

Examples related to writing and reading logs using static credentials.
