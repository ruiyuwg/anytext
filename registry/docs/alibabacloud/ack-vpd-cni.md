ACK VPD CNI provides container network management capabilities for Lingjun nodes in ACK managed Pro clusters. This topic describes the basic information and release history of ACK VPD CNI.

## **Introduction**

As the Container Network Interface (CNI) plugin for Lingjun nodes, ACK VPD CNI allocates and manages container network resources for nodes connected via Lingjun.

When Lingjun-connected nodes join a Container Service for Kubernetes (ACK) cluster, you must install the ACK VPD CNI component to manage the container network resources.

**Note**

Currently, only users on the whitelist can use the ACK VPD CNI component. Contact your sales or solutions team to request access.

## **Procedure**

1.  On the **Clusters** page, find the one you want to manage and click its name. In the navigation pane on the left, click **Add-ons**.
    
2.  On the **Add-ons** page, click the **Networking** tab, find ACK VPD CNI, and follow the on-screen instructions to configure and install the component.
