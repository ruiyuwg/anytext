This topic describes how to set an alert threshold for data transfer plans. After you set an alert threshold for your data transfer plan, the system sends alert notifications to you by text message and email if the remaining quota of the data transfer plan reaches the specified threshold.

## Background information

The quota alert feature for the General-purpose data transfer plan notifies you when your remaining data reaches a set percentage. This lets you purchase a General-purpose data transfer plan in a timely manner and avoid the high data charges incurred after your General-purpose data transfer plan is exhausted.

By default, an alert message is sent when the usage of a General-purpose Data Transfer Plan reaches 80%. You can also set alerts for different remaining quota percentages based on your needs or usage habits. For example, if you purchase a Shared Data Transfer Plan with a 10 GB quota and set the remaining quota percentage to 10%, the system sends an alert message when the remaining quota in the General-purpose Data Transfer Plan is 1 GB.

**Important**

Usage alerts may be delayed. Your bill reflects the actual usage. We recommend that you purchase new Data Transfer Plans in advance based on your usage.

## Procedure

1.  Log on to the [Expenses and Costs console](https://usercenter2-intl.console.alibabacloud.com/).
    
2.  In the navigation pane on the left, choose **Resource Instance Management**.
    
3.  On the **Manage Reserved Instances** page, set the Resource Type parameter to **Resource Packages**.
    
4.  On the right side of the page, click **Remaining Usage Alert Settings**. To the right of **Unified Remaining Usage Alert Settings**, turn on the **Enable Alert** switch. Select a percentage from the **Remaining Usage Percentage** list, and then click **OK**.
    
    You can also find the target General-Purpose Data Transfer Plan in the resource plan list and set a remaining quota percentage for it individually.
