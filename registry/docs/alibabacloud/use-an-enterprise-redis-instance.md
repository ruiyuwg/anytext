Checks whether the edition of an ApsaraDB for Redis instance is Enhanced Edition (Tair). If so, the evaluation result is Compliant.

## Scenarios

ApsaraDB for Redis Enhanced Edition (Tair) offers high security, high reliability, high performance, convenient management, and cost-effectiveness. It is suitable for enterprise users that require high security, high reliability, high performance, and high concurrency.

## **Risk level**

Default risk level: low.

When you apply this rule, you can change the risk level based on your business requirements.

## **Compliance evaluation logic**

-   If the edition of an ApsaraDB for Redis instance is Enhanced Edition (Tair), the evaluation result is Compliant.
    
-   If the edition of an ApsaraDB for Redis instance is not Enhanced Edition (Tair), the evaluation result is Non-compliant.
