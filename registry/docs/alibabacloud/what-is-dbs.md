Data Management (DMS) is a one-stop data management platform that allows you to manage data throughout its lifecycle. You can use DMS to manage global data assets, govern data, design and develop databases, integrate data, develop data, and consume data. The Data Disaster Recovery feature provides low-cost, highly reliable backup and recovery capabilities. The preceding features allow enterprises to mine value from data in an efficient and secure manner and help enterprises undergo digital transformation.

## Features

DMS provides a wide range of features. For more information, see [Features](/help/en/dms/product-overview/features-1#concept-2433258).

## Why DMS

-   Management of global data assets: DMS allows you to manage global data assets, provides quality governance and security governance throughout the lifecycle of data, and helps enterprises query and use data in an efficient manner.
    
-   Data integration: DMS allows you to integrate real-time and offline data from common data sources. During data integration, you can customize data processing logic in a flexible manner. This resolves operational inefficiencies that are caused by data silos.
    
-   Easy of use: DMS provides data forwarding and processing capabilities that manage data throughout its lifecycle. DMS also provides a graphical and guided development mode and various capabilities, such as intelligent warning and independent diagnostics and repair. This facilitates data mining.
    
-   Efficient collaboration: DMS provides DevOps that includes the management of data throughout its lifecycle and a built-in control system for data forwarding. For more information about DevOps, see [Manage iterations](/help/en/dms/manage-iterations). DevOps ensures data security and improves the research and development (R&D) efficiency of enterprises.
    
-   Data Disaster Recovery: DMS provides advanced features, such as flexible backup policies, instant recovery, and cross-region replication, to ensure high data availability and disaster recovery.
    

For more information, see [Benefits](/help/en/dms/product-overview/benefits#concept-2433237).

## How to use DMS

You can use the following methods to perform operations, such as data asset management, database development, data integration, and data processing in the DMS console:

-   [DMS Console](https://dms.alibabacloud.com/new): DMS provides a web-based GUI. This way, you can perform operations in an efficient manner.
    
-   [API](/help/en/dms/list-of-operations-by-function#doc-1819544): You can call API operations to perform the operations that are available in the DMS console.

## Related services

-   [Data Transmission Service (DTS)](/help/en/dts/product-overview/what-is-dts#concept-26592-zh): DTS supports data transmission among data sources such as relational database management systems (RDBMSs), NoSQL databases, and Online analytical processing (OLAP) databases. DTS provides the following features: data synchronization, data migration, change tracking, data integration, and data processing. You can use DTS to build a secure, scalable, and highly available architecture.
    
-   [ApsaraDB RDS](/help/en/rds/product-overview/what-is-apsaradb-rds-what-is-apsaradb-rds#concept-pc2-lv5-tdb): ApsaraDB RDS is a stable, reliable, and scalable online database service. ApsaraDB RDS provides a variety of solutions for disaster recovery, backup, restoration, and migration to facilitate database O&M.
    
-   [PolarDB](/help/en/polardb/polardb-for-mysql/what-is-polardb-for-mysql-enterprise-edition#concept-jpz-zb2-sdb): PolarDB is a next-generation relational database service that is developed by Alibaba Cloud. PolarDB is compatible with the MySQL, PostgreSQL, and Oracle database engines. PolarDB provides superior performance in storage and computing to meet diverse requirements of enterprises. Each PolarDB cluster provides a storage capacity of up to 100 TB and supports up to 16 nodes.
    
-   [Tair (Redis OSS-compatible)](/help/en/redis/product-overview/what-is-apsaradb-for-redis#concept-m3j-s5z-sdb): Tair (Redis OSS-compatible) is fully managed database service that is compatible with the Redis protocol and provides high performance.
    
-   [ApsaraDB for MongoDB](/help/en/mongodb/product-overview/what-is-apsaradb-for-mongodb#topic-6642): ApsaraDB for MongoDB is developed based on the Apsara distributed system and reliable storage engine, and is compatible with the MongoDB protocol. ApsaraDB for MongoDB uses a multi-node architecture to ensure high availability, and supports auto scaling, disaster recovery, backup and restoration, and performance optimization.
    
-   [AnalyticDB for MySQL](/help/en/analyticdb/analyticdb-for-mysql/product-overview/what-is-analyticdb-for-mysql#concept-n4h-2rr-vy): AnalyticDB for MySQL is a cloud-native enterprise-class data warehousing service that integrates database and big data technologies. AnalyticDB for MySQL supports high-throughput real-time data addition, removal, and modification, low-latency real-time data analysis, and complex extract, transform, and load (ETL) operations. AnalyticDB for MySQL is compatible with upstream and downstream ecosystem tools and can be used to build enterprise-class report systems, data warehouses, and data service engines.
    
-   [AnalyticDB for PostgreSQL](/help/en/analyticdb/analyticdb-for-postgresql/product-overview/overview-product-overview#concept-ltd-l1r-52b): AnalyticDB for PostgreSQL is a data warehouse for massively parallel processing (MPP). AnalyticDB for PostgreSQL provides online analysis services for a large amount of data.
    
-   [Object Storage Service (OSS)](/help/en/oss/user-guide/what-is-oss#concept-ybr-fg1-tdb): OSS is a secure, cost-effective, and highly reliable cloud storage service that is provided by Alibaba Cloud. OSS allows you to store a large amount of data in the cloud.
