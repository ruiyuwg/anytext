This topic describes how to enable the S3 compatibility feature. By default, this feature is disabled.

## **Limits**

Lindorm standalone instances do not support the S3 compatibility feature.

## Enable S3 compatibility

1.  Log on to the [Lindorm console](https://lindorm.console.alibabacloud.com/cn-hangzhou/clusterhou/cluster).
    
2.  In the upper-left corner of the page, select the region where the instance is deployed.
    
3.  On the **Instances** page, click the ID of the target instance or click **View Instance Details** in the **Actions** column for the instance.
    
4.  In the navigation pane on the left, click **Database Connections**. The **Wide Table Engine** tab is displayed by default.
    
5.  In the **Other ways to connect to the database** section, under **By** **S3****Compatible address connection**, click **Enable** **S3 Compatibility**.
    
6.  In the dialog box, click **OK**.
