During daily O&M of ApsaraDB RDS for PostgreSQL instances, you can use Database Autonomy Service (DAS) to handle instance failures, optimize instance performance, improve efficiency, and reduce O&M costs. DAS is a cloud service that is developed based on machine learning and expert experience. DAS provides self-awareness, self-healing, self-optimization, self-O&M, and self-securing capabilities to simplify database O&M and ensure the stability, security, and efficiency of database services.

## Function description

Autonomy services that are provided by ApsaraDB RDS for PostgreSQL have the following features:

-   [Autonomy center](/help/en/rds/apsaradb-rds-for-postgresql/use-the-autonomy-center-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2293947)
    
    This feature allows you to specify a time range and view events such as exceptions, optimization events, and auto scaling events within the specified time range.
    
-   [Session management](/help/en/rds/apsaradb-rds-for-postgresql/use-the-session-management-feature-for-an-apsaradb-rds-for-postgresql-instance-1#concept-1545909)
    
    This feature is used to view, export, and close the sessions of your RDS instance.
    
-   [Real-time monitoring](/help/en/rds/apsaradb-rds-for-postgresql/use-the-real-time-monitoring-feature-for-an-apsaradb-rds-for-postgresql-instance#task-1597420)
    
    This feature is used to view the real-time performance of your RDS instance.
    
-   [Storage analysis](/help/en/rds/apsaradb-rds-for-postgresql/use-the-storage-analysis-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2172390)
    
    This feature allows you to view the storage usage of your RDS instance. For example, you can view the remaining days for which storage is available, the storage usage of individual tables, the tablespace fragments, and the storage exception diagnosis. You can use this feature to identify the storage exceptions at the earliest opportunity to ensure business stability.
    
-   [Performance insight](/help/en/rds/apsaradb-rds-for-postgresql/use-the-performance-insight-feature-for-an-apsaradb-rds-for-postgresql-instance#concept-xrn-2hc-dhb)
    
    This feature is used to monitor loads, analyze data, and optimize performance. You can use this feature to evaluate the loads of your RDS instance and identify the root causes of performance issues to improve the stability of your RDS instance.
    
-   [Performance trend](/help/en/rds/apsaradb-rds-for-postgresql/use-the-performance-trends-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2172467)
    
    This feature allows you to view performance trends over specified time ranges, compare performance trends, and customize charts to view the performance trends of your RDS instance.
    
-   [Slow SQL statement analysis](/help/en/rds/apsaradb-rds-for-postgresql/use-the-slow-query-log-analysis-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2172487)
    
    This feature is used to check the trends, execution, and optimization suggestions for slow query logs of your RDS instance.
    
-   [SQL Explorer and Audit](/help/en/rds/apsaradb-rds-for-postgresql/sql-insight-or-audit#task-2170152)
    
    This feature is based on the full request analysis and security audit capabilities and is integrated with the SQL statement search feature and the SQL Explorer feature. You can use the SQL Explorer and Audit feature to query information about the SQL statements that are executed on your RDS instance. Then, you can use the information to troubleshoot various performance issues.
    
-   [Monitoring dashboard](/help/en/rds/apsaradb-rds-for-postgresql/use-the-monitoring-dashboard-feature#task-2214173)
    
    This feature allows you to specify RDS instances and metrics to monitor and compare the metrics of the RDS instances. You can also configure metric linkage. This helps you monitor your RDS instances.
    
-   [Event alerting](/help/en/rds/apsaradb-rds-for-postgresql/use-the-event-subscription-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2294026)
    
    This feature is used to send you notifications when specified events occur. You can specify a notification method based on your business requirements.
    
-   [Automatic SQL optimization](/help/en/rds/apsaradb-rds-for-postgresql/use-the-automatic-sql-optimization-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2294027)
    
    This feature is used to automatically analyze and optimize your SQL queries and create indexes. This helps you quickly resolve issues related slow SQL queries and ensure the optimal performance of your RDS instance.
    
-   [Automatic storage expansion](/help/en/rds/apsaradb-rds-for-postgresql/use-the-automatic-storage-expansion-feature-for-an-apsaradb-rds-for-postgresql-instance#task-2294029)
    
    This feature is used to automatically expand the storage capacity of your RDS instance when the used storage of your RDS instance is greater than or equal to the specified threshold. This helps ensure the business stability.
