## Issue

Where can I view details about the resource plan after I purchase a resource plan of Alibaba Cloud CDN on the [CDN Resource Plan](https://common-buy-intl.aliyun.com/?commodityCode=%20cdn_bag_intl#/buy) page?

## Solution

Check your purchase history of resource plans. For more information, see [Query the details of resource plans](/help/en/cdn/product-overview/query-the-details-of-resource-plans-1#concept-2047427). To view resource plans that you have purchased, perform the following steps:

1.  Log on to the [Alibaba Cloud CDN](https://cdn.console.alibabacloud.com) console.
    
2.  In the top navigation bar, click **Expenses**.
    
3.  In the left-side navigation pane, click **Manage Reserved Instances**.
    
4.  Set **Resource Type** to **Resource Packages**.
    
5.  Click the **Details** tab.
    
6.  View details of the resources plans.
