Apsara PolarDB supports Node.js, Java, Go, PHP,. NET, and Python.

The following table lists the download links and development guides for different SDKs. For more information about SDKs, see [AlibabaCloud Open Platform](https://open.alibabacloud.com/sdk).

**Note**

The SDKs described in this topic are only used to call the OpenAPI operations of PolarDB. For example, you can use SDKs to call OpenAPI operations such as [CreateDBCluster](/help/en/polardb/polardb-for-mysql/api-createdbcluster#doc-api-polardb-CreateDBCluster) and [ModifyDBClusterParameters](/help/en/polardb/polardb-for-mysql/api-modifydbclusterparameters#doc-api-polardb-ModifyDBClusterParameters), but you cannot use SDKs to call operations to add, delete, modify, or query data. For more information about the OpenAPIs of PolarDB, see [API overview](/help/en/polardb/polardb-for-mysql/api-overview#doc-65206).
