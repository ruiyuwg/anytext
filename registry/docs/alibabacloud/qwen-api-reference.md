Alibaba Cloud Model Studio provides multiple interfaces for Qwen:

-   [OpenAI Chat Completion](/help/en/model-studio/qwen-api-via-openai-chat-completions): Mature community ecosystem. Offers the lowest cost for migrating existing applications or integrating third-party tools.
    
-   [OpenAI Responses](/help/en/model-studio/qwen-api-via-openai-responses): Includes built-in web search, code interpreter, and web extractor tools, and requires no manual maintenance of conversation history.
    
-   [DashScope](/help/en/model-studio/qwen-api-via-dashscope): Native interface from Model Studio. Offers the most complete set of features and parameters.
