This topic describes how to configure the DNS servers of your domain name registered with Xinnet to Alibaba Cloud DNS.

## **Configuration method**

1.  Log on to the [Xinnet homepage](http://www.xinnet.com/index.html), and click the **Console** button at the top of the page.
    
2.  Click the **Domain Names** button in the left-side navigation pane.
    
3.  On the **Domain Name Service** page, click **Domain Name Management**.
    
4.  On the **Domain Name Management** page, click the **Manage** button next to the target domain name.
    
5.  After the page opens, click **More Domain Information** and then click the **Enter Management** button.
    
6.  On the new page that opens, click the **Modify DNS** button.
    
7.  On the **Modify Domain DNS** page, select **Use Non-Xinnet DNS**, enter the DNS server names allocated by Alibaba Cloud DNS in the input box, and click **Submit** to complete the configuration.
    
    **Note**
    
    If you do not know the DNS server names allocated in the Alibaba Cloud DNS system, see [View DNS server status](/help/en/dns/pubz-view-dns-server-status-and-exception-handling#2977dbc544lrs).
    
8.  After the configuration is complete, please wait patiently for the DNS server configuration to take effect. Theoretically, global propagation takes 48 hours.
