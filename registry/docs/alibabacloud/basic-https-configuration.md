Configure SSL/TLS rules to apply different encryption policies based on the request hostname. You can enforce HTTPS redirection, enable opportunistic encryption, and configure HSTS to ensure browsers access HTTP links over encrypted TLS connections and use HTTPS exclusively. This enhances security.

## **Features overview**

**Configuration item**

**Description**

[SSL/TLS rules](/help/en/edge-security-acceleration/esa/user-guide/ssl-tls-rules)

Use SSL/TLS rules to apply different SSL/TLS encryption policies to requests for different hostnames.

[HTTPS rules](/help/en/edge-security-acceleration/esa/user-guide/https-application-configuration)

By configuring rules, you can enforce HTTPS connections between clients and Edge Security Acceleration (ESA) points of presence (POPs). You can also enable opportunistic encryption and configure the HTTP Strict Transport Security (HSTS) feature to ensure that the browser accesses HTTP links through an encrypted TLS connection, forcing the client to use HTTPS connections to enhance security.
