PolarDB provides multiple data synchronization solutions for seamlessly synchronizing data between different databases without affecting your business.

[Data Transmission Service (DTS)](/help/en/dts/product-overview/what-is-data-transmission-service#concept-1917748) allows you to synchronize data between PolarDB databases in real time.
