## **SDK usage notes**

-   Alibaba Cloud provides [OpenAPI Explorer](https://next.api.alibabacloud.com/product/ResourceCenter) to simplify API usage. You can use OpenAPI Explorer to debug API operations and dynamically generate SDK sample code.
    
-   For more information about how to obtain an AccessKey pair, see [Create an AccessKey pair](/help/en/ram/user-guide/create-an-accesskey-pair#task-2245479).
    
-   For more information about Resource Center API operations, see [List of operations by function](/help/en/resource-management/resource-center/developer-reference/api-resourcecenter-2022-12-01-overview).
