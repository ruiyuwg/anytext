If an Alibaba Cloud account that is not the management account or a member of a resource directory is added to a resource share as a principal, the principal can exit the resource share.

## Limits

-   A principal can exit a resource share only if the principal is not the management account or a member of a resource directory. If a principal is the management account or a member of a resource directory, the principal cannot exit a resource share. Instead, the principal can be removed only by the resource owner.
-   If a resource share contains one or more types of resources that do not support exit from the resource share, the principals in the resource share cannot exit the resource share. In this case, the principals can be removed from the resource share only by the resource owner. For more information about the types of resources that support exit from a resource share, see the **Support for exit from a resource share** column in the Services that work with Resource Sharing section of [Services that work with Resource Sharing](/help/en/resource-management/resource-sharing/product-overview/services-that-work-with-resource-sharing#concept-2247844).

## Procedure

1.  Log on to the [Resource Management console](https://resourcemanager.console.alibabacloud.com/resource-share).
2.  In the left-side navigation pane, choose **Resource Sharing** > **Resources Shared To Me**.
3.  On the **Resources Shared To Me** page, find the desired resource share and click its ID.
4.  In the upper-right corner of the page that appears, click **Exit Resource Share**.
5.  In the **Exit Resource Share** message, click **OK**.
