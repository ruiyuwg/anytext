Hybrid Cloud Monitoring provides the high precision monitoring feature. This feature applies to scenarios where high-precision metric data is required for a cloud service. You can enable high precision monitoring for one or more metrics of a cloud service with a few clicks.

## Procedure

1.  Log on to the [CloudMonitor console](https://cloudmonitor.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, choose **Hybrid Cloud Monitoring** > **High Precision Monitoring**.
    
3.  On the **High Precision Monitoring** page, turn on **High Precision Monitoring** for the cloud service that you want to monitor.
    
4.  In the **Tips** message, click **OK**.
    
    Enable high precision monitoring for all metrics of the cloud service.
    

## Related operations

-   On the **High Precision Monitoring** page, turn off **High Precision Monitoring** to disable high precision monitoring for the cloud service.
    
-   In the upper-right corner of the **High Precision Monitoring** page, click **Monitoring Charts**. You can view the monitoring chart that displays all metrics that support high precision monitoring of the cloud service.
