This topic describes how to view the ID of an Alibaba Cloud account.

1.  Log on to the [Alibaba Cloud Management Console](https://home.console.alibabacloud.com) with your Alibaba Cloud account.
    
2.  Move the pointer over the profile picture in the upper-right corner. The value of **Account ID** is the ID of your Alibaba Cloud account.
