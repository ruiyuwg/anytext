Simple Log Service provides the scheduled SQL feature for automatic data analysis, aggregation, projection, and filtering at regular intervals.

Simple Log Service allows for the use of scheduled SQL to process data from a source logstore and direct it to a destination logstore or metricstore. It also facilitates the transfer of data from a source metricstore to a destination metricstore. For more information, see the following topics:

-   [Process and save data from one logstore to another](/help/en/sls/logstore-import-logstore)
    
-   [Process and save data from a logstore to a metricstore](/help/en/sls/logstore-import-metricstore)
    
-   [Process and save data from one metricstore to another](/help/en/sls/metricstore-import-metricstore)
