This topic provides an overview of instance types for YiTian read-only ApsaraDB RDS for MySQL instances that originally use the ARM architecture. This overview includes the most recent instance types and the specifications for each instance type.

**Note**

-   For more information about how to create a read-only RDS instance, see [Create a read-only ApsaraDB RDS for MySQL instance](/help/en/rds/apsaradb-rds-for-mysql/create-a-read-only-apsaradb-rds-for-mysql-instance#concept-ghp-wq5-vdb).
    
-   The subscription and pay-as-you-go billing methods are supported for read-only RDS instances. For more information, see [Instance types for read-only ApsaraDB RDS instances](/help/en/rds/product-overview/read-only-apsaradb-rds-instance-types#section-8h0-4ki-ap2). For more information about the prices, visit the ApsaraDB RDS buy page.
    
-   The maximum number of connections in this topic indicates the maximum number of processes that can be connected to the RDS instance at a time.
