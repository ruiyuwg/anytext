This topic describes how to view the information, such as the basic information and security settings, about a Resource Access Management (RAM) user. This topic also describes how to view the RAM user groups to which a RAM user is added, the policies that are attached to a RAM user, the events that are performed by a RAM user and recorded by ActionTrail, and permission access records.

## Procedure

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) as a RAM user who has administrative rights.
    
2.  In the left-side navigation pane, choose **Identities** > **Users**.
    
3.  On the **Users** page, view the RAM user list.
    
    You can click the ![setting.jpg](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0423401961/p701166.jpg) icon in the upper-right corner of the list to specify the columns that you want to be displayed on the Users page.
    
4.  Click the name of a RAM user to view the details of the RAM user.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4284228471/p950453.png)
    
    -   In the **Basic Information** section, view the logon name, UID, display name, and creation time of the RAM user.
        
    -   On the **Authentication** tab, view the console logon settings and security settings of the RAM user.
        
    -   On the **Groups** tab, view the RAM user groups to which the RAM user is added.
        
    -   On the **Permissions** tab, view the policies that are attached to the RAM user.
        
    -   On the **Events** tab, view the events that are performed by the RAM user and recorded by ActionTrail.
        
    -   On the **Policy Access Beta** tab, view the permission access records of the RAM user. For more information, see [Overview](/help/en/ram/overview-of-permissions-audit).
