With the MLOps capabilities provided by PolarDB for AI, you can also upload, deploy, and use externally trained models. A wide array of external models are supported, such as sklearn-compatible LightGBM and GBDT and algorithms created using deep learning frameworks like TensorFlow and PyTorch.

To load an external model, do the following steps:

-   [Upload a model](/help/en/polardb/polardb-for-mysql/model-management#section-fxy-ujo-1r5)
    
-   [Deploy a model](/help/en/polardb/polardb-for-mysql/model-management#section-usm-ybd-vog)
    
-   [Evaluate a model](/help/en/polardb/polardb-for-mysql/model-management#section-ald-y92-4gh)
    
-   [Perform model inference](/help/en/polardb/polardb-for-mysql/model-management#section-tj6-52f-tgd)
