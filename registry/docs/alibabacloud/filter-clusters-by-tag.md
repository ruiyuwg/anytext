After you bind tags to PolarDB clusters, you can filter clusters by tag to find the required clusters.

## Procedure

1.  Log on to the [PolarDB console](https://polardb.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, click **Clusters**.
    
3.  In the top navigation bar, select the region in which the cluster that you want to manage is deployed.
    
4.  On the **Clusters** page, click **Filter by Tag** and select the tag.
    
    ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2771138071/p742584.png)
    
5.  If you select the tag, all clusters to which the tag is bound are displayed on the **Clusters** page.
