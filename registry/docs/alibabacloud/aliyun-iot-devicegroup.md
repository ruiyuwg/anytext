ALIYUN::IOT::DeviceGroup is used to create a group.

You can create a group in the following regions:

-   Shanghai
-   Singapore (Singapore)
-   Japan (Tokyo)
-   Germany (Frankfurt)
-   US (Silicon Valley)
-   US (Virginia)

## Syntax

```
{
  "Type": "ALIYUN::IOT::DeviceGroup",
  "Properties": {
    "SuperGroupId": String,
    "GroupName": String,
    "GroupDesc": String,
    "IotInstanceId": String
  }
}
```

## Properties

     

Parameter

Type

Required

Editable

Description

Constraint

SuperGroupId

String

No

Released

The ID of the parent group. To create a level -1 group, do not specify this parameter.

None

GroupName

String

Yes

Not supported

The name of a device group.

The name must be 4 to 30 characters in length, and can contain Chinese characters, uppercase letters, lowercase letters, digits, and underscores (\_).

**Note** A Chinese character occupies two characters.

GroupDesc

String

Not supported

Supported

The description of the API group.

The length cannot exceed 100 characters.

**Note** A Chinese character occupies two characters.

IotInstanceId

String

No

Released

The ID of the instance.

This parameter is not required for public instances.

## Return value

Fn::GetAtt

-   GroupId: The group ID, which is the globally unique identifier generated by the system for the group.
-   IotInstanceId: The ID of the instance.
