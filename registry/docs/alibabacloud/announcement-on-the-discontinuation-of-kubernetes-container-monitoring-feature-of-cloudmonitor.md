Dear Alibaba Cloud users, to provide better container service monitoring capabilities, the Kubernetes container monitoring feature in CloudMonitor will gradually transition into Managed Service for Prometheus. CloudMonitor plans to discontinue the Kubernetes container monitoring feature on September 30, 2025, at 00:00:00 (UTC+8). Starting from April 14, 2025, at 00:00:00 (UTC+8), new users no longer have access to the Kubernetes container monitoring feature in CloudMonitor.

## Recommendations

We recommend that you use Managed Service for Prometheus for container monitoring. Managed Service for Prometheus is better integrated with Container Service for Kubernetes (ACK) and provides richer metrics and built-in dashboards. For more information, see [Monitor an ACK cluster](/help/en/prometheus/container-observable).

## **Impacts**

Existing container clusters are not affected before the Kubernetes container monitoring feature of CloudMonitor is discontinued. We apologize for any inconvenience caused by this change to the Kubernetes container monitoring feature in CloudMonitor. If you have any questions, you can [submit a ticket](https://smartservice.console.alibabacloud.com/service/create-ticket-intl) or call service hotline.
