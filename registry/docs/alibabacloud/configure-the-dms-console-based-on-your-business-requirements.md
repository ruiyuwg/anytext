Data Management (DMS) allows you to customize the layout and style of the DMS console based on your business requirements. This topic describes how to customize your DMS console.

The DMS console supports two modes: simple mode and normal mode.

## Simple mode

1.  Log on to the [DMS console V5.0](https://dms.alibabacloud.com/new).
2.  Configure the items based on your business requirements.
    
    **Item**
    
    **Description**
    
    Frequently Used Features
    
    Show your recent DMS features.
    
    Skins
    
    Select the blue skin (default) or dark skin for the DMS console.
    
    For more information, see [Simple mode](/help/en/dms/simple-mode).
    

## Normal mode

1.  Log on to the [DMS console V5.0](https://dms.alibabacloud.com/new).
2.  On the right side of the top navigation bar, click the ![5设置](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4856580461/p348735.png) icon to view the items that you can configure.
    
3.  Configure the items based on your business requirements.
    
    **Item**
    
    **Description**
    
    Drop-down Menus in Top Navigation Bar
    
    By default, the **Drop-down Menus in Top Navigation Bar** switch is turned on. If you turn on this switch, a drop-down menu appears when you click a top-level directory in the top navigation bar, which allows you to quickly access the features under the directory.
    
    **Note**
    
    After you turn off this switch, you can access the features through the left-side navigation pane on the page.
    
    Content Displayed in Left-side Navigation Pane
    
    After you turn on Drop-down Menus in Top Navigation Bar, you can determine the objects to be displayed in the left-side navigation pane by configuring this item. Valid values:
    
    -   Tabs: The second-level and third-level menus are displayed in the left-side navigation pane.
        
        **Note**
        
        If you turn off Drop-down Menus in Top Navigation Bar, only menus are displayed in the left-side navigation pane.
        
    -   Resources: The instance list is displayed on the left side of the page.
        
    
    Shortcuts
    
    By default, the Shortcuts switch is turned on. If you turn on Shortcuts, you can click **Shortcuts** below the top navigation bar. In the dialog box that appears, click the ![5星号](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0188490461/p348977.png) icon to the right of a feature to add the feature to the section to the right of Shortcuts.
    
    Show Tabs
    
    By default, the Show Tabs switch is turned on. If you turn on Show Tabs, you can view and use multiple features. Each feature is displayed on a tab. You can drag the tabs to adjust the order in which the tabs are displayed.
    
    **Note**
    
    If you turn off Show Tabs, you can view and use only one feature at a time. The feature that you view and use is displayed on a tab.
    
    Skins
    
    Select the blue skin (default) or the dark skin for the DMS console.
