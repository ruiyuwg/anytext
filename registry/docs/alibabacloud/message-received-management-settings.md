Use the Message Center to control how you receive notifications from Alibaba Cloud. You can customize notification methods and manage contacts to ensure you receive critical alerts and updates promptly.

## Set notification methods and contacts

1.  Log on to the **[Message Center console](https://notifications-intl.console.alibabacloud.com/innerMsg/unread/)**.
    
2.  In the navigation pane on the left, go to **Common Settings**.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989504.png)
    
3.  Under **Receiving Channel**, select or clear the checkboxes for **Email**, **Text Message**, or **Internal Message** to set your preferred delivery method for each message type.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989536.png)
    

### **Customize message settings**

To fine-tune notifications for a specific message type, click **Modify** under **Actions** column. You can then:

-   Set message limits per channel.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989549.png)
    
-   Assign one or more contacts to receive the notifications.![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989667.png)
    
-   Filter messages using keyword-based rules.![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989707.png)
    
-   View the revision history for the message type.![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989712.png)
    

## **Add a new contact**

1.  On the **Basic Message Receiving** page, click **Manage Message Contacts** in the upper-right corner.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p990006.png)
    
2.  Click **Add Message Contact** to create a contact.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p990131.png)
    
    To edit an existing contact, click **Modify** in the **Actions** column.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p990132.png)
    

## **Set the notification language**

1.  On the **Basic Message Receiving** page, click **Set Message Language** in the upper-right corner.
    
2.  Select your preferred message language from the list.
    

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989665.png)

**Note**

This setting applies only to new messages. Previously sent messages will retain their original language.

## **Unsubscribe from event messages**

To stop receiving promotional or event-related messages:

1.  Go to the **Event Messages** tab.
    
2.  Click **Unsubscribe**.
    

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8561783571/p989717.png)
