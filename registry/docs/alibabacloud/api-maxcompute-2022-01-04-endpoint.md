This topic lists the public and VPC endpoints for the MaxCompute API (version 2022-01-04) across all supported regions. Use these endpoints to call the MaxCompute API programmatically.

## Endpoint format

MaxCompute endpoints follow a consistent naming pattern:

-   **Public endpoint**: `maxcompute.<region-id>.aliyuncs.com`
    
-   **VPC endpoint**: `maxcompute-vpc.<region-id>.aliyuncs.com`
    

All endpoints use the HTTPS protocol.

## Public endpoint vs. VPC endpoint

**Type**

**When to use**

Public endpoint

Access MaxCompute from the internet or from resources outside Alibaba Cloud.

VPC endpoint

Access MaxCompute from resources within a VPC in the same region. Traffic to VPC endpoints does not traverse the public internet.
