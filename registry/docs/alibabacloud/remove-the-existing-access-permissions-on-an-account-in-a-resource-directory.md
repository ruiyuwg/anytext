This topic describes how to remove the existing access permissions on an account in a resource directory from a user or group.

## Procedure

1.  Log on to the [CloudSSO console](https://cloudsso.console.alibabacloud.com).
    
2.  In the navigation pane on the left, click **Multi-account Permission Configuration**.
    
3.  On the **Multi-account Permission Configuration** page, click the name of the required account.
    
4.  On the page that appears, click the **Access Assignments** tab.
    
5.  Find the required user or group and click **Remove Access Assignments** in the **Actions** column.
    
6.  In the **Remove Access Assignments** dialog box, select the permission that you want to remove and click **OK**.
    
7.  Click **Complete**.
