After you create an ApsaraDB for MongoDB instance, the system automatically creates a root user in the admin database. You can log on to a database as the root user to create other users and grant them permissions.

For more information about how to create a database account, see the following topics:

-   [Use DMS to manage database accounts](/help/en/mongodb/user-guide/use-dms-to-manage-database-accounts#task-2224072)
-   [Use the mongo shell to manage database accounts](/help/en/mongodb/user-guide/use-mongo-shell-to-manage-database-accounts#task-2225841)
-   [Manage user permissions on MongoDB databases](/help/en/mongodb/user-guide/manage-user-permissions-on-mongodb-databases#section-tpv-ktc-7qq)
