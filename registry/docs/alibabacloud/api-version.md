Alibaba Cloud API uses version numbers to manage the lists of operations of major versions of cloud service APIs. For example, ApsaraDB RDS currently supports the list of operations of version `2014-08-15`. `2014-08-15` is an API version number rather than a date. Users are presented with the latest public information about the API. `2014-08-15` is not the last update date of the API.

### **View the API version**

1.  Log on to [Alibaba Cloud OpenAPI Explorer](https://api.alibabacloud.com/).
    
2.  Move the pointer over Cloud Products in the top navigation bar and select a cloud service.
    
3.  On the homepage of the cloud service, view the API version on the **API Overview** tab. The following figure shows the API versions of [OCR](https://api.aliyun.com/product/ocr-api?tab=apis).
