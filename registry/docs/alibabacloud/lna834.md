Checks whether the difference between the expiration time of each subscription Server Load Balancer (SLB) instance and the current time is greater than a specified value. If so, the evaluation result is Compliant.

## Scenarios

This rule applies when you need to check the remaining validity period of subscription SLB instances. This prevents your business from being interrupted due to an expired instance.

## Risk level

Default risk level: high.

When you apply this rule, you can change the risk level based on your business requirements.

## Compliance evaluation logic

-   If the difference between the expiration time of each subscription SLB instance and the current time is greater than a specified value, the evaluation result is Compliant.
-   If the difference between the expiration time of each subscription SLB instance and the current time is less than or equal to a specified value, the evaluation result is Incompliant.
