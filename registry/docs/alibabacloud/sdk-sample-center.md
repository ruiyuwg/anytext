This topic describes how to view and submit SDK samples for specific scenarios in Alibaba Cloud OpenAPI Explorer.

## View SDK samples for specific scenarios

You can go to [Sample Code Center](https://api.alibabacloud.com/api-tools/demo) and view the scenario-specific samples of cloud services. The following figure shows how to view the scenario-specific samples of [Virtual Private Cloud (VPC)](/help/en/vpc/what-is-vpc).

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1383060271/p819604.png)

## **Submit SDK samples for specific scenarios**

As an open platform, Alibaba Cloud OpenAPI Explorer warmly welcomes senior developers to submit SDK samples to help beginner developers. The following sections describe the entry points and examples of submitting scenario-specific samples to OpenAPI Explorer.

Go to [Sample Code Center](https://api.alibabacloud.com/api-tools/demo) and select a cloud service. On the sample code page of the cloud service, click **Submit Sample Code** in the upper-right corner to go to the [My Contributions](https://api.alibabacloud.com/community/contribution/code_sample/my) page and submit sample code. For more information about how to create a scenario-specific sample, see [SDK Sample Code Contribution Guide](https://api.alibabacloud.com/community/document/code_sample/).
