### API actions

**Action**

**Description**

[ACS::ExecuteAPI](/help/en/oos/user-guide/acs-executeapi#topic9410)

Calls an API operation of a cloud service.

[ACS::WaitFor](/help/en/oos/user-guide/acs-waitfor#topic-1869809)

Calls an API operation to query the status of a resource until the resource enters the expected state.

[ACS::CheckFor](/help/en/oos/user-guide/acs-checkfor#topic5414)

Calls an API operation to check whether a resource is in the expected state.

[ACS::ExecuteHttpRequest](/help/en/oos/user-guide/acs-executehttprequest)

Calls an external API operation by using an HTTP or HTTPS request.

### Trigger actions

**Action**

**Description**

[ACS::TimerTrigger](/help/en/oos/user-guide/acs-timertrigger#topic2900)

Triggers an action at the specified point in time.

[ACS::AlarmTrigger](/help/en/oos/user-guide/acs-alarmtrigger)

Triggers an action when a metric reaches the alert threshold.

[ACS::EventTrigger](/help/en/oos/user-guide/acs-eventtrigger#topic5110)

Triggers an action when a specific event occurs.

### Control actions

**Action**

**Description**

[ACS::Approve](/help/en/oos/user-guide/acs-approve#topic8697)

Approves the execution of an O&M task.

[ACS::Choice](/help/en/oos/user-guide/acs-choice#topic7030)

Selects the O&M tasks to be executed based on the specified conditions.

[ACS::Notify](/help/en/oos/user-guide/acs-notify#topic6397)

Sends notifications when an O&M task is complete.

[ACS::Sleep](/help/en/oos/user-guide/acs-sleep#topic560)

Blocks a template for a period of time.

[ACS::SelectTargets](/help/en/oos/user-guide/acs-selecttargets)

Selects multiple resources at a time when you create an execution.
