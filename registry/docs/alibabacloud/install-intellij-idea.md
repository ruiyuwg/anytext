This topic describes how to install the basic platform IntelliJ IDEA of MaxCompute Studio. MaxCompute Studio is a plug-in that runs on IntelliJ IDEA.

## Prerequisites

IntelliJ IDEA can be installed on the Windows, macOS, and Linux operating systems. For more information about requirements on hardware and operating systems, see [Requirements for IntelliJ IDEA](https://www.jetbrains.com/help/idea/2016.3/requirements-for-intellij-idea.html).

## Procedure

1.  Click [IntelliJ IDEA](https://www.jetbrains.com/idea/?spm=5176.doc50889.2.1.0ohIYs) to download IntelliJ IDEA based on your operating system, such as Windows, macOS, or Linux. The Windows operating system is used in the following example, and supports IntelliJ IDEA 14.1.4 or later.
    
    **Important**
    
    -   IntelliJ IDEA includes Ultimate Edition, and free Community Edition.
        
    -   You must install IntelliJ IDEA version 2024.2.5 or earlier. This is because the latest version of MaxCompute Studio, version 4.3.0, is compatible with IntelliJ IDEA up to version 2024.2.5. Please choose a suitable Studio version based on your development tool.
        
    
2.  After IntelliJ IDEA is downloaded, double-click the installer to start the setup wizard, and click **Next**.
    
    ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/12116/15452072091503_en-US.png)
    
3.  Specify the destination folder and click **Next**.
    
    ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/12116/15452072091504_en-US.png)
    
4.  Select your operating system and click **Next**.
    
    ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/12116/15452072091507_en-US.png)
    
5.  Click **Install**.
    
    ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/12116/15452072091508_en-US.png)
    
6.  After IntelliJ IDEA is installed, click **Finish**.
    
    ![](https://help-static-aliyun-doc.aliyuncs.com/assets/img/12116/15452072091511_en-US.png)
    

## What to do next

Install MaxCompute Studio. For more information, see [Install MaxCompute Studio](/help/en/maxcompute/user-guide/install-maxcompute-studio#task-2456397).
