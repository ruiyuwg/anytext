Serverless Devs is an open source platform for serverless application developers. You can use Serverless Devs to manage the full lifecycle of an application. This topic describes the YAML syntax, permission management, and commands of Serverless Devs that can be used for the full lifecycle management.

## YAML syntax and permission management

You can visit the following pages to view the details and permission policies for the fields in the YAML syntax.

-   [service](https://github.com/devsapp/fc/blob/main/docs/en/yaml/service.md)
    
-   [function](https://github.com/devsapp/fc/blob/main/docs/en/yaml/function.md)
    
-   [triggers](https://github.com/devsapp/fc/blob/main/docs/en/yaml/triggers.md)
    
-   [customDomains](https://github.com/devsapp/fc/blob/main/docs/en/yaml/customDomains.md)

## Integration with continuous integration and continuous delivery (CI/CD) platforms or tools

Serverless Devs can integrate with platforms or tools such as GitHub Actions, GiteeGo, Jenkins, or Alibaba Cloud DevOps to implement continuous integration and continuous delivery (CI/CD). For more information, see [Integration with CI and CD platforms and tools](https://github.com/Serverless-Devs/Serverless-Devs/blob/master/docs/en/cicd.md).
