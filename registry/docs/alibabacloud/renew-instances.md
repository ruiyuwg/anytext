You can renew a subscription Data Transmission Service (DTS) instance for up to seven days after it expires. After this grace period, the instance is released and cannot be recovered. To prevent service interruptions, you can manually renew the instance or enable auto-renewal before it expires.

**Note**

Pay-as-you-go instances are billed in real time based on usage and do not need to be renewed. You must ensure that your account has a sufficient balance.

## Manually renew an instance

1.  Use one of the following methods to go to the Data Synchronization or Change Tracking task page and select the region in which the data synchronization or change tracking task resides.
    
    ### DTS console
    
    1.  Log on to the [DTS console](https://dts.alibabacloud.com/).
        
    2.  In the left-side navigation pane, click **Data Synchronization** or **Change Tracking**.
        
    3.  In the upper-left corner of the page, select the region in which the DTS instance resides.
        
    
    ### DMS console
    
    **Note**
    
    The actual operation may vary based on the mode and layout of the DMS console. For more information, see [Simple mode](/help/en/dms/simple-mode) and [Customize the layout and style of the DMS console](/help/en/dms/configure-the-dms-console-based-on-your-business-requirements).
    
    1.  Log on to the [DMS console](https://dms.alibabacloud.com).
        
    2.  In the top navigation bar, move the pointer over ****Data + AI**** > ****DTS (DTS)**** > ****Data Synchronization**** or **Data + AI** > ********DTS (DTS)******** > **Change Tracking**.
        
    3.  On the right side of **Data Synchronization Tasks** or **Change Tracking Tasks**, select the region to which the DTS instance belongs.
        
    
2.  Locate the target DTS instance, and in the **Billing Method** column, click **Renew**.
    
3.  In the dialog box that appears, verify the **Basic Information** of the destination instance, and in the **New Instance Class** area, select a **Subscription Duration**.
    
4.  Read and select **Data Transmission Service (Pay-as-you-go) Service Terms**.
    
5.  Click **Pay**.
    

## Enable auto-renewal

1.  Log on to the [DTS console](https://dts.alibabacloud.com/).
    
2.  In the top navigation bar, choose **Expenses** > **Renewal Management**.
    
3.  On the **Resource Renewal** page, filter the list to display only Data Transmission Service instances.
    
4.  Click the **Manual Renewal** or **Non-renewal** tab.
    
5.  Find the instance for which you want to enable auto-renewal and click **Enable Auto-renewal** in the **Actions** column.
    
    **Note**
    
    To enable auto-renewal for multiple instances at the same time, select the instances and click **Enable Auto-renewal** at the bottom of the page.
    
6.  In the **Enable Auto-renewal** dialog box, select an **Auto-renewal Period** and click **Enable Auto-renewal**.
    
    **Note**
    
    -   After you enable auto-renewal, the system starts deducting fees nine days before the subscription instance expires. You must ensure that your payment method has a sufficient balance to complete the renewal.
        
    -   After you enable auto-renewal, the system renews the instance based on the selected auto-renewal period. For example, if you select a 3-month auto-renewal period, you are charged for a 3-month subscription in each renewal cycle.
        
    -   To modify or cancel auto-renewal, see or [Renew an expiring resource](/help/en/user-center/renewal-guide#eff7e0f2a1u29).
