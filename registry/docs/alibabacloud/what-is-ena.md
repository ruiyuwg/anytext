Edge Network Acceleration (ENA) is built based on the widely distributed edge compute nodes of Alibaba Cloud and the compliant network resources of carriers. ENA can provide enterprises with end-to-end fast connectivity services such as accelerated connectivity between the internal branches of enterprises, accelerated connectivity between enterprise data centers (DCs), and accelerated connectivity between corporate intranets and Alibaba Cloud.

## Overview

ENA can provide enterprises with end-to-end fast connectivity services such as accelerated connectivity between the internal branches of enterprises, accelerated connectivity between enterprise DCs, and accelerated connectivity between corporate intranets and Alibaba Cloud.

## Benefits

-   High security
    
    ENA enables communication data to be transmitted over a dedicated channel that is built for an enterprise, without passing through the Internet. This prevents privacy data from being stolen.
    
-   High-speed connectivity
    
    ENA helps the branches of an enterprise directly communicate with each other over the corporate intranet with low latency.
    
-   Quick access
    
    ENA helps quickly build a dedicated channel that connects a corporate intranet to an Alibaba Cloud point of presence (POP) gateway. Compared with the traditional end-to-end access method, ENA greatly reduces the construction period.
    
-   Multiple branches
    
    Access points are distributed in more than 30 cities around the globe to implement high-quality leased line connectivity between branches. Multi-access point connectivity is available across multiple cities to achieve highly reliable access.
    
-   One-stop service
    
    ENA provides a one-stop service for customers to connect to Alibaba Cloud POP gateways. This releases you from tedious construction affairs.
    
-   Cost-effectiveness
    
    Compared with traditional end-to-end construction costs, on-site installation costs are greatly reduced.
    

## Scenarios

-   Quick setup of hybrid networking
    
    ENA helps quickly build a dedicated channel that connects a corporate intranet to an Alibaba Cloud POP gateway to provide one-stop, low-cost, and efficient services, with stable bandwidth, low latency, and high security.
    
-   Data center connectivity
    
    ENA helps quickly build a dedicated channel between enterprise self-managed DCs to achieve high-speed and stable connectivity between the DCs.
    
-   Cross-region intranet building for chain enterprises
    
    ENA helps quickly establish connections between on-premises branches and Alibaba Cloud POP gateways to implement fast channel connectivity between Alibaba Cloud and the on-premises branches, providing a new option for enterprises to build intranets across regions at low costs.
    
-   Fast coverage of cloud computing
    
    ENA provides high-assurance and cost-effective dedicated connections for cloud computing enterprises to ensure service stability for medium- and high-end customers.
