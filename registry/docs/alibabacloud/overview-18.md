PyODPS offers interfaces for ODPS objects. You can operate MaxCompute in Python programming style.

With PyODPS, you can perform basic operations on MaxCompute objects such as:

-   [SQL](/help/en/maxcompute/user-guide/sql#concept-hqh-5vf-cfb)
    
-   [Projects](/help/en/maxcompute/user-guide/projects#concept-kpt-vjf-cfb)
    
-   [Schema](/help/en/maxcompute/user-guide/schemas#concept-2312105)
    
-   [Tables](/help/en/maxcompute/user-guide/tables#concept-lhx-tmf-cfb)
    
-   [Task instances](/help/en/maxcompute/user-guide/task-instances#concept-tfd-wtf-cfb)
    
-   [Resources](/help/en/maxcompute/user-guide/resources#concept-zgl-m3t-cfb)
    
-   [Functions](/help/en/maxcompute/user-guide/functions#concept-q3r-cvf-cfb)
    

For more information, see [Definitions](https://pyodps.readthedocs.io/en/stable/api.html).
