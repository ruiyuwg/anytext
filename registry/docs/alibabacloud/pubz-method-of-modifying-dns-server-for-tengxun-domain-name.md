This topic describes how to configure the DNS servers for a domain name registered with Tencent Cloud to use Alibaba Cloud DNS.

## **Configuration method**

1.  Log on to the [DNSPod Domain Registration Console](https://console.cloud.tencent.com/domain/all-domain/all). On the **All Domains** tab, click the **More** button next to your domain name, and then select **Change DNS Servers**.
    
2.  In the **Change DNS Servers** dialog box, select **Custom DNS**, enter the DNS server names assigned by Alibaba Cloud DNS, and then click the **Submit** button to complete the configuration.
    
    **Note**
    
    If you do not know the DNS server names assigned by Alibaba Cloud DNS, see [View the DNS server addresses of a domain name](/help/en/dns/pubz-view-dns-server-status-and-exception-handling#2977dbc544lrs).
    
3.  After completing the configuration, wait for the DNS server settings to take effect. Global propagation typically takes up to 48 hours.
