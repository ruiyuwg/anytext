The following table lists the API operations available for use in Resource Group.

**Note**

Alibaba Cloud provides [OpenAPI Explorer](https://next.api.alibabacloud.com/product/ResourceManager) to simplify API usage. You can use OpenAPI Explorer to debug API operations and dynamically generate SDK sample code.

**Operation**

**Description**

[CreateResourceGroup](/help/en/resource-management/api-createresourcegroup#doc-api-ResourceManager-CreateResourceGroup)

Creates a resource group.

[ListResourceGroups](/help/en/resource-management/api-listresourcegroups#doc-api-ResourceManager-ListResourceGroups)

Queries a list of resource groups.

[GetResourceGroup](/help/en/resource-management/api-getresourcegroup#doc-api-ResourceManager-GetResourceGroup)

Queries the information about a resource group.

[CreatePolicy](/help/en/resource-management/api-createpolicy#doc-api-ResourceManager-CreatePolicy)

Creates a permission policy.

[DeleteResourceGroup](/help/en/resource-management/api-deleteresourcegroup#doc-api-ResourceManager-DeleteResourceGroup)

Deletes a resource group.

[UpdateResourceGroup](/help/en/resource-management/api-updateresourcegroup#doc-api-ResourceManager-UpdateResourceGroup)

Updates the basic information about a resource group.

[ListPolicies](/help/en/resource-management/api-listpolicies#doc-api-ResourceManager-ListPolicies)

Queries a list of permission policies.

[GetPolicy](/help/en/resource-management/api-getpolicy#doc-api-ResourceManager-GetPolicy)

Queries the information about a permission policy.

[CreatePolicyVersion](/help/en/resource-management/api-createpolicyversion#doc-api-ResourceManager-CreatePolicyVersion)

Creates a version for a permission policy.

[DeletePolicyVersion](/help/en/resource-management/api-deletepolicyversion#doc-api-ResourceManager-DeletePolicyVersion)

Deletes a version of a permission policy.

[ListPolicyVersions](/help/en/resource-management/api-listpolicyversions#doc-api-ResourceManager-ListPolicyVersions)

[GetPolicyVersion](/help/en/resource-management/api-getpolicyversion#doc-api-ResourceManager-GetPolicyVersion)

[SetDefaultPolicyVersion](/help/en/resource-management/api-setdefaultpolicyversion#doc-api-ResourceManager-SetDefaultPolicyVersion)

[AttachPolicy](/help/en/resource-management/api-attachpolicy#doc-api-ResourceManager-AttachPolicy)

Attaches a permission policy to an object.

[DetachPolicy](/help/en/resource-management/api-detachpolicy#doc-api-ResourceManager-DetachPolicy)

Detaches a permission policy from an object.

[ListPolicyAttachments](/help/en/resource-management/api-listpolicyattachments#doc-api-ResourceManager-ListPolicyAttachments)

Queries a list of attachment records of permission policies.

[DeletePolicy](/help/en/resource-management/api-deletepolicy#doc-api-ResourceManager-DeletePolicy)

Deletes a permission policy.

[CreateRole](/help/en/resource-management/api-createrole#doc-api-ResourceManager-CreateRole)

Creates a RAM role.

[DeleteRole](/help/en/resource-management/api-deleterole#doc-api-ResourceManager-DeleteRole)

Deletes a RAM role.

[GetRole](/help/en/resource-management/api-getrole#doc-api-ResourceManager-GetRole)

Queries the information about a RAM role.

[ListRoles](/help/en/resource-management/api-listroles#doc-api-ResourceManager-ListRoles)

Queries a list of RAM roles.

[UpdateRole](/help/en/resource-management/api-updaterole#doc-api-ResourceManager-UpdateRole)

Updates the information about a RAM role.

[ListResources](/help/en/resource-management/api-listresources#doc-api-ResourceManager-ListResources)

Queries a list of resources that can be accessed by the current account in resource groups.

[MoveResources](/help/en/resource-management/api-moveresources#doc-api-ResourceManager-MoveResources)

Moves resources from one resource group to another.

[CreateServiceLinkedRole](/help/en/resource-management/api-createservicelinkedrole#doc-api-ResourceManager-CreateServiceLinkedRole)

Creates a service-linked role.

[DeleteServiceLinkedRole](/help/en/resource-management/api-deleteservicelinkedrole#doc-api-ResourceManager-DeleteServiceLinkedRole)

Deletes a service-linked role.

[GetServiceLinkedRoleDeletionStatus](/help/en/resource-management/api-getservicelinkedroledeletionstatus#doc-api-ResourceManager-GetServiceLinkedRoleDeletionStatus)

Queries the status of the task that is used to delete a service-linked role.

[TagResources](/help/en/resource-management/api-tagresources-411680#doc-api-ResourceManager-TagResources)

Adds tags to resource groups or the members in a resource directory.

[UntagResources](/help/en/resource-management/api-untagresources-411681#doc-api-ResourceManager-UntagResources)

Removes tags from resource groups or the members in a resource directory.

[ListTagResources](/help/en/resource-management/api-listtagresources-2#doc-api-ResourceManager-ListTagResources)

Queries a list of tags that are added to resource groups or the members in a resource directory.

[EnableAssociatedTransfer](/help/en/resource-management/api-enableassociatedtransfer)

Enables the Transfer Associated Resources feature.

[DisableAssociatedTransfer](/help/en/resource-management/api-disableassociatedtransfer)

Disables the Transfer Associated Resources feature.

**Note**

Both the Resource Management and Resource Access Management (RAM) services provide the API operations used to manage permission policies and the API operations used to manage RAM roles. Two API operations with the same name in Resource Management and RAM provide the same features. You can use either of the two API operations to perform the desired operations. However, two API operations with the same name in the two services have differences. For more information, see [API overview](/help/en/ram/api-overview-2#concept-1989050).
