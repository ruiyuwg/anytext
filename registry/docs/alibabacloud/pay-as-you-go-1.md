If the pay-as-you-go billing method is used, you are charged based on the actual resource usage. If you have activated CloudMonitor Basic (pay-as-you-go) and the actual resource usage exceeds the free quotas, the related items are billed based on the pay-as-you-go billing method.

**Important**

CloudMonitor Basic will support the pay-as-you-go billing method from 10:00:00 (UTC+8) on September 26, 2024. For more information, see [Announcement on the changes in billing of CloudMonitor Basic](/help/en/cms/cloudmonitor-1-0/product-overview/announcement-basic-cloud-monitoring-billing-adjustment).

The following table describes the billing of CloudMonitor Basic (pay-as-you-go).

**Item**

**Description**

**Scenarios**

If the free quotas are used up, the pay-as-you-go billing method is used.

**Billing cycle**

You are charged on a daily basis. Bills are generated and fees are deducted from the balance of your Alibaba Cloud account at the end of each billing cycle.

**Billable item**

-   Alert text messages
    
    If the value of a metric reaches the specific alert condition, alert notifications are sent by using text messages.
    
-   Alert phone calls
    
    If the value of a metric reaches the specific alert condition, alert notifications are sent by using phone calls.
    
    **Note**
    
    Starting from April 27, 2024, you are not charged for unanswered calls.
    
-   API calls for metric data query
    
    The number of calls for the [DescribeMetricLast](/help/en/cms/cloudmonitor-1-0/api-describemetriclast-new#doc-api-Cms-DescribeMetricLast), [DescribeMetricList](/help/en/cms/cloudmonitor-1-0/api-describemetriclist-new#doc-api-Cms-DescribeMetricList), [DescribeMetricData](/help/en/cms/cloudmonitor-1-0/api-describemetricdata-ne#doc-api-Cms-DescribeMetricData), and [DescribeMetricTop](/help/en/cms/cloudmonitor-1-0/api-describemetrictop-new#doc-api-Cms-DescribeMetricTop) APIs. Calls that are generated by using the CloudMonitor console are excluded. After the free quota is used up, you are charged for calling these APIs based on the pay-as-you-go billing method.
    
-   Dynamic threshold
    
    The actual service usage of the dynamic threshold feature is measured based on the following formula: Service duration × Number of time series of a metric.
    
    The billing standard for a metric is related to the alert precision of a dynamic threshold. CloudMonitor provides only standard-precision (in minutes) dynamic thresholds for metrics. The unit price of a standard-precision dynamic threshold for a metric is
    
    USD 0.0004 per time series of the metric per hour.
    
    -   The number of time series for a metric is related to the dimensions of the metric. The number of unique and valid combinations of all dimensions for a metric is the number of time series for the metric.
        
    -   The actual service duration of the dynamic threshold feature is measured every hour on the hour. If a dynamic threshold is reached in the time series of a metric in an hour, 1 hour is counted into the service duration.
        

**Pricing**

-   Alert text messages: The free quota is 1,000 per month. You are charged for the excess usage at USD 0.0064 per message.
    
-   Alert phone calls: USD 0.0212 per call.
    
-   API calls for metric data query: The free quota is one million calls per month. You are charged for the excess usage at USD 0.017 per 10,000 calls.
    
-   Dynamic threshold: USD 0.0004 (per time series of a metric per hour).
    

**Deduction rule**

The free quotas are used to offset fees first. After the free quotas are used up, you are charged by using the pay-as-you-go billing method. For more information about the free quotas, see [Free quotas](/help/en/cms/cloudmonitor-1-0/product-overview/free-quota#concept-2243558).

**Billing example**

-   Alert text messages
    
    Assume that you used 1,200 alert messages on August 20, 2023. The following fee is incurred:
    
    Fee = (1,200 - 1,000) × USD 0.0064 = USD 1.28
    
-   Alert phone calls
    
    Assume that you used 300 alert calls on August 20, 2023. The following fee is incurred:
    
    Fee = 300 × USD 0.0212 = USD 6.36
    
-   API calls for metric data query
    
    Assume that you called 1.2 million API operations to query metric data on August 25, 2023. The following fee is incurred:
    
    Fee = (120 - 100) × USD 0.017 = USD 0.34
    
-   Dynamic threshold
    
    -   Assume that a dynamic threshold-based alert rule is set for the CPU utilization metric (CPUUtilization) of an Elastic Compute Service (ECS) instance. The alert rule takes effect for a time series of the metric. The fee for applying this rule for 30 days is calculated based on the following formula:
        
        Fee = 1 time series of the metric × 24 hours × 30 days × USD 0.0004 = USD 0.288
        
    -   Assume that the ECS instance has two disks and a dynamic threshold-based alert rule is set for the disk usage metric (diskusage\_used) of both disks. The alert rule takes effect for two time series of the metric. The fee for applying this rule for 30 days is calculated based on the following formula:
        
        Fee = 2 time series of the metric × 24 hours × 30 days × USD 0.0004 = USD 0.576
