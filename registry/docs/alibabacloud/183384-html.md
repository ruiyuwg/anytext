This topic describes the limits that apply in Cloud Config.

**Item**

**Upper limit**

Maximum number of rules allowed for a single account

200

Maximum number of delivery tasks allowed for a single account

5

Maximum number of account groups allowed for a management account

5

Maximum number of delivery tasks allowed for an account group

5

Maximum number of member accounts allowed for an account group

200

**Note**

-   The number of policies that can be attached to a RAM user, RAM user group, or RAM role is not affected by authorization scope. In other words, you can apply the same number of policies whether you grant permissions on a single resource group or on your Alibaba Cloud account.
