This topic walks you through how to use ApsaraDB RDS for PostgreSQL, including how to create RDS for PostgreSQL instances and databases, configure whitelists, and connect to and use an RDS for PostgreSQL instance.

If this is the first time that you use RDS for PostgreSQL, we recommend that you familiarize yourself with the limits of RDS for PostgreSQL. For more information, see [Limits](/help/en/rds/apsaradb-rds-for-postgresql/quotas-and-limits#concept-zvw-n1g-wdb).

Before you use an RDS for PostgreSQL instance, you must perform the following operations:

1.  [Create an ApsaraDB RDS for PostgreSQL instance](/help/en/rds/apsaradb-rds-for-postgresql/create-an-apsaradb-rds-for-postgresql-instance#concept-kzn-qcg-wdb)
    
2.  [Create a database and an account](/help/en/rds/apsaradb-rds-for-postgresql/create-a-database-and-an-account-on-an-apsaradb-rds-for-postgresql-instance#concept-njz-1gg-wdb)
    
3.  [Configure an IP address whitelist](/help/en/rds/apsaradb-rds-for-postgresql/configure-an-ip-address-whitelist-for-an-apsaradb-rds-for-postgresql-instance#concept-sfx-kdg-wdb)
    
4.  [Apply for or release a public endpoint](/help/en/rds/apsaradb-rds-for-postgresql/apply-for-or-release-a-public-endpoint-on-an-apsaradb-rds-for-postgresql-instance#concept-nsl-hff-vdb)
    
5.  [Connect to an ApsaraDB RDS for PostgreSQL instance](/help/en/rds/apsaradb-rds-for-postgresql/connect-to-an-apsaradb-rds-for-postgresql-instance-1#concept-stt-3hg-wdb)
    

After these operations are complete, you can use the features provided by RDS for PostgreSQL, such as extensions and the spatial-temporary engine GanosBase. For more information about the features supported by RDS for PostgreSQL, see [Features](/help/en/rds/rds-postgresql-database-features/).
