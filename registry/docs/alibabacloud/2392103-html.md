If the existing methods for API calls do not meet your business requirements, you can encapsulate custom HTTP requests for API calls.

## Usage notes

We recommend that you use Alibaba Cloud SDKs to call API operations.

When you construct requests to call Alibaba Cloud API operations, you must sign the requests. Alibaba Cloud SDKs provide the algorithm for signing API requests. For more information, see [Request syntax and signature method](/help/en/sdk/product-overview/request-structure-and-signature/).
