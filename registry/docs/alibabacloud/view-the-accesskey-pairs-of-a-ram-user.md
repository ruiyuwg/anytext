You can view the AccessKey ID, status, last used service, and creation time of AccessKey pairs for RAM users. The AccessKey secret is displayed only when you create an AccessKey pair and cannot be retrieved later.

## View AccessKey pairs as a RAM administrator

You can view the AccessKey pairs of all RAM users by using your Alibaba Cloud account or as a RAM administrator to which the AliyunRAMFullAccess policy is attached.

1.  Log on to the [RAM console](https://ram.console.alibabacloud.com/) as a RAM user who has administrative rights.
    
2.  In the left-side navigation pane, choose **Identities** > **Users**.
    
3.  On the **Users** page, click the name of the RAM user whose AccessKey pairs you want to view.
    
4.  Click the **AccessKey** tab to view the AccessKey pairs of the RAM user, including the AccessKey ID, status, last used service, and creation time.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3863589471/p792554.png)
    

## View AccessKey pairs as a RAM user

If a RAM administrator allows RAM users to manage AccessKey pairs, RAM users can view their own AccessKey pairs. For more information, see [Manage the security settings of RAM users](/help/en/ram/user-guide/manage-security-settings-of-ram-users#task-188786).

1.  Log on to the [Alibaba Cloud Management Console](https://signin.alibabacloud.com/login.htm) as a RAM user.
    
2.  Move the pointer over the profile picture in the upper-right corner and click **AccessKey**.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3863589471/p792553.png)
    
3.  On the **AccessKey Pair** page, view the AccessKey pairs, including the AccessKey ID, status, last used service, and creation time.
    
    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3863589471/p792554.png)
