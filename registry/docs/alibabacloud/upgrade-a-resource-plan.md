This topic describes how to upgrade an File Storage NAS (NAS) resource plan. You cannot downgrade a NAS resource plan.

## Procedure

1.  Log on to the [NAS console](https://nas.console.alibabacloud.com/).
    
2.  In the left-side navigation pane, click **Resource Plans**.
    
3.  In the top navigation bar, select a region.
    
4.  On the **Resource Plans** page, find the resource plan and click **Upgrade** in the Actions column.
    
5.  On the **NAS Resource Plan|Configuration Change** page, select the new base capacity that you want to upgrade to.
    
6.  Check the resource plan information, read and select **I have read and agreed to NAS Resource Plan Terms of Service**, and then click **Buy Now**.
    
7.  Confirm the order and click **Buy**.
