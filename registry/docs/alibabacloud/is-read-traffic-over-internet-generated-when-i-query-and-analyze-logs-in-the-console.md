If data is pulled over a public Simple Log Service endpoint, read traffic over the Internet is generated. The traffic is calculated based on the size of data after compression.

If you use a third-party application, Simple Log Service allows you to consume log data only by using related SDKs. If you query, analyze, transform, and ship log data in the Simple Log Service console, read traffic over the Internet is not generated because the operations are performed over an internal network of Alibaba Cloud.
