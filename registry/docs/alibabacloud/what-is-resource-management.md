Resource Management provides a collection of resource management services that support enterprise IT administration. The services include Resource Directory, Resource Group, Resource Sharing, Tag, and Resource Center. Resource Directory lets you implement account management based on the organizational structure of your enterprise. Resource Group and Tag allow you to group and manage the resources within the accounts used by your enterprise. Resource Sharing lets the users that use the accounts in the same organizational structure share resources with each other. Resource Center allows you to search for resources across accounts, services, or regions.

## Resource Directory

Resource Directory allows you to establish an organizational structure for the accounts used by your enterprise and manage the relationships between the accounts. This way, you can plan, build, and manage the resources that are used by your enterprise applications in a centralized manner.

After you enable a resource directory, you can consolidate the accounts used by your enterprise into it to establish multi-level relationships for the accounts and the resources within the accounts. Then, you can manage the resources in a centralized manner based on the relationships. This helps you meet the requirements for finance, security, auditing, and compliance.

Applications related to billing, settlement, operation tracking, and compliance auditing are interconnected with Resource Directory. This enables Resource Directory to provide an increasing number of business-based data services.

For more information, see [What is Resource Directory?](/help/en/resource-management/resource-directory/product-overview/resource-directory-overview#concept-2436329).

## Resource Group

Resource Group allows you to sort resources owned by your Alibaba Cloud account into groups. This simplifies the resource and permission management within your Alibaba Cloud account.

Resource Group allows you to perform the following operations:

-   Create resource groups to manage the resources of your Alibaba Cloud account in various regions.
    
-   Specify an administrator for each resource group. Each administrator manages the resources in the resource group for which they are responsible.
    
-   View billing statements by resource group to facilitate cost allocation.
    

For more information, see [What is Resource Group?](/help/en/resource-management/resource-group/product-overview/resource-group-overview).

## Resource Sharing

Resource Sharing allows you to share the resources of your Alibaba Cloud account with other accounts and access the resources shared by other accounts.

-   To share your resources with other accounts, you can create a resource share and add the resources and accounts to the resource share.
    
-   If other resource owners share resources with you, you can access these resources without confirmation and perform specific operations on them. The operations you can perform vary based on the resource type.
    

For more information, see [What is Resource Sharing?](/help/en/resource-management/resource-sharing/product-overview/resource-sharing-overview#concept-2436329).

## Tag

Tags are used to identify resources. Tags allow you to categorize, search for, and aggregate resources that have the same characteristics from different dimensions. This facilitates resource management.

The Tag service allows you to perform the following operations:

-   Manage all tags in the same console.
    
-   Manage tags in a visualized manner.
    
-   Search for all tags and the resources to which tags are added on the Tag page of the Resource Management console.
    
-   Use a tag editor to add, modify, or query multiple tags at a time.
    

A tag consists of a tag key and a tag value. You can create tags, add them to resources, and then perform the following tasks:

-   Search for resources in a rapid manner.
    
-   Implement automated O&M.
    
-   Control access to resources.
    
-   Analyze data stored in Log Service in a rapid manner.
    

For more information, see [What is Tag?](/help/en/resource-management/tag/product-overview/tag-overview#concept-2407084).

## Resource Center

Resource Center allows you to view resources across accounts, services, or regions. This helps you have a global view of resources within your Alibaba Cloud accounts. Resource Center also allows you to search for resources by region, service, resource type, resource ID, resource name, or tag. After you find the resource that you want to manage, you can go to the corresponding service console with one click and perform subsequent operations. Resource Center facilitates resource searches and management.

For more information, see [Resource Center overview](/help/en/resource-management/resource-center/product-overview/resource-center-overview#concept-2281139).

## How to use Resource Management

After you create an Alibaba Cloud account, you can use Resource Management by using one of the following methods:

-   Resource Management console
    
    Resource Management provides an interactive web console. You can log on to the [Resource Management console](https://resourcemanager.console.alibabacloud.com/) to use Resource Management.
    
-   API operations and SDKs
    
    Resource Management provides RESTful API operations and SDKs for multiple programming languages to facilitate secondary development.
    
    Alibaba Cloud provides [OpenAPI Explorer](https://next.api.alibabacloud.com) to simplify API usage. You can use OpenAPI Explorer to debug API operations and dynamically generate SDK sample code.
