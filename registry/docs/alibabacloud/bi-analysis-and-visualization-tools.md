This topic describes the business intelligence (BI) analysis tools that you can connect to Hologres.

Hologres is compatible with the PostgreSQL ecosystem and provides Java Database Connectivity (JDBC) and Open Database Connectivity (ODBC) interfaces. It supports connections to third-party extract, transform, and load (ETL) and BI tools, such as Tableau and Quick BI. You can connect BI tools directly to Hologres to perform multidimensional analysis and explore business data. The BI analysis tools that you can connect to Hologres are listed in the following table.
