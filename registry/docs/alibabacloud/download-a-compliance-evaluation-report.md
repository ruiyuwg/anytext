You can download a compliance evaluation report generated based on rules to an on-premises machine. This allows you to assign tasks and remediate the configurations of non-compliant resources on premises.

## Procedure

1.  Log on to the [Cloud Config console](https://confignew.console.alibabacloud.com).
    
2.  Optional. In the upper-left corner, select an account group.
    
    This operation is required only if you are using a management account of a resource directory. Otherwise, you do not need to perform the operation.
    
3.  In the left-side navigation pane, choose **Compliance & Audit** > **Rules**.
    
4.  On the **Rules** page, click the ![image..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4696595861/p668763.png) icon in the upper-right corner.
    
    Wait 1 to 2 minutes for the latest compliance evaluation report to be generated.
    
5.  In the **Download Compliance Report** message, click **OK**.
    
    You can obtain a compliance evaluation report in the Excel format. The report displays the type, ID, name, and region of each resource that is evaluated as non-compliant within your account. In addition, the report displays the names of the rules for which resources are evaluated as non-compliant and the links to the topics that describe how to remediate non-compliant resources.
