Simple Log Service can render query and analysis results into charts. You can use a chart (Pro) to display the results of multiple query statements. You can also configure personalized display settings for the results of each query statement.

## Chart types

Simple Log Service provides the following types of charts (Pro):

-   [Table](/help/en/sls/table/#task-2133734)
    
-   [Line chart](/help/en/sls/line-chart/#task-2133736)
    
-   [Flow chart](/help/en/sls/flow-chart/#task-2134807)
    
-   [Column chart](/help/en/sls/column-chart#concept-2170547)
    
-   [Statistical chart](/help/en/sls/single-value-chart/#concept-2209384)
    
-   [Bar gauge](/help/en/sls/bar-gauge/#concept-2215599)
    
-   [Pie chart](/help/en/sls/pie-chart/#concept-2217286)
    
-   [Markdown chart (Pro)](/help/en/sls/manage-a-markdown-chart)
    
-   [Radar chart](/help/en/sls/radar-chart#concept-2234790)
    
-   [Topology chart](/help/en/sls/topology-chart#concept-2236574)
    
-   [Cross table](/help/en/sls/cross-table#concept-2250610)
    
-   [Scatter chart](/help/en/sls/scatter-chart#concept-2250611)
    
-   [Histogram](/help/en/sls/histogram#concept-2251235)
    

## Operations

Charts are used to display query and analysis results. You can select different types of charts from the chart type section and configure settings for the charts.

**Operation**

**Description**

Select a chart

Select a chart type to display your query and analysis results.

[General Configurations](/help/en/sls/statistical-chart-properties#section-324-y0y-b0l)

Configure global settings for a chart. For example, you can select a color scheme to display the results of all query statements for the chart.

[Field Configuration](/help/en/sls/statistical-chart-properties#section-9jb-h7o-d1d)

Configure personalized display settings for the results of a single query statement or for a single column of data in the results. For example, if you select a query statement and then select a color scheme, the chart is generated based on the results of the query statement and uses the color scheme that you select.

[Configure a drill-down event](/help/en/sls/drill-down-events#concept-v5f-zk4-x2b)

Configure a drill-down event for the results of a single query statement or for a single column of data in the results to analyze data from a finer-grained dimension. Drill-down events include events to open a Logstore, open quick analysis, open a dashboard, open trace analysis, open trace details, and customize an HTTP link.

[Add a chart to a dashboard](/help/en/sls/add-a-chart-to-a-dashboard#task-2141885)

Add a chart to a dashboard.
