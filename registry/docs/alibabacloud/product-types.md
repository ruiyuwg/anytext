To reduce user costs, ApsaraDB RDS provides YiTian instances and standard instances. ApsaraDB RDS instances that use the ARM architecture are YiTian instances.

## Introduction to YiTian instances and standard instances

Architecture and scenario

YiTian RDS instances use the ARM architecture and allow you to use higher instance specifications at lower costs. This type of instance is provided based on intelligent cost management and resource integration. YiTian RDS instances provide high stability and availability, help reduce IT costs, and are suitable for enterprises that require cost reduction and efficiency enhancement.

Standard RDS instances use the x86 architecture and support larger capacity and more instance families. This type of instance is well-proven by extensive market testing and provides high-security, high-stability, and high-performance database services for the core business of enterprises.
