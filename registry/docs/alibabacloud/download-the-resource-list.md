Cloud Config displays all your resources that reside in different regions in a list. You can view the resources in the resource list in the Cloud Config console or download the resource list to your on-premises machine to allocate resources and view the information about a resource on your on-premises machine.

## Procedure

1.  Log on to the [Cloud Config console](https://confignew.console.alibabacloud.com).
    
2.  Optional. In the upper-left corner, select an account group.
    
    This operation is required only if you are using a management account of a resource directory. Otherwise, you do not need to perform the operation.
    
3.  In the left-side navigation pane, choose **Resources** > **Global Resources**.
    
4.  On the **Global Resources** page, view the latest resource list by resource ID, resource type, region, and resource status or click ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8370335271/p840185.png) to download the resource list.
    
    You can obtain a resource list in the CSV format. In the resource list, you can view the information about a resource, such as the ID of the account to which the resource belongs, the ID, name, type, status, and tags of the resource, the time when the resource was created, and the region where the resource resides.
    
    **Note**
    
    If you do not configure filter conditions, the list that contains all resources is generated.
