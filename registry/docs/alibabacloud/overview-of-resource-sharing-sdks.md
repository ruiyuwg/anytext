## **SDK usage notes**

-   Alibaba Cloud provides [OpenAPI Explorer](https://next.api.alibabacloud.com/product/ResourceSharing) to simplify API usage. You can use OpenAPI Explorer to debug API operations and dynamically generate SDK sample code.
    
-   For more information about how to obtain an AccessKey pair, see [Create an AccessKey pair](/help/en/ram/user-guide/create-an-accesskey-pair#task-2245479).
    
-   For more information about Resource Sharing API operations, see [List of operations by function](/help/en/resource-management/resource-sharing/developer-reference/api-resourcesharing-2020-01-10-overview).
