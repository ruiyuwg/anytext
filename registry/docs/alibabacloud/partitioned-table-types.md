PolarDB is compatible with MySQL partition types of hash, range, list, range-hash, and list-hash. PolarDB 8.0.2.2.0 and later support composite partitions and more partition types. This topic describes the composite partition types supported in PolarDB and the usage of these types.

PolarDB is compatible with the following MySQL partition types:

-   [HASH](/help/en/polardb/polardb-for-mysql/user-guide/hash#concept-2202942)
-   [KEY](/help/en/polardb/polardb-for-mysql/user-guide/key#concept-2202958)
-   [RANGE](/help/en/polardb/polardb-for-mysql/user-guide/range#concept-2203114)
-   [LIST](/help/en/polardb/polardb-for-mysql/user-guide/list#concept-2203168)
-   [RANGE-HASH](/help/en/polardb/polardb-for-mysql/user-guide/range-hash#concept-2203565)
-   [LIST-HASH](/help/en/polardb/polardb-for-mysql/user-guide/list-hash#concept-2203697)

A composite partition comprises both partitions and subpartitions. PolarDB 8.0.2.2.0 and later support the following composite partition types:

-   [RANGE-RANGE](/help/en/polardb/polardb-for-mysql/user-guide/range-range#concept-2181252)
-   [RANGE-LIST](/help/en/polardb/polardb-for-mysql/user-guide/range-list#concept-2181255)
-   [LIST-RANGE](/help/en/polardb/polardb-for-mysql/user-guide/list-range#concept-2181255)
-   [LIST-LIST](/help/en/polardb/polardb-for-mysql/user-guide/list-list#concept-2181255)
-   [HASH-HASH](/help/en/polardb/polardb-for-mysql/user-guide/hash-hash#concept-2181255)
-   [HASH-KEY](/help/en/polardb/polardb-for-mysql/user-guide/hash-key#concept-2183482)
-   [HASH-RANGE](/help/en/polardb/polardb-for-mysql/user-guide/hash-range#concept-2183498)
-   [HASH-LIST](/help/en/polardb/polardb-for-mysql/user-guide/hash-list#concept-2183501)
-   [KEY-HASH](/help/en/polardb/polardb-for-mysql/user-guide/key-hash#concept-2183505)
-   [KEY-KEY](/help/en/polardb/polardb-for-mysql/user-guide/key-key#concept-2183622)
-   [KEY-RANGE](/help/en/polardb/polardb-for-mysql/user-guide/key-range#concept-2183623)
-   [KEY-LIST](/help/en/polardb/polardb-for-mysql/user-guide/key-list#concept-2183624)
-   [LIST DEFAULT HASH](/help/en/polardb/polardb-for-mysql/user-guide/list-default-hash#concept-2183627)
