PolarDB for PostgreSQL(Compatible with Oracle) provides three billing methods for storage, which are pay-as-you-go + storage plans, pay-as-you-go, and subscription. They each correspond to a set of billing rules.

PolarDB charges fees for the storage capacity consumed by your clusters. For more information, see [PSL4 and PSL5](/help/en/polardb/polardb-for-oracle/comparison-between-psl4-and-psl5-1#concept-2144264) and [Storage Capacity](/help/en/polardb/polardb-for-oracle/glossary-1#concept-2336415). For more information about the billing rules for each billing method, see the following topics:

-   [Pay-as-you-go + storage plans](/help/en/polardb/polardb-for-oracle/pay-as-you-go-and-storage-plans#concept-2233808)
-   [pay-as-you-go](/help/en/polardb/polardb-for-oracle/pay-as-you-go#concept-2233601)
-   [subscription](/help/en/polardb/polardb-for-oracle/subscription#concept-2233602)
