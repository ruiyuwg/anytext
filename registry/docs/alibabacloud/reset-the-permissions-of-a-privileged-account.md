If an issue occurs to a privileged account, you can reset the permissions of the privileged account and specify a new password to resolve the issue. For example, if the permissions of the privileged account are revoked, you can resolve the issue based on this topic.

## Procedure

**Warning**

The privileged account is your management account and is recorded and used by the control system. You are not allowed to reset the password of the privileged account in an unauthorized interface or environment.

1.  Go to the [Instances](https://rds.console.alibabacloud.com/rdsList/basic) page. In the top navigation bar, select the region in which the RDS instance resides. Then, find the RDS instance and click the ID of the instance.
    
2.  In the left-side navigation pane, click **Accounts**.
    
3.  Find the privileged account and click **Reset Account Permissions** in the Actions column.
    
    ![重置账号](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0098080071/p608804.png)
    
4.  Enter a new password for the privileged account and click **OK**.
