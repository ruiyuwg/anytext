Currently, DataV supports the following components:

-   Charts
-   Maps
-   Information
-   Table
-   Control
-   Media
-   Materials
-   Others
-   More widgets

## Charts

On the Charts tab, you can select a chart, including column chart, line chart, pie chart, scatter chart, and other charts. ![charts](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493504.jpg)

## Maps

You can select a map from the Map drop-down list, including Basic Flat Map, Flat Map with 3D Effects and Globe.

## Information

In the Information widget, you can select the required text, including the carousel list, key-value table, general title, marquee, and multi-line text. ![Information](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493505.jpg)

## Table

In the Table widget, you can select the required table, including the carousel list, key-value table, and List Carousel I.![table](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493509.jpg)

## Control

In the Control widget, you can select the required control, including Page Carousel, iframe and Tab List.![control](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493515.jpg)

## Media

In the Media widget, you can select the required media, including Customized Background, Graphic and RTMP Supported Live Stream Player.![media](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493518.jpg)

## Materials

In the Materials widget, you can select the target materials, including Video, Background Image and Background Box.![materials](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493527.jpg)

## Others

Among Others components, you can select the auxiliary graphics you need, including Clustered Column Chart, Stacked Percentage Bar Chart and Table with Progress Charts.

## More widgets

Click More Widgets on the toolbar to subscribe to third-party widgets.![more](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0904473661/p493529.jpg)
