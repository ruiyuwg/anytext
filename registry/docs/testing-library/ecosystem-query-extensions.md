[`query-extensions`](https://github.com/tjefferson08/query-extensions) is an experimental companion library for Testing Library that mixes a higher-level API into the standard `@testing-library` core queries

-   npm
-   Yarn

```
npm install --save-dev query-extensions
```

```
yarn add --dev query-extensions
```

Check out the [github repo](https://github.com/tjefferson08/query-extensions) for documentation for examples and rationale.
