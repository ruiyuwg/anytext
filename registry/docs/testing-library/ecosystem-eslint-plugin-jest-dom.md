[`eslint-plugin-jest-dom`](https://github.com/testing-library/eslint-plugin-jest-dom) is an ESLint plugin for Jest DOM that helps users to follow best practices and anticipate common mistakes when writing tests.

This plugin includes:

-   Several rules for linting Jest DOM specific code.
-   Shareable config for recommended rules.
-   Some autofixable rules.

Find more info about available rules and configs on GitHub.

-   [eslint-plugin-jest-dom on GitHub](https://github.com/testing-library/eslint-plugin-jest-dom)
