# @auth/neon-adapter

An official [PostgreSQL](https://www.postgresql.org/) adapter for Auth.js / NextAuth.js.

[![](/img/adapters/neon.svg)](https://www.postgresql.org/)

npmpnpmyarnbun

```

```

```
pnpm add next-auth @auth/neon-adapter
```

```
yarn add next-auth @auth/neon-adapter
```

```
bun add next-auth @auth/neon-adapter
```
