JSX attributes

# prop:\*

[Edit this page](https://github.com/solidjs/solid-docs/edit/main/src/routes/reference/jsx-attributes/prop.mdx)

Forces the prop to be treated as a property instead of an attribute.

```
<div prop:scrollTop={props.scrollPos + "px"} />
```

Strong-Typing Custom Properties

Type definitions are required when using TypeScript. See the [TypeScript](/configuration/typescript#forcing-properties-and-custom-attributes) page for examples.
