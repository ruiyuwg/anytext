# Title

[Edit this page](https://github.com/solidjs/solid-docs/edit/main/src/routes/solid-meta/reference/meta/title.mdx)

`Title` is a component that renders the [`title`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/title) element. This will render the title of the page in the browser tab.

```
import { Title } from "@solidjs/meta";<Title>My Site</Title>;
```

***

## [Usage](/solid-meta/reference/meta/title#usage)

### [Setting the title for your site](/solid-meta/reference/meta/title#setting-the-title-for-your-site)

```
import { MetaProvider, Title } from "@solidjs/meta";export default function Root() {  return (    <MetaProvider>      <Title>Default Application Title</Title>    </MetaProvider>  );}
```
