# StartServer

[Edit this page](https://github.com/solidjs/solid-docs/edit/main/src/routes/solid-start/reference/server/start-server.mdx)

`StartServer` takes a function returning a document component and converts it to a static document which can be used in [`createHandler`](/solid-start/reference/server/create-handler) to bootstrap the server.

```
import { StartServer } from "@solidjs/start/server";
```

***

## [Parameters](/solid-start/reference/server/start-server#parameters)

Property

Type

Description

document

Function

A function that returns the static document for your application.
