# Load Balancing

You can use Cloudflare Load Balancing with Cloudflare WAN (formerly Magic WAN) to distribute traffic across endpoints, reducing strain and improving the performance of your network. Cloudflare WAN uses Private Network Load Balancing, which supports both on-ramping and off-ramping traffic to Cloudflare WAN.

Refer to [Private Network Load Balancing](https://developers.cloudflare.com/load-balancing/private-network/) for more information about the feature and how to set it up. Before using this feature, [enable Load Balancing](https://developers.cloudflare.com/load-balancing/).
