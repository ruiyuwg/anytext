# Index

## Guides Table Of Contents[​](#guides-table-of-contents "Direct link to Guides Table Of Contents")

[]()

This table of contents is in alphabetical order.

- [Benchmarking](/docs/v5.3.x/Guides/Benchmarking/.md): This guide introduces how to benchmark applications based on Fastify.
- [Contributing](/docs/v5.3.x/Guides/Contributing/.md): Details how to participate in the development of Fastify, and shows how to setup an environment compatible with the project's code style.
- [Delay Accepting Requests](/docs/v5.3.x/Guides/Delay-Accepting-Requests/.md): A practical guide on how to delay serving requests to specific routes until some condition is met in your application. This guide focuses on solving the problem using [`Hooks`](/docs/v5.3.x/Reference/Hooks/.md), [`Decorators`](/docs/v5.3.x/Reference/Decorators/.md), and [`Plugins`](/docs/v5.3.x/Reference/Plugins/.md).
- [Detecting When Clients Abort](/docs/v5.3.x/Guides/Detecting-When-Clients-Abort/.md): A practical guide on detecting if and when a client aborts a request.
- [Ecosystem](/docs/v5.3.x/Guides/Ecosystem/.md): Lists all core plugins and many known community plugins.
- [Fluent Schema](/docs/v5.3.x/Guides/Fluent-Schema/.md): Shows how JSON Schema can be written with a fluent API and used in Fastify.
- [Getting Started](/docs/v5.3.x/Guides/Getting-Started/.md): Introduction tutorial for Fastify. This is where beginners should start.
- [Migration Guide (v4)](/docs/v5.3.x/Guides/Migration-Guide-V4/.md): Details how to migrate to Fastify v4 from earlier versions.
- [Migration Guide (v3)](/docs/v5.3.x/Guides/Migration-Guide-V3/.md): Details how to migrate to Fastify v3 from earlier versions.
- [Plugins Guide](/docs/v5.3.x/Guides/Plugins-Guide/.md): An informal introduction to writing Fastify plugins.
- [Prototype Poisoning](/docs/v5.3.x/Guides/Prototype-Poisoning/.md): A description of how the prototype poisoning attack works and is mitigated.
- [Recommendations](/docs/v5.3.x/Guides/Recommendations/.md): Recommendations for how to deploy Fastify into production environments.
- [Serverless](/docs/v5.3.x/Guides/Serverless/.md): Details on how to deploy Fastify applications in various Function as a Service (FaaS) environments.
- [Style Guide](/docs/v5.3.x/Guides/Style-Guide/.md): Explains the writing style we use for the Fastify documentation for those who want to contribute documentation.
- [Testing](/docs/v5.3.x/Guides/Testing/.md): Explains how to write unit tests for Fastify applications.
- [Write Plugin](/docs/v5.3.x/Guides/Write-Plugin/.md): A set of guidelines for what the Fastify team considers good practices for writing a Fastify plugin.
