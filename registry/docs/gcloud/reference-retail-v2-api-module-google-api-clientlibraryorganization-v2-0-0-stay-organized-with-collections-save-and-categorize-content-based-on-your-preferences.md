Reference documentation and code samples for the Retail V2 API module Google::Api::ClientLibraryOrganization.

The organization for which the client libraries are being published. Affects the url where generated docs are published, etc.

## Constants

### CLIENT\_LIBRARY\_ORGANIZATION\_UNSPECIFIED

**value:** 0  
Not useful.

### CLOUD

**value:** 1  
Google Cloud Platform Org.

### ADS

**value:** 2  
Ads (Advertising) Org.

### PHOTOS

**value:** 3  
Photos Org.

### STREET\_VIEW

**value:** 4  
Street View Org.

### SHOPPING

**value:** 5  
Shopping Org.

### GEO

**value:** 6  
Geo Org.

### GENERATIVE\_AI

**value:** 7  
Generative AI - [https://developers.generativeai.google](https://developers.generativeai.google)
