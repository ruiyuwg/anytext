# Access Transparency Mantieni tutto organizzato con le raccolte Salva e classifica i contenuti in base alle tue preferenze.

[Access Transparency](https://docs.cloud.google.com/assured-workloads/access-transparency/docs/overview?hl=it) ti fornisce log che acquisiscono le azioni intraprese dal personale di Google quando accede ai tuoi contenuti.

Puoi [attivare Access Transparency](https://docs.cloud.google.com/assured-workloads/access-transparency/docs/enable?hl=it) per la tua organizzazione Google Cloud se disponi delle autorizzazioni richieste per la tua organizzazione. Una volta attivata, puoi [leggere i log](https://docs.cloud.google.com/assured-workloads/access-transparency/docs/reading-logs?hl=it).
