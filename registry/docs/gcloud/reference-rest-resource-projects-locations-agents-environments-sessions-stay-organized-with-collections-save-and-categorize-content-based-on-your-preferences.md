# REST Resource: projects.locations.agents.environments.sessions Stay organized with collections Save and categorize content based on your preferences.

 

## Resource

There is no persistent data associated with this resource.

 

## Methods

### `[detectIntent](/dialogflow/cx/docs/reference/rest/v3/projects.locations.agents.environments.sessions/detectIntent)`

Processes a natural language query and returns structured, actionable data as a result.

### `[fulfillIntent](/dialogflow/cx/docs/reference/rest/v3/projects.locations.agents.environments.sessions/fulfillIntent)`

Fulfills a matched intent returned by `[MatchIntent](/dialogflow/cx/docs/reference/rest/v3/projects.locations.agents.sessions/matchIntent#google.cloud.dialogflow.cx.v3.Sessions.MatchIntent)`.

### `[matchIntent](/dialogflow/cx/docs/reference/rest/v3/projects.locations.agents.environments.sessions/matchIntent)`

Returns preliminary intent match results, doesn't change the session status.

### `[serverStreamingDetectIntent](/dialogflow/cx/docs/reference/rest/v3/projects.locations.agents.environments.sessions/serverStreamingDetectIntent)`

Processes a natural language query and returns structured, actionable data as a result through server-side streaming.
