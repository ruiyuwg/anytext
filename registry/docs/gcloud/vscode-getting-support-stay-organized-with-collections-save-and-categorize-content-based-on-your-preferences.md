# Getting support Stay organized with collections Save and categorize content based on your preferences.

## File bugs or feature requests

If you encounter any bugs, confusing commands, or unclear documentation, or if you'd like to propose a feature idea, you can file your feedback using one of the following methods:

-   Choosing the **Cloud Code: Report Extension Issue on GitHub** option from the command palette (press `Ctrl`/`Cmd`+`Shift`+`P` or click **View** > **Command Palette**).
-   [Submitting a GitHub issue](https://github.com/GoogleCloudPlatform/cloud-code-vscode/issues).
-   Clicking the **Send feedback** link in this documentation to open a feedback form.

The Cloud Code team reviews your comments.

## Get support from the community

### Google Developer Program forums

For community-based support, discussions, and to connect with other users and Google staff, your primary destination is [discuss.google.dev](https://discuss.google.dev/c/google-cloud/14). This is the official forum for:

-   **Asking questions.** Get peer-to-peer support for your technical challenges.
-   **Sharing knowledge.** Contribute your expertise and help other members of the community.
-   **Engaging with Google staff.** Discuss with Google Cloud team members and find best practices and tutorials from Google staff.

### Ask a question on Stack Overflow

Ask a question about Cloud Code on [Stack Overflow](http://stackoverflow.com/questions/tagged/cloud-code-vscode). Use the tag `cloud-code-vscode` for questions about Cloud Code. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Keep up with Google Cloud

-   Read the [Google Cloud blog](https://cloudplatform.googleblog.com/).
-   Follow [@googlecloud](https://twitter.com/googlecloud) on Twitter.

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](/support).
