## This package is not the recommended entry point to using this client library!

For this library, we recommend using [com.google.cloud.spanner](https://cloud.google.com/java/docs/reference/google-cloud-spanner/latest/com.google.cloud.spanner) for new applications.

## Stub Package Implications

This package is a a base stub class. It is for advanced usage and reflects the underlying API directly. We generally recommend using the non-stub, latest GA package, such as [com.google.cloud.spanner](https://cloud.google.com/java/docs/reference/google-cloud-spanner/latest/com.google.cloud.spanner). Use with caution.
