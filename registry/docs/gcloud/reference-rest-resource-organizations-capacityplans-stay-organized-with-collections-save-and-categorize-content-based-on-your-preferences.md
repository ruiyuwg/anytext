# REST Resource: organizations.capacityPlans Stay organized with collections Save and categorize content based on your preferences.

 

## Resource

There is no data associated with this resource at the folder level or organization level. Persistent data associated with this resource only exists at the project level. For more information, see the [projects.capacityPlans resource](/capacity-planner/docs/api/reference/rest/v1beta/projects.capacityPlans).

 

## Methods

### `[query](/capacity-planner/docs/reference/rest/v1beta/organizations.capacityPlans/query)`

Returns a list of the capacity plans that are in the parent parameter and match your specified filters.
