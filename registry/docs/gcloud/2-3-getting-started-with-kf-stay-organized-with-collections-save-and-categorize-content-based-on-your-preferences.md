# Getting started with Kf Stay organized with collections Save and categorize content based on your preferences.

With Kf, you can migrate your Cloud Foundry apps to [Google Kubernetes Engine (GKE)](/kubernetes-engine) or [GKE Enterprise](/anthos) without changing your developer workflows.

Use the sections below to get started deploying Cloud Foundry apps to GKE using Kf.

## Get started with a quickstart

Use the [quickstart](/migrate/kf/docs/2.3/quickstart) to install Kf and deploy a simple test Cloud Foundry app. This introduces you to the basic steps you'd perform for most app deployments.

## Get an introduction to key concepts

For an introduction to the value of Kf, as well as high-level overviews of the technology, see the following topics.

-   Visit [Kf Dependencies and Architecture](/migrate/kf/docs/2.3/concepts/kf-dependencies) to learn more about how Kf works.
-   Look at a [side-by-side comparison](/migrate/kf/docs/2.3/concepts/compare-services) of Cloud Foundry and Kf components.
-   For information on using service brokers with Kf, see [Service Brokers](/migrate/kf/docs/2.3/concepts/about-service-brokers).
-   For more on Kf security design, see [Security Overview](/migrate/kf/docs/2.3/concepts/security-overview).
