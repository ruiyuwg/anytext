# Getting support

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Identity Platform on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-identity). Use the tag `google-identity` for questions about Identity Platform. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Identity Platform

You can visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Identity Platform and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA).

### File feature requests and bug reports

If you'd like to request a new feature for Identity Platform, or encounter a reproducible bug, you can report them through the [issue tracker](/support/docs/issue-trackers). You can [review the open issues](https://issuetracker.google.com/savedsearches/6115075) to see if your bug or request has already been reported, and [star](https://developers.google.com/issue-tracker/guides/subscribe#subscribing_by_starring_an_issue) an existing thread to keep updated. If there are no existing threads, you can [request a new feature](https://issuetracker.google.com/issues/new?component=1120253&template=1629995) or [report a new bug](https://issuetracker.google.com/issues/new?component=1120253&template=1629969).
