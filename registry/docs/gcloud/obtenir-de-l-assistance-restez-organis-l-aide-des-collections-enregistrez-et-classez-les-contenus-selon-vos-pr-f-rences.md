# Obtenir de l'assistance Restez organisé à l'aide des collections Enregistrez et classez les contenus selon vos préférences.

## Obtenir une formule d'assistance Google

Google Cloud propose plusieurs formules d'assistance répondant à différents besoins tels que la couverture 24h/24, 7j/7, l'assistance téléphonique et l'accès à un responsable de l'assistance technique. Pour en savoir plus, consultez la page [Cloud Customer Care](https://docs.cloud.google.com/support?hl=fr).

## Obtenir l'aide de la communauté

Posez une question concernant Cloud Run Functions sur [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-functions). Utilisez le tag `google-cloud-functions` pour les questions concernant Cloud Run Functions. Ce tag reçoit non seulement des réponses de la communauté Stack Overflow, mais également des ingénieurs de Google, qui surveillent le tag et offrent un support non officiel.

Vous pouvez également consulter des [tutoriels de la communauté](https://docs.cloud.google.com/community/tutorials?q=%22Cloud+Functions%22&hl=fr).

## Discuter de Cloud Run Functions

Consultez la [communauté Slack](https://googlecloud-community.slack.com/) Google Cloudpour discuter de Cloud Run Functions et d'autres produits Google Cloud . Si vous n'avez pas encore rejoint la communauté, [inscrivez-vous à l'aide de ce formulaire](https://join.slack.com/t/googlecloud-community/shared_invite/zt-2mz6i6j8l-qMC13DEg6FAtGMH4wVytTA). Pour Cloud Run Functions, rejoignez le canal [`#functions`](https://googlecloud-community.slack.com/messages/C1D2F6GRF/).

## Signaler des bugs ou demander des fonctionnalités

Si vous pensez avoir trouvé un bug légitime, vous êtes invité à le signaler dans l'[outil public de suivi des problèmes](https://issuetracker.google.com/issues?q=status%3Aopen+componentid%3A187195&hl=fr). Un membre de notre équipe d'assistance et/ou de développement sera ainsi alerté. Si l'objectif principal de ce canal est le signalement de bugs, vous pouvez également soumettre ici des demandes de fonctionnalités.

## Groupe de testeurs bêta

Le [groupe de testeurs bêta de Cloud Run Functions](https://groups.google.com/forum/?hl=fr#!forum/cloud-functions-beta-testers) est un forum permettant de répondre aux questions techniques des développeurs à propos de Cloud Run Functions. Ce groupe est largement axé sur la communauté, avec des réponses fournies par d’autres utilisateurs. L'assistance Google, ainsi que les équipes produit et ingénierie, peuvent participer à la conversation lorsqu'une réponse officielle est requise. [Rejoignez le groupe](https://groups.google.com/forum/?hl=fr#!forum/cloud-functions-beta-testers) pour publier une nouvelle question et aider vos collègues utilisateurs bêta à faire leurs premiers pas avec Cloud Run Functions.

Le groupe de testeurs bêta est également un lieu de découverte et d'information au sujet des nouvelles fonctionnalités de Cloud Run Functions au fur et à mesure de leur développement. Comme toujours, nous accueillons les demandes de fonctionnalités générales et les suggestions via ce groupe et nous les transmettons directement à notre équipe de développement.
